한 줄 정의

제논-135 독작용은 핵분열생성물 ¹³⁵Xe(열중성자 흡수단면적 약 2.65×10⁶ b)가 주로 ¹³⁵I 붕괴로 생성되어 열중성자를 흡수함으로써 열중성자 이용률 f를 낮추고 음의 반응도를 주는 현상이며, 생성과 소멸(붕괴·연소)의 시간차 때문에 출력 변화와 정지 후 수십 시간에 걸친 반응도 변화를 일으킵니다.

원리와 메커니즘

생성과 소멸 경로

¹³⁵Te —β⁻(약 11 s)→ ¹³⁵I —β⁻(6.7 h)→ ¹³⁵Xe —β⁻(9.2 h)→ ¹³⁵Cs 순서로 붕괴합니다. ¹³⁵Te는 금방 붕괴하므로 ¹³⁵I가 핵분열에서 직접 생긴다고 봅니다. ²³⁵U 열핵분열의 유효 수율은 γI = 0.0639, γXe = 0.00237이므로(Lamarsh 3판 Table 7.5)[1] ¹³⁵Xe의 약 96 %는 ¹³⁵I 붕괴로 생깁니다. 소멸은 자체 β 붕괴(λXe)와 중성자 흡수(σa^Xe φ, "연소")의 두 경로이고, 흡수 후 생긴 ¹³⁶Xe는 독성이 거의 없습니다.

  • dI/dt = γI Σf φ − λI I
  • dX/dt = γXe Σf φ + λI I − λXe X − σa^Xe φ X
  • 반응도(누설 무시, f 변화만): ρXe = −σa^Xe X/(ν p ε Σf)

상수는 λI = 2.87×10⁻⁵ s⁻¹, λXe = 2.09×10⁻⁵ s⁻¹(Lamarsh Table 7.6), σa^Xe = 2.65×10⁶ b(2,200 m/s)입니다[1]. 전출력 φ = 5×10¹³ n/cm²·s에서 연소 항 σφ = 1.3×10⁻⁴ s⁻¹은 붕괴상수의 약 6배이므로, 운전 중 제논은 주로 연소로 사라지고 정지하면 붕괴로만 사라집니다. 이 비대칭이 아래 거동을 모두 설명합니다.

평형제논 — 출력에 비례하지 않는다

시간 미분을 0으로 두면 평형값이 나옵니다.

  • I∞ = γI Σf φ/λI, X∞ = (γI + γXe) Σf φ/(λXe + σa^Xe φ)
  • ρ∞ = −[(γI + γXe)/(ν p ε)] × φ/(φX + φ), φX = λXe/σa^Xe ≈ 7.9×10¹² n/cm²·s

φ ≪ φX이면 출력에 비례하고, φ = φX에서 포화값의 절반, φ ≫ φX이면 최대 −(γI + γXe)/ν = −0.066/2.42 ≈ −2.73 %(약 −2,740 pcm) 에 다가갑니다. 출력용 PWR은 φ가 φX보다 몇 배 커 포화 영역에 있으므로, 50 % 출력에서도 평형제논은 100 %의 약 88 %입니다(아래 표, 교과서 1군 모델 계산값[1][2]). 실제 PWR 값은 노형·연소도·스펙트럼 평균 단면적에 따라 달라 이 계산값과 같지 않습니다.

열중성자속 φ 1×10¹³ 2.5×10¹³ 5×10¹³ 1×10¹⁴
평형 ρ (pcm) −1,531 −2,082 −2,365 −2,538
정지 후 정점 시각 5.7 h — 9.5 h 10.3 h
정지 후 정점 ρ (pcm) −1,861 — −6,296 −11,550

무제논 상태에서 기동하면 ¹³⁵I(6.7 h)를 거치므로 평형까지 시간이 걸립니다. φ = 5×10¹³에서 24시간 후 90 %, 48시간 후 99 %이므로 약 40~50시간이면 평형입니다.

정지 후 제논 정점

정지하면 φ = 0이 되어 연소가 멈춥니다. 남은 ¹³⁵I는 계속 붕괴해 제논을 만들고, λI > λXe이므로 한동안 생성이 소멸보다 큽니다.

  • X(t) = X0 e^(−λXe t) + [λI I0/(λI − λXe)] (e^(−λXe t) − e^(−λI t))
  • 정점 시각 t_max = ln{(λI/λXe) · λI I0/[λI I0 + (λI − λXe) X0]}/(λI − λXe)

정점은 약 10시간 전후이고, 정지 전 중성자속이 클수록 더 높고 늦습니다. φ = 5×10¹³에서 정점은 정지 9.5시간 후 평형값의 약 2.7배이며, 정지 약 34시간 후 평형값 아래로 내려가며, 이후 수일에 걸쳐 줄어듭니다(정지 48시간 후에도 평형값의 약 40 %).

이 정점 동안 가용 반응도 여유보다 제논 반응도가 크면 재기동할 수 없습니다(재기동불능시간). 예를 들어 무제논 기준으로 제논 보상에 쓸 수 있는 여유가 4,000 pcm(가상)이면, 위 모델에서 정지 후 약 1.8~24.0시간 사이가 해당합니다.

출력 단계 변화 — 순간과 최종이 반대 방향

구분 직후(수 시간) 극값 최종(약 2일, 48 h)
100 → 50 % 연소 감소 → 제논 증가 4.8 h 후 −3,303 pcm 새 평형 −2,082 pcm(감소)

직후 방향은 연소 항의 변화가, 최종 방향은 평형값 차이가 정합니다(φ100 = 5×10¹³ 기준 계산).

원전에서의 의미

  • 운전 보상: 정지 후 재기동 시에는 제논 정점·감소 시점을 예측해 임계 붕소농도(ECC)를 계산합니다.
  • 주기말 제약: 주기말에는 붕소 농도가 낮아 희석 여유가 작으므로 제논 정점을 보상(override)하지 못해 재기동불능시간이 생기기 쉽습니다.
  • 부하추종: 출력을 내리면 제논이 먼저 늘어 출력 회복을 방해합니다.
  • 안전 해석: 정지여유도와 잉여반응도 평가에서 제논 상태(평형·무제논·정점)를 조건으로 명시합니다.

답안용 요약

  1. 정의: 핵분열생성물 ¹³⁵Xe(σa ≈ 2.65×10⁶ b)의 열중성자 흡수로 f 감소 → 음의 반응도
  2. 생성: ¹³⁵I(T½ 6.7 h) 붕괴 약 96 % + 직접 수율 γXe
  3. 소멸: 붕괴(T½ 9.2 h) + 중성자 흡수(연소, 전출력에서 지배적)
  4. 평형제논: ρ∞ = −[(γI + γXe)/ν]·φ/(φX + φ), φX ≈ 7.9×10¹² → 고출력 포화, 최대 약 −2.7 %
  5. 도달 시간: 무제논 기동 후 약 40~50 h
  6. 정지 후: 연소 정지 + ¹³⁵I 계속 붕괴 → 약 10 h 후 정점, 이후 수일에 걸쳐 감소
  7. 재기동불능시간: 제논 반응도 > 가용 여유 구간, 주기말에 문제
  8. 출력 변화: 감소 시 일시 증가 후 낮은 평형, 증가 시 일시 감소 후 높은 평형
  9. 대응: 붕소·제어봉 보상, 축방향 제논 진동 감시(ASI)

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

계산 예 — 출력 50 → 100 % 평형제논 반응도(2020년 4교시 2번)

주어진 값: φ50 = 2.5×10¹³, φ100 = 5.0×10¹³, γI 0.06, γXe 0.002, Σf 0.18 cm⁻¹, Σa,F 0.58, Σa,M 0.10 cm⁻¹, σa^Xe 2.7×10⁶ b, T½ 9.2 h. 나머지 5인자 = 1이므로 k = f입니다.

  1. λXe = 0.693/(9.2×3,600) = 2.093×10⁻⁵ s⁻¹, φX = λXe/σ = 7.75×10¹²
  2. Σa^Xe = (γI + γXe)Σf φ/(φX + φ) → 50 %: 0.008519 cm⁻¹, 100 %: 0.009662 cm⁻¹
  3. f50 = 0.58/0.688519 = 0.84239, f100 = 0.58/0.689662 = 0.84099
  4. Δρ = 1/k50 − 1/k100 = (0.688519 − 0.689662)/0.58 = −1.97×10⁻³ ≈ −197 pcm

Δk/k 근사로 쓰면 약 −166 pcm이므로, 어느 정의를 썼는지 답안에 밝혀 두는 것이 좋습니다. 출력이 두 배인데 평형제논 반응도 변화가 이렇게 작은 것이 포화의 결과입니다.

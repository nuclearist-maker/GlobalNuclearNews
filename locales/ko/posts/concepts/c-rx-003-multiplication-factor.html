한 줄 정의

증배계수는 한 세대에 핵분열로 생긴 중성자 수를 앞 세대 중성자 수로 나눈 값입니다. 수지로 쓰면 생성률 ÷ (흡수율 + 누설률)입니다. 누설이 없는 무한 매질의 값이 무한증배계수 k∞ = η·f·p·ε(4인자 공식)이고, 유한 노심의 값이 유효증배계수 keff = k∞·P_FNL·P_TNL(6인자 공식)입니다.

답안 첫 줄은 "중성자 한 세대의 생성 대 소멸(흡수+누설) 비로, keff = 1이면 임계이며 열중성자로에서는 6인자의 곱으로 표현함"이라고 쓰면 정의·판정 기준·공식이 함께 들어갑니다.

원리와 메커니즘

중성자 한 세대 따라가기

열중성자로에서 핵분열로 태어난 고속중성자 N개는 다음 순서로 늘고 줄어듭니다. 인자의 정의는 "그 단계를 통과한 수 ÷ 들어온 수"입니다. 이 순서는 수지를 세는 순서일 뿐, 사건이 꼭 이 차례로만 일어난다는 뜻은 아닙니다.

단계 인자 정의 무엇을 셈하나
① ε 고속핵분열인자 전체 핵분열 고속중성자 ÷ 열핵분열 고속중성자 고속분열(주로 U-238, 문턱 약 1 MeV)로 얻는 추가분
② P_FNL 고속비누설확률 감속 중 노심 밖으로 새지 않을 확률 고속 누설
③ p 공명이탈확률 공명영역(약 6~200 eV)을 흡수 없이 통과할 확률 U-238 공명흡수 손실
④ P_TNL 열비누설확률 열중성자가 흡수 전 새지 않을 확률 열 누설
⑤ f 열중성자이용률 열중성자 흡수 중 연료 흡수 비율 감속재·구조재·독물질 흡수 손실
⑥ η 재생계수 연료 흡수 열중성자 1개당 생성 고속중성자 수 η = ν·Σf^F/Σa^F (연료 흡수가 모두 핵분열은 아님)

아래 그림은 DOE 기초 핸드북(DOE-HDBK-1019)의 예제 값(ε 1.031, P_FNL 0.889, p 0.803, P_TNL 0.905, f 0.751, η 2.012)으로 10,000개를 한 바퀴 돌린 결과입니다. 이 예제에서는 공명흡수(−1,806)와 비연료 흡수(−1,659)가 가장 큰 손실이고, 누설 두 항을 합하면 약 1,840개가 빠져나갑니다. 다음 세대는 10,065개이므로 keff ≈ 1.0065입니다[1].

4인자와 누설 2인자는 결정 요인이 다르다

  • k∞ = η·f·p·ε는 격자(재료) 성질입니다. 농축도, 감속재/연료비, 연료봉 직경, 온도, 붕소·독물질이 정합니다. 위 예제는 k∞ = 1.251입니다.
  • P_FNL·P_TNL은 노심 크기·형상이 정합니다. 1군 확산이론에서 P_TNL = 1/(1+L²B²)이고, 고속은 페르미 나이이론으로 P_FNL ≈ e^(−τB²), 작은 τB²에서는 1/(1+τB²)로 근사합니다(L² 열확산면적, τ 페르미 나이, B² 기하학적 버클링)[2]. 예제에서 두 값의 곱은 0.805입니다.

열중성자 확산방정식 −D∇²φ + Σaφ = (1/k)·νΣfφ에 ∇²φ = −B²φ를 넣으면 keff = k∞/(1+L²B²)가 바로 나옵니다(2002년 2교시 1번). 2군으로 확장하면 keff = ν₁Σf1/(D₁B²+Σr1) + ν₂Σf2·Σs12/[(D₁B²+Σr1)(D₂B²+Σa2)]이고(2002년 3교시 1번, 원문 가정 B_g² = B²), 1군형으로 묶으면 keff ≈ k∞/(1+M²B²), M² = L² + τ입니다. 임계조건 keff = 1은 재료 버클링 B_m² = (k∞−1)/M²과 기하학적 버클링 B_g²이 같아지는 조건과 같은 말입니다.

η 계산 예 (2004년 3교시 3번 조건)

2.5 wt% 농축, σf²³⁵ = 580 b, σa²³⁵ = 680 b, σa²³⁸ = 2.8 b, ν = 2.43이면 원자수비 N₂₅/N₂₈ = (0.025/235)/(0.975/238) = 0.0260입니다.

η = ν·σf25·N₂₅ / (σa25·N₂₅ + σa28·N₂₈) = 2.43×580×0.0260 / (680×0.0260 + 2.8) ≈ 1.79

순수 U-235는 2.43×580/680 ≈ 2.07, 천연우라늄은 약 1.33입니다[2]. U-238 흡수가 분모에 들어가기 때문에 η는 농축도에 따라 크게 달라집니다.

keff 범위와 원자로 상태

keff ρ 상태 중성자 수
< 1 < 0 미임계 세대마다 감소(외부 선원이 있으면 일정 수준으로 수렴)
= 1 0 임계 일정
> 1 0 < ρ < β 지발초임계 지발중성자가 주기 지배, 제어 가능
> 1 ρ ≥ β 즉발임계·즉발초임계 즉발중성자만으로 증가, 설계상 배제

위 예제의 ρ ≈ 0.0064는 β = 0.0065에 가까운 큰 값입니다. 세대 수지를 보여주는 예제일 뿐 운전 상태가 아닙니다. 실제 운전에서는 붕소와 제어봉으로 keff = 1을 유지합니다.

원전에서의 의미 — 인자별 영향

같은 "k∞ 감소"라도 어느 인자가 움직이는지를 써야 25점 답안이 됩니다.

규제·기준 근거

  • 10 CFR 50.68(1998 신설): 신연료 저장대 keff ≤ 0.95(무붕산수 침수)와 최적감속 시 ≤ 0.98, 사용후연료 저장대 keff ≤ 0.95를 요구합니다. 붕산 효과를 인정하면 무붕산수 침수 시에도 1.0 미만이어야 합니다. 모두 95% 확률·95% 신뢰도 기준입니다[3].
  • GDC 62: 핵연료 저장·취급 중 임계를 기하학적 안전 배치로 우선 방지하도록 요구합니다. GDC 26·27은 반응도 제어계통과 정지여유도를 다룹니다[4].
  • NUREG-0800 SRP 4.3: 증배계수·반응도 계수의 계산 방법과 불확도를 심사합니다. SRP 9.1.1·9.1.2는 저장 임계 해석을 심사합니다[5]. 재장전 중 붕소농도는 표준기술지침서와 노심운영제한보고서(COLR)로 관리합니다.
  • IAEA: SSR-2/1(Rev.1, 2016)과 SSG-52(2019)가 노심 설계와 반응도 제어 요건을 둡니다[6].
  • 국내: 「원자로시설 등의 기술기준에 관한 규칙」의 핵연료 저장·취급 임계 방지 조항(제33조 ①1호·②1호, 운영은 제61조)과 제28조(반응도제어계통)가 같은 구조를 따릅니다[7].
  • 출제 당시 대비: 증배계수 물리는 바뀐 것이 없습니다. 2002~2004년 출제 시점에도 10 CFR 50.68은 시행 중이었습니다.

답안용 요약

[10점 답안 예시] 유효증배계수와 6인자, keff에 따른 원자로 상태

  1. 정의: keff = 한 세대 생성 중성자 ÷ 앞 세대(흡수+누설) 중성자임
  2. 4인자(k∞): k∞ = η·f·p·ε, 누설 없는 무한 매질, 격자 성질임
  3. ε: U-238 고속분열 추가분, 비균질로 약 1.03
  4. p: U-238 공명영역(약 6~200 eV) 흡수를 피할 확률
  5. f: 열중성자 흡수 중 연료 흡수 비율, 감속재·독물질 흡수로 감소
  6. η: 연료 흡수당 생성 중성자 = ν·Σf/Σa, U-235 약 2.07, 천연U 약 1.33
  7. 누설 2인자: P_FNL ≈ e^(−τB²), P_TNL = 1/(1+L²B²) → keff = k∞·P_FNL·P_TNL
  8. 상태: keff < 1 미임계, = 1 임계, > 1 초임계(0 < ρ < β 지발초임계, ρ ≥ β 즉발임계)
  9. 설계·운전: 연소로 k∞ 감소 → 붕소·가연성독봉으로 잉여반응도 관리, 저장 keff ≤ 0.95

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

한 줄 정의

**감속재온도계수(MTC, Moderator Temperature Coefficient, α_M)**는 다른 온도를 고정한 채 감속재 평균 온도가 1도 변할 때의 반응도 변화 α_M = ∂ρ/∂T_M입니다. 단위는 pcm/°C 또는 pcm/°F(1 pcm/°F = 1.8 pcm/°C)를 씁니다. 기출의 "감속재 온도계수", "감속재온도계수", "MTC"는 모두 같은 개념입니다.

답안 첫 줄은 "감속재 온도 변화에 따른 반응도 변화율로, 경수로에서는 물의 밀도 변화가 부호를 결정하며 출력 운전 영역에서 음이 되도록 설계함"이면 충분합니다.

원리와 메커니즘

온도가 아니라 밀도가 주역

경수로에서 감속재 온도가 오르면 물이 팽창해 수소 원자수밀도가 줄어듭니다. MTC는 대부분 이 밀도 효과로 정해지고, 순수한 온도(스펙트럼 경화) 효과는 작습니다. 그래서 감속재 밀도계수 α_D = ∂ρ/∂ρ_w와 α_M ≈ α_D·(∂ρ_w/∂T)로 연결됩니다(∂ρ_w/∂T < 0). 밀도가 줄면 세 가지가 겹칩니다.

  1. 감속 능력 감소 → 공명탈출확률 p 감소(음)
  2. 감속·확산 거리 증가 → 비누설확률 감소(음)
  3. 물과 용해 붕소의 흡수 감소 → 열중성자 이용률 f 증가(양). 붕소 농도에 비례해 커집니다.

셋의 합이 MTC의 부호입니다[1][2]. PWR은 무붕소 기준 과소감속 영역(감속재/연료비가 k∞ 최대점보다 작은 쪽)에 설계점을 둡니다. 그러면 1·2가 3을 이겨 MTC가 음이 됩니다.

붕소가 많으면 최대점이 왼쪽으로 간다

붕소를 녹이면 감속재 쪽 흡수가 커져 k∞ 최대점이 낮은 감속재/연료비 쪽으로 이동합니다. 최대점이 설계점보다 왼쪽에 오면 설계점은 과다감속 쪽이 되고, 온도 상승(밀도 감소)이 오히려 k∞를 키웁니다. 이것이 주기초(BOC) 양의 MTC의 원리입니다(2019년 3교시 2번).

단순 2인자 모델(f = 1/(1 + b·x), p = exp(−0.25/x), 설계점 x = 1)로 계산하면 무붕소 최대점은 x ≈ 1.96입니다. 붕소 1,500 ppm에서는 x ≈ 1.06, 2,000 ppm에서는 x ≈ 0.97로 설계점을 넘어갑니다. 누설과 스펙트럼 변화를 뺀 개념 모델이므로 실제 경계 농도는 노심 설계 계산으로 정합니다.

안전해석에서 양쪽 끝이 모두 쓰인다

  • 가장 덜 음(BOC·저출력): 부하상실, 급수상실, 저출력 제어봉 인출 같은 가열 사건과 ATWS 압력 첨두에 보수적입니다. APR1400 DCD 15.4.1·15.4.2는 BOC의 최대 양 MTC를 가정합니다[8].
  • 가장 음(EOC): 주증기관파단처럼 냉각 사건에서 재임계·출력 복귀에 보수적입니다.
  • 정상 운전에서는 음의 MTC가 출력 자기제어와 부하추종을 돕습니다. 연료 쪽 즉발 궤환은 FTC이고, 둘을 합친 출력 궤환은 출력계수입니다.

최소임계온도(2013년 1교시 1번, 2026년 1교시 8번)

임계 전 저온관온도를 운영기술지침서 최소값 이상으로 유지하는 이유는 다음과 같습니다.

  1. 저온일수록 MTC가 덜 음(양 가능)이므로 MTC를 안전해석 가정 범위 안에 둡니다.
  2. 보호계통 계측기를 정상 측정 범위 안에서 씁니다.
  3. 가압기 증기 거품(운전 가능 상태)을 유지합니다.
  4. 원자로용기를 최소 RTNDT 이상(P-T 한계)에서 임계로 만듭니다[4].

계산 기출 3문항

  • ITC와 출력계수(2020년 3교시 1번, 2026년 3교시 2번): 등온온도계수 ITC = MTC + FTC입니다. 2020년은 FTC = −12 − (−10) = −2 pcm/K입니다. 출력계수 = MTC·dT_M/dP + FTC·dT_F/dP = (−10)(2) + (−2)(10) = −40 pcm/%power입니다. 2026년은 FTC = −1 pcm/K, 출력계수 = (−5)(1) + (−1)(5) = −10 pcm/%power입니다.
  • MTC와 안정주기(2023년 4교시 6번): 100 °C 상승에 −0.2 %Δk/k이면 α_M = −2 pcm/°C입니다. 350 → 320 °C 냉각이면 Δρ = +60 pcm(+6×10⁻⁴)입니다. 1군 근사(β = 0.0065, λ = 0.08 s⁻¹ — 설명용 가정) 안정주기는 T = (β − ρ)/(λρ) = 0.0059/(0.08 × 0.0006) ≈ 123 s이고, keff = 1/(1 − ρ) = 1.0006입니다.

규제·기준 근거

  • 10 CFR 50 부록 A GDC 11(원자로 고유 보호): 출력운전 범위에서 즉발 고유 궤환이 급격한 반응도 증가를 보상하는 경향을 가져야 합니다. 음의 MTC·FTC가 이 요건의 실체입니다[6].
  • NUREG-0800 SRP 4.3(노심 설계): 반응도계수 계산과 불확실도를 심사합니다.
  • STS LCO 3.1.3(Westinghouse형, NUREG-1431 현행 Rev.5): MTC를 노심운영제한보고서(COLR) 한계 이내로 유지합니다. 상한은 MODE 1과 MODE 2(keff ≥ 1), 하한은 MODE 1~3에 적용합니다. 상한을 벗어나면 24시간 안에 제어봉 행정적 인출한계를 설정하고, 못 하면 6시간 안에 MODE 2(keff < 1)로 갑니다. 하한을 벗어나면 12시간 안에 MODE 4로 갑니다[4].
  • 한계값 예시: Ginna COLR(Westinghouse형, Cycle 39)은 BOL HZP 상한 +5 pcm/°F(70 % RTP 미만), 0 pcm/°F(70 % 이상), EOL 전출력 하한 −44.6 pcm/°F입니다. CE형 STS(NUREG-1432 LCO 3.1.4)는 양의 한계를 +0.5×10⁻⁴ Δk/k/°F(70 % RTP 이하), 0(70 % 초과)으로 둡니다(STS 원문은 호기별로 채우는 대괄호 값). 값은 호기·주기별 COLR을 따릅니다[3][5].
  • 측정: 기동 노물리시험(HZP)에서 Tavg를 조금 바꿔 ITC를 재고 MTC = ITC − FTC(계산값)로 구합니다. 주기말 근처에서 감시 측정으로 하한 만족을 확인합니다.
  • LCO 3.4.2(최소임계온도): Westinghouse형은 Tavg, CE형·APR1400은 Tcold 기준이며 값은 기술지침서 본문에 둡니다(APR1400 DC 예: Tcold ≥ 548 °F, 553 °F 미만이면 감시 강화)[7].
  • 국내: 「원자로시설 등의 기술기준에 관한 규칙」 제18조(원자로의 고유보호)가 GDC 11과 같은 요건을 둡니다[10]. 운영기술지침서에 MTC·최소임계온도 LCO가 있고 수치는 COLR에 있습니다.
  • IAEA: SSR-2/1(Rev.1, 2016) 노심 설계 요건, SSG-52(2019) 반응도계수 평가[9].
  • 출제 당시 대비: 2001년 제63회 당시 STS Rev.2에서 현행 Rev.5(2021)로 바뀌었지만 MTC 개념과 LCO 구조는 같습니다.

답안용 요약

[10점 답안 예시] 가압경수로 BOC 감속재온도계수가 양이 될 수 있는 이유

  1. 정의: α_M = ∂ρ/∂T_M, 감속재 온도 1도당 반응도 변화(pcm/°C)임
  2. 주 메커니즘: 온도↑ → 물 밀도↓(순수 온도 효과는 작음)
  3. 음의 효과: 감속 능력↓ → p↓, 확산거리↑ → 누설↑
  4. 양의 효과: 물·용해 붕소 흡수↓ → f↑, 붕소 농도에 비례
  5. 설계: 무붕소 기준 과소감속 설계로 출력운전 영역 음의 MTC 확보
  6. BOC 양 가능 이유: 잉여반응도가 커 붕소 농도 최대 → k∞ 최대점이 왼쪽 이동 → 설계점이 과다감속 쪽
  7. 저온·저출력: 물 열팽창이 작아 덜 음 → 최소임계온도 제한
  8. 대책: 가연성 흡수체로 붕소 농도 제한, COLR 상한·HZP 측정, 상한 초과 시 제어봉 인출 제한
  9. EOC: 붕소 희석으로 가장 음 → 냉각 사건(MSLB) 해석에 보수적

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

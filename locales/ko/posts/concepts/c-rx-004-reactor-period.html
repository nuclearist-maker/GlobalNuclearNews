한 줄 정의

원자로 주기 T는 중성자 밀도(출력)가 e배(약 2.718배) 되는 데 걸리는 시간이며, T = P/(dP/dt)로 정의합니다. 출력은 P(t) = P₀·e^(t/T)로 변하고, 양의 주기는 증가, 음의 주기는 감소, T = ∞는 임계 상태입니다.

답안 첫 줄에는 "출력이 e배 변하는 시간으로, 계단 반응도 투입 후 과도가 끝난 뒤의 안정주기는 역시간방정식으로 반응도와 연결됨"이라고 쓰면 정의와 계산 근거가 함께 들어갑니다.

원리와 메커니즘

즉발중성자만 있다면: T = ℓp/(k−1)

무한 균질로에서 지발중성자를 무시하면 한 세대(즉발중성자 수명 ℓp) 동안 중성자가 (k−1)n만큼 늘어납니다. dn/dt = (k−1)n/ℓp이므로 n(t) = n₀·e^((k−1)t/ℓp), 곧 T = ℓp/(k−1) 입니다[2]. 제73회 2교시 2번이 이 유도를 그대로 물었습니다. 경수로 ℓp ≈ 2×10⁻⁵ s에 k−1 = 0.002를 넣으면 T ≈ 0.01 s가 되어 1초에 출력이 e¹⁰⁰배가 됩니다. 실제 원자로가 이렇게 움직이지 않는 이유가 지발중성자입니다.

지발중성자를 넣으면: 역시간방정식과 1군 근사

지발중성자를 포함한 점동특성 방정식에 n ∝ e^(ωt)를 넣으면 역시간방정식 ρ = ωΛ + Σβᵢω/(ω+λᵢ)가 나옵니다(ω = 1/T)[1][2]. 이 식은 7개의 근을 가지며, 양의 반응도에서는 양의 근 하나(ω₁)만 남고 나머지 6개는 음수라 시간이 지나면 사라집니다.

계산 문항에서는 1군 근사를 주로 씁니다.

  • 1군 역시간방정식: ρ = ℓp/T + β/(1+λT)
  • Λ를 무시하고 0 < ρ < β이면: T ≈ (β−ρ)/(λρ)
  • ρ > β(즉발초임계)이면: T ≈ Λ/(ρ−β) (ms 수준)

2021년 3교시 6번 조건(ρ = 0.002, β = 0.0065, λ = 0.08 s⁻¹, ℓp = 2×10⁻⁵ s)을 넣으면 지발 고려 T ≈ 0.0045/(0.08×0.002) = 28.1 s, 지발 무시 T = 2×10⁻⁵/0.002 = 0.010 s입니다. 같은 반응도에서 주기가 약 2,800배 길어집니다.

즉발도약 뒤에 오는 안정주기

계단 반응도를 넣으면 출력은 먼저 즉발중성자만으로 수십 ms 안에 약 β/(β−ρ)배로 뛰고, 선행핵 농도가 따라오는 과도를 거친 뒤 일정한 기울기로 갑니다. 주기는 과도 중에도 순간값 P/(dP/dt)로 정의되지만 시간에 따라 변합니다. 과도항이 사라지고 남는 단일 지수항의 주기가 안정주기이고, 계측기가 일정하게 보여 주는 값도 이것입니다. 아래 그림은 6군 점동특성 방정식을 직접 적분한 결과입니다(초기 임계·선행핵 평형, 궤환 없음). ρ = +0.001에서는 출력이 약 1.18배로 즉발도약한 뒤 약 60초부터 T ≈ 55 s의 직선이 됩니다.

음의 방향은 다릅니다. ρ = −0.05(약 −7.7$)를 넣으면 출력은 약 0.115배로 즉발강하한 뒤 순간 주기가 −29 s → −51 s → −77 s로 수백 초에 걸쳐 점점 길어지며 약 −80 s의 안정주기에 다가갑니다. 짧은 수명 선행핵은 금방 붕괴해 사라지고, 끝까지 남는 1군 선행핵(Br-87, λ₁ = 0.0124 s⁻¹)의 평균수명 1/λ₁ ≈ 80 s가 출력 감소 속도를 묶기 때문입니다[1]. 음의 반응도를 더 크게 넣어도 즉발강하 폭만 커질 뿐 안정주기의 크기는 80 s보다 짧아지지 않습니다(역시간방정식에서 음의 안정근은 −λ₁보다 0에 가깝습니다). 2023년 3교시 6번(ω = 1/80 s⁻¹)이 이 성질을 씁니다.

주기와 기동률의 관계

기동률 SUR(startup rate)은 출력이 1분에 몇 decade(10배수) 변하는지를 나타내며 단위는 dpm(decades per minute)입니다. P = P₀·10^(SUR·t)(t는 분)와 P = P₀·e^(t/T)(t는 초)를 같다고 놓으면 SUR·ln10 = 60/T이므로

SUR(dpm) = 60/(T·ln10) = 26.06/T(s)

입니다. 1 dpm은 T = 26 s, −80 s는 −0.33 dpm에 해당합니다. 출력이 2배 되는 배가시간은 Td = T·ln2 = 0.693T입니다. 로그 출력 기록계에서는 직선의 기울기가 곧 기동률이어서, 운전원은 주기보다 기동률을 직접 읽습니다.

원전에서의 의미

  • 기동(임계 접근 이후): 임계를 넘긴 뒤 제어봉 인출로 소량의 양의 반응도를 넣어 출력을 decade 단위로 올립니다. 기동률은 절차서가 정한 범위 안에서 관리합니다. 저출력에서는 온도 궤환이 거의 없어 주기가 투입 반응도로만 정해지므로, 반응도 투입률이 가장 민감한 변수입니다.
  • 온도 궤환과 주기 증가: 가열점(point of adding heat)을 넘어 출력이 오르면 연료 온도(도플러)와 감속재 온도(음의 MTC) 궤환이 반응도를 깎아 주기가 길어지고 결국 T = ∞(새 평형)로 갑니다. 2012년 3교시 6번 "출력 증가에 따라 기동률이 어떻게 변하는가"의 답이 이것입니다.
  • 정지 후 출력 감소: 원자로 정지 직후 즉발강하로 출력이 수 % 수준으로 떨어진 뒤 약 −80 s 주기(−1/3 dpm)로 줄어듭니다. 10% 반응도 정지라면 즉발강하 후 약 6.7%에서 출발해 10⁻⁶ 수준까지 내려가는 데 약 15분이 걸립니다. 정지 직후 기동률계가 약 −1/3 dpm으로 안정되는지를 보는 것이 정지 확인의 한 지표가 됩니다. 붕괴열은 별도 성분입니다.
  • 보호계통 관점: 미임계·저출력 기동 중 제어봉 비정상 인출(SRP 15.4.1)은 짧은 주기로 출력이 급증하는 사건입니다. 저출력 영역의 중성자속 트립(국내 CE형 설계의 고로그출력 트립 등)이 이 출력 급증을 끊습니다.

규제·기준 근거

  • 10 CFR 50 부록 A: GDC 20(보호계통 기능), GDC 25(반응도 제어계통 단일 오작동 시 SAFDL 보호), GDC 28(반응도 한계)[4].
  • NUREG-0800 SRP 15.4.1: 미임계 또는 저출력 기동 조건에서의 제어봉 집합체 비정상 인출. 반응도 투입률, 출력 급증, 트립 시점과 연료 판단기준을 심사합니다[5].
  • 운전원 시험 기준: 미국 NRC 운전원 일반기초시험 공식표가 SUR = 26.06/τ, P = P₀·10^(SUR·t)를 표준식으로 제시합니다[3].
  • 국내: 「원자로시설 등의 기술기준에 관한 규칙」 제26조(원자로보호계통)·제28조(반응도제어계통)와 발전소별 운영기술지침서(기동 중 노외 중성자 계측 운전 요건), KINS 안전심사지침 15.4.1이 같은 구조를 따릅니다[8].
  • IAEA: SSR-2/1(Rev.1, 2016)과 SSG-52(2019)가 반응도 제어·보호계통 설계 요건을 다룹니다[7].
  • 출제 당시 대비 변경: 주기의 물리와 식은 바뀐 것이 없습니다. 반응도 사고의 연료 판단기준만 RG 1.77(1974)에서 RG 1.236(2020)으로 대체되었습니다[6].

답안용 요약

[10점 답안 예시] 원자로 주기의 정의와 특성

  1. 정의: 중성자 밀도(출력)가 e배 되는 시간, T = P/(dP/dt), P = P₀e^(t/T)
  2. 부호: T > 0 출력 증가, T < 0 감소, T = ∞ 임계
  3. 즉발만: T = ℓp/(k−1) ≈ 0.01 s(ℓp 2×10⁻⁵ s, ρ 0.002) → 제어 불가
  4. 지발 포함: 역시간방정식 ρ = ωΛ + Σβᵢω/(ω+λᵢ)의 양의 근, 1군 T ≈ (β−ρ)/(λρ) ≈ 28 s
  5. 안정주기: 계단 투입 → 즉발도약 β/(β−ρ) → 과도 → 단일 지수(안정주기)
  6. 즉발초임계: ρ > β이면 T ≈ Λ/(ρ−β), ms 수준
  7. 음의 안정주기: 큰 음의 ρ에서도 장시간 안정주기는 약 −80 s보다 짧아지지 않음(1군 선행핵 1/λ₁, 즉발강하 중 순간값은 별개)
  8. 기동률: SUR(dpm) = 26.06/T, 배가시간 0.693T
  9. 운전: 기동 중 기동률을 절차서 범위로 관리, 출력 상승 시 온도 궤환으로 주기 증가
  10. 안전: 제어봉 비정상 인출(SRP 15.4.1) 시 짧은 주기 → 저출력 영역 트립으로 보호

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

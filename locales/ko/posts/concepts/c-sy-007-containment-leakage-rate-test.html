한 줄 정의

격납건물 누설률시험(기밀시험)은 설계기준사고 때 계산된 최대압력(기준시험압력 Pa)에서 격납건물이 새는 양을 측정해, 운영기술지침서의 허용누설률(La) 안에 여유를 두고 있는지 확인하는 시험입니다. 건물 전체를 가압하는 종합 누설률시험(ILRT, Type A)과 관통부·격리밸브를 따로 가압하는 국부 누설률시험(LLRT, Type B·C)으로 나눕니다.

격납건물은 다중방벽의 마지막 방벽입니다. 이 시험은 그 방벽의 "새는 정도"를 숫자로 보증하는 절차이고, 그 숫자 La는 사고 선량해석의 입력값이기도 합니다.

원리와 메커니즘

Pa와 La — 두 기준값

  • Pa(기준시험압력): 설계기준사고(LOCA·MSLB) 조건에서 계산된 격납건물 최대압력입니다. 설계압력이 아닙니다. 예를 들어 APR1400 미국 설계인증(DC)은 Pa 51.09 psig(약 0.352 MPa(g)), 설계압력 60 psig(0.414 MPa(g), 절대 약 0.515 MPa)입니다[5].
  • La(허용누설률): Pa에서 허용되는 최대 누설률로, **격납건물 내 공기 질량의 %/day(wt%/day)**로 씁니다. 부피 기준이 아닙니다. APR1400은 0.1 %/day입니다[5].

Type A·B·C — 어느 누설 경계를 검증하는가

구분 국내 고시 명칭 검증하는 누설 경계 시험압력
Type A 종합 누설률시험 격납건물 전체(격리 상태) 설계압력 이하, 시험 중 Pa의 96 % 이상 유지[1]
Type B 관통부 누설률시험 전기관통부 밀봉, 에어록(몸체 가압·문 씰), 핵연료이송관·장비반입구 개스킷 Pa 이상 1.1 Pa 이하
Type C 격리밸브 누설률시험 격리밸브 시트(내측·외측 밸브 사이 공간 가압이 대표 구성) Pa 이상 1.1 Pa 이하

Type A는 B·C 경로를 포함한 "전체"를 한 번에 보지만, 어디서 새는지는 알려주지 않습니다. 그래서 정비 때마다 개별 경로를 B·C로 찾아 보수하고, 몇 년에 한 번 A로 전체를 확인합니다. 국부 시험에서 격리밸브는 격리가 필요한 방향으로 가압하고, 미리 조정하지 않은 정상 닫힘 상태 그대로 시험합니다(보수전 값 확보).

절대법과 질량점법

Type A는 절대법으로 측정합니다. 격납건물을 가압·격리해 안정시킨 뒤 일정 간격으로 절대압력 P, 이슬점에서 구한 수증기 분압 Pv, 부피가중 평균 절대온도 T를 측정해 건공기 질량을 구합니다. 실제로는 구획별 온도·이슬점 센서 수십 개의 측정값을 구획 체적에 반영해 건공기 질량을 산정합니다.

  • W = (P − Pv)·V / (R·T) — V는 자유체적, R은 건공기 기체상수
  • 질량점법: 측정점 (tᵢ, Wᵢ)를 최소제곱 직선 W = A + B·t에 맞추고, L(%/day) = −2400·B/A(t는 시간 단위)로 누설률을 구합니다. 판정에는 95 % 상한신뢰한계(UCL)를 씁니다(ANSI/ANS-56.8)[4].
  • 국내 고시는 내부 대기가 안정된 뒤 측정을 시작해 24시간 이상의 안정적 추이 자료로 계산하도록 합니다. 이어서 알려진 양의 인위 누설을 더한 확인시험(최소 4시간 자료)으로 측정계의 응답이 맞는지 봅니다. 오차는 0.25 La 이하여야 합니다[1].

원전에서의 의미

허용기준 — 왜 0.75와 0.60인가

구분 국내 고시 제2018-5호 미국 App.J Option A Option B 프로그램(T/S 5.5.x)
Type A 종합 누설률 ≤ 0.75 La[1] Lam < 0.75 La[2] as-found < 1.0 La(성능기준), 복귀 전 as-left < 0.75 La(T/S 프로그램)
Type B+C 합 최대경로 합 ≤ 0.60 La[1] < 0.60 La[2] 복귀 전 최대경로 합 < 0.60 La

0.75는 다음 시험까지 생길 열화에 25 %의 여유를 남기는 값입니다. 0.60은 B·C 경로에 La의 60 %만 배정해 콘크리트·라이너 등 나머지 경로와 열화 여유를 남깁니다. 최대경로 누설률은 한 경로의 두 격리방벽 중 큰 값이며, 이를 경로별로 합산합니다(모든 밸브 중 최댓값이나 두 방벽 값의 합이 아님). 단일고장으로 성능이 좋은 쪽 방벽을 잃어도 기준이 성립하도록 보수적으로 합산하는 것입니다. 실제 새는 양(작은 값)은 미국 실무에서 최소경로 누설률로 따로 기록합니다.

국내 실적 예로, 신고리 4호기(현 새울 2호기) 운영허가(원안위 제96회, 2019)에서는 기준 0.075 wt%/24 h(= 0.75 La) 대비 0.0328 wt%/24 h(약 0.33 La)였습니다[6]. 같은 안건에서 구조건전성시험은 설계압력의 115 %로 따로 수행했습니다.

운영기술지침서와 선량해석

  • 격납건물 LCO(STS 3.6.1)는 누설률시험 프로그램(T/S 5.5.x)의 시험을 점검요건으로 삼습니다. as-found가 1.0 La를 넘으면 격납건물 불능으로 보고, 1시간 안에 복구하지 못하면 6시간 내 모드 3, 36시간 내 모드 5로 갑니다[7].
  • La는 사고 방사선 영향평가의 누설 입력값입니다. PWR은 처음 24시간 La로, 이후 0.5 La로 누설한다고 가정합니다(RG 1.183)[8]. 방출량이 La에 비례하므로, 시험으로 La를 지키는 것은 제한구역 경계(EAB) 2시간 250 mSv 같은 위치제한 선량 판단의 전제를 지키는 일입니다.

답안용 요약

  1. 정의: 격납건물 기밀성능 확인용 누설률 측정시험(고시 제2018-5호)
  2. Pa: 설계기준사고 시 계산된 격납건물 최대압력(설계압력 아님)
  3. La: Pa에서의 누설률 제한치, 공기 질량 %/day, T/S에서 정함(APR1400 0.1 %/day)
  4. 종합(Type A): 격납건물 전체, Pa의 96 % 이상 유지·안정 후 24 h 이상, 절대법·질량점법 L = −2400·B/A, ≤ 0.75 La, 확인시험 오차 ≤ 0.25 La
  5. 국부(Type B): 전기관통부·에어록·이송관 / Type C: 격리밸브, 시험압력 Pa~1.1 Pa
  6. 국부 기준: 최대경로 누설률 합 ≤ 0.60 La, 개별 관통부 기준치
  7. 주기: 사용전 → 3년 → 5년 → 인정 시 10년(국내), 미국 Option B 최대 15년
  8. 의미: La = 사고 선량해석 누설 입력, 제23조 누설밀봉 방호벽 입증

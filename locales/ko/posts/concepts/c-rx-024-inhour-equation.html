한 줄 정의

**역시간 방정식(inhour equation)**은 점동특성 방정식에 지수해 n ∝ e^(ωt)를 넣어 얻는, 투입 반응도 ρ와 역주기 ω = 1/T의 관계식 **ρ = ωΛ + Σβᵢω/(ω+λᵢ)**입니다. 6군이면 ω에 대한 7차식이 되어 근이 7개 나오고, 양의 반응도에서는 양의 근 하나 ω₁이 남아 안정주기 T = 1/ω₁을 정합니다.

답안 첫 줄은 "점동특성 방정식의 지수해 조건에서 얻은 반응도–역주기 관계식, 최대 근이 안정주기를 결정함"이면 충분합니다.

원리와 메커니즘

점동특성 방정식에서 바로 나옵니다

궤환이 없고 반응도가 일정한 점동특성 방정식은 다음과 같습니다.

  • dn/dt = [(ρ−β)/Λ]n + Σλᵢcᵢ
  • dcᵢ/dt = (βᵢ/Λ)n − λᵢcᵢ (i = 1~6)

n = n̂e^(ωt), cᵢ = ĉᵢe^(ωt)로 놓으면 둘째 식에서 ĉᵢ = βᵢn̂/[Λ(ω+λᵢ)]가 되고, 이를 첫째 식에 넣어 β − Σλᵢβᵢ/(ω+λᵢ) = Σβᵢω/(ω+λᵢ)로 정리하면 역시간 방정식이 됩니다[1][2]. 점동특성 가정 안에서는 근사가 아닌 정확식입니다. 즉발중성자 수명 ℓp로 쓰는 교재(Lamarsh)는 ρ = ωℓp/(1+ωℓp) + [1/(1+ωℓp)]Σβᵢω/(ω+λᵢ) 형태이고, Λ = ℓp/k와 ρ = (k−1)/k를 넣으면 같은 식입니다. 주기로 쓰면 ρ ≈ ℓp/T + Σβᵢ/(1+λᵢT)입니다.

작은 ω에서는 지발 항 Σβᵢω/λᵢ가 커서 반응도 대부분을 "흡수"하므로 주기가 길어집니다.

근은 7개, 살아남는 것은 하나

분모를 모두 곱하면 ω의 7차 다항식입니다. ρ(ω)는 ω = −λᵢ에서 끊어진 7개 가지로 이루어지고, 도함수 dρ/dω = Λ + Σβᵢλᵢ/(ω+λᵢ)²가 항상 양수라 각 가지에서 단조증가합니다. 각 가지의 양 끝이 −∞와 +∞로 가므로 수평선 ρ = ρ₀는 가지마다 정확히 한 번 만나고, 근 7개가 모두 실수로 확보됩니다. 근의 순서는 ω₇ < −λ₆ < ω₆ < … < ω₂ < −λ₁ < ω₁입니다.

  • ρ > 0: ω₁만 양수이고 나머지 6개는 음수입니다. 해 n(t)/n₀ = ΣAⱼe^(ωⱼt)에서 음의 항이 감쇠하므로 장시간에는 n(t) ≈ A₁e^(ω₁t)가 되고 T = 1/ω₁이 안정주기입니다.
  • ρ < 0: 7개 모두 음수이고 ω₁은 −λ₁과 0 사이에 있습니다. 그래서 음의 안정주기는 T₁ < −80.6 s, 곧 |T₁| > 1/λ₁ = 80.6 s입니다(ρ = −0.01 → −82.6 s, −0.1 → −80.8 s). 외부 중성자원이 없는 일정 반응도에서 장시간 지배 모드에 대한 성질이며, 정지 직후 즉발강하 속도를 제한하는 것은 아닙니다.
  • 가장 왼쪽 근 ω₇: |ω₇| ≫ λ₆이면 ω₇ ≈ −(β−ρ)/Λ로 수 ms에 끝나는 즉발 과도항이며 즉발도약·즉발강하를 만듭니다.

2021년 3교시 6번 계산

ρ = 0.002, β = 0.0065, λ = 0.08 s⁻¹, ℓp = 2×10⁻⁵ s입니다.

  • 1군 식 ℓpω² + (ℓpλ + β − ρ)ω − ρλ = 0 → ω₁ = 0.03554 s⁻¹, T = 28.1 s(Λ 무시 근사 (β−ρ)/(λρ) = 28.1 s와 일치), 다른 근 −225 s⁻¹은 4.4 ms 즉발 과도
  • 지발 미고려: T = ℓp/ρ = 0.010 s, 약 2,800배 차이
  • 참고로 6군 Keepin 상수로는 17.3 s입니다.

2008년 4교시 5번 계산

원본 수식 개체로 복원한 조건은 ℓp = 1.0×10⁻⁴ s, β = 0.006, λ = 0.0125 s⁻¹이고, 그래프는 A(0~5분) 일정 → B(5~10분) 1,000배 상승 → C(10~15분) 일정 → D(15~25분) 1/1,000로 감소입니다.

  • A·C: T = ∞, ρ = 0, k_eff = 1
  • B: T = 300/ln1000 = 43.4 s → ρ = ℓp/T + β/(1+λT) = 0.00389, k_eff = 1/(1−ρ) = 1.0039
  • D: T = −600/ln1000 = −86.9 s → 1 + λT = −0.086 → ρ = −0.070, k_eff = 0.935

D의 반응도가 β의 12배로 크게 나오는 것은 1군 식이 T = −1/λ = −80 s에서 발산하기 때문입니다. 같은 주기를 6군으로 풀면 B 약 0.0012, D 약 −0.0039가 되므로, 답안에는 문제 조건대로 계산하고 "1군 λ 선택에 민감"을 한 줄 덧붙이면 좋습니다.

"인아워"라는 이름

inhour는 inverse hour의 줄임말입니다. 초기 원자로 시절 ω를 h⁻¹로 표기했고, 안정주기를 1시간(3,600 s)으로 만드는 반응도를 1 inhour로 정의했습니다[2][3]. 이 노트의 상수로 계산하면 ρ(ω = 1/3600) = 2.33×10⁻⁵, 곧 **약 2.3 pcm(0.36 ¢)**입니다. 지금 국내 PWR 문서는 pcm·$·%Δk/k를 주로 쓰고 inhour 단위는 거의 쓰지 않지만, 방정식 이름으로 남았습니다. 비교 감각으로 1 dpm(T = 26 s)은 약 160 pcm, T = 60 s는 약 94 pcm입니다.

원전에서의 의미

  • 반응도 측정의 원리: 양주기법은 제어봉을 조금 인출해 안정주기(또는 배가시간)를 재고 역시간 곡선으로 반응도로 바꿔 제어봉 반응도가를 교정합니다. 반응도계(reactivity computer)는 점동특성을 거꾸로 푸는 역동특성 방식이며, 정상 지수 상승 구간에서는 역시간 방정식과 같은 값을 줍니다.
  • 영출력 노물리 시험: 재장전 후 반응도계로 임계붕소농도, 등온온도계수, 제어봉 반응도가를 측정해 설계값과 비교합니다. 반응도계의 βeff·Λ·λᵢ는 노심 설계가 주기별로 제공합니다.
  • 안전해석: 제어봉 인출·이탈 해석은 점동특성에서 출발합니다. 1$ 이상에서는 즉발 항 ωΛ가 지배해 Λ가 핵심 인자가 됩니다.

답안용 요약

[10점 답안 예시] 역시간 방정식(Inhour Equation)과 인자의 의미

  1. 정의: 점동특성 방정식에 n ∝ e^(ωt) 대입해 얻은 반응도–역주기 관계식
  2. 식: ρ = ωΛ + Σβᵢω/(ω+λᵢ), ω = 1/T (ℓp 형: ρ ≈ ℓp/T + Σβᵢ/(1+λᵢT))
  3. 인자: Λ 즉발중성자 세대시간, βᵢ 군별 지발 분율, λᵢ 선행핵 붕괴상수, ρ 투입 반응도
  4. 근: 6군 → 7차식, 근 7개, 점근선 ω = −λᵢ
  5. ρ > 0: 양의 근 1개 → 안정주기 T = 1/ω₁, 나머지 6개 음수(감쇠)
  6. ρ < 0: 근 모두 음수, |T| > 1/λ₁ ≈ 80 s(장시간 지배 모드)
  7. 즉발 과도항: ω₇ ≈ −(β−ρ)/Λ, 즉발도약·강하
  8. 근사: 1군 T ≈ (β−ρ)/(λρ), 즉발초임계 T ≈ Λ/(ρ−β)
  9. 예: ρ = 0.001 → 6군 T = 55 s, 즉발만 0.02 s
  10. 인아워: 안정주기 1시간 반응도 = 1 inhour(약 2.3 pcm), 양주기법·반응도계의 근거

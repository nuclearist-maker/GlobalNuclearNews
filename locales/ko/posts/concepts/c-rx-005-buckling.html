한 줄 정의

**버클링(B²)**은 1군 확산방정식을 ∇²φ + B²φ = 0 꼴로 썼을 때의 상수로, 중성자속 분포의 상대 곡률(−∇²φ/φ)입니다. 재료 조성만으로 정해지는 값이 재료(물질) 버클링 B_m² = (k∞ − 1)/L²(수정 1군은 M²)이고, 노심 형상·치수와 경계조건으로 정해지는 값이 기하학적 버클링 B_g²입니다. 둘이 같을 때 노심은 임계입니다[1][2].

답안 첫 줄은 "중성자속의 곡률을 나타내는 확산방정식의 고유값으로, 재료가 허용하는 B_m²와 형상이 요구하는 B_g²가 같으면 임계임"이라고 쓰면 정의와 임계조건이 함께 들어갑니다. 구조역학의 좌굴(buckling)과는 이름만 같습니다.

원리와 메커니즘

두 관점 — 물리(재료)와 수학(형상)

D∇²φ − Σaφ + (1/k)·νΣfφ = 0

  • 물리적 관점(재료 버클링): 임계(k = 1)에서 정리하면 ∇²φ + [(νΣf − Σa)/D]φ = 0입니다. 대괄호가 B_m²이고, k∞ = νΣf/Σa, L² = D/Σa를 쓰면 B_m² = (k∞ − 1)/L²입니다. 단위 체적의 순생성(νΣf − Σa)φ가 누설 −D∇²φ로 정확히 빠져나가려면 중성자속이 이만큼 휘어야 한다는 뜻입니다. 재료가 "감당할 수 있는 곡률"이라고 보면 됩니다[1].
  • 수학적 관점(기하학적 버클링): 같은 식은 경계(외삽 경계)에서 φ = 0을 만족해야 합니다. 이 조건을 만족하는 해는 B²가 특정 고유값일 때만 존재하고, 전 영역에서 φ > 0인 기본 모드가 최소 고유값 B_g²입니다. 형상이 "요구하는 곡률"이며 재료와 무관합니다.

판정은 간단합니다. B_m² = B_g²이면 임계, B_m² > B_g²이면 초임계, B_m² < B_g²이면 미임계입니다. k∞ < 1이면 B_m² < 0이므로 어떤 크기로도 임계가 되지 않습니다.

keff·비누설확률과의 관계

임계가 아닐 때는 1/k를 남겨 풀면 keff = k∞/(1 + L²B_g²)입니다. 열 비누설확률 P_TNL = 1/(1 + L²B_g²)가 그대로 보입니다[1]. 고속군까지 넣으면 다음과 같습니다.

  • 수정 1군: keff ≈ k∞/(1 + M²B_g²), M² = L² + τ
  • 나이-확산: keff = k∞·e^(−τB_g²)/(1 + L²B_g²), 고속 비누설확률 P_FNL = e^(−τB_g²)(2군 근사 1/(1 + τB_g²))

노심이 커질수록 B_g²가 작아져 두 비누설확률이 1에 가까워집니다(2015년 1교시 9번의 답). 페르미 연령 τ는 고속중성자가 열에너지까지 감속되는 동안 이동한 평균 제곱거리의 1/6입니다. Lamarsh 표 기준 경수 τ ≈ 27 cm², L² = 8.1 cm²이고, 중수 131 cm²·9.4×10³ cm², 흑연 368 cm²·3,500 cm²입니다[1]. 경수로에서는 τ가 L²보다 커서 고속 누설을 빼고 1군으로만 계산하면 크게 틀립니다.

형상별 기하학적 버클링

치수는 외삽 경계 기준입니다. 외삽거리 d ≈ 0.71λ_tr = 2.13D이며 대형로에서는 무시해도 됩니다[1][2].

형상 B_g² 중성자속 분포 φmax/φavg
평판(두께 a) (π/a)² A cos(πx/a) 1.57
직육면체 a×b×c (π/a)² + (π/b)² + (π/c)² cos·cos·cos 3.88
유한 원통(R, H) (2.405/R)² + (π/H)² A J₀(2.405r/R)cos(πz/H) 3.64
구(반경 R) (π/R)² A sin(πr/R)/r 3.29

2.405는 J₀의 첫 영점입니다. 평판(2002년 3교시 3번)은 대칭조건 φ(−x) = φ(x)로 sin 항이 빠지고, φ(X₀/2) = 0에서 B = π/X₀, φ = A cos(πx/X₀)가 됩니다. 구(2004년 4교시 2번)는 출력 P = E_RΣf∫φdV로 규격화하면 φ(r) = [P/(4R²E_RΣf)]·sin(πr/R)/r입니다.

같은 B_m²에서 체적이 가장 작은 형상은 구(V ≈ 130/B³)이고, 최적 원통은 H ≈ 1.85R(H/D ≈ 0.92)일 때 V ≈ 148/B³, 정육면체는 161/B³입니다. Lamarsh 예제는 최적 원통을 H = 1.82R로 반올림해 씁니다[1]. 표면적 대비 체적이 클수록 누설이 줄어 임계질량이 작아집니다.

임계반경·임계질량 계산 절차

계산형 기출은 모두 같은 4단계입니다. ① 조성 → k∞, L²(M²) ② B_m² = (k∞ − 1)/M² ③ 형상식 B_g²(치수) = B_m²로 치수 ④ 체적 × 연료 분율 × 밀도 = 질량.

예 1 — 원통형 균질로 임계반경(2011년 4교시 3번): 원문의 누락 기호를 원본에서 복원하면 ε = P_f = p = 1, ν = 2.43, σa^H₂O = 0.664 b, σa^UO₂ = 23 b, σf²³⁵ = 580 b, L_th² = 8.1 cm²입니다.

  • f = 4×23/(4×23 + 100×0.664) = 0.581
  • η = 2.43×(0.03×580)/23 = 1.838 → k∞ = ηf = 1.068
  • 균질 혼합물 L² = L_M²(1 − f) = 8.1×0.419 = 3.40 cm²
  • B_m² = 0.0677/3.40 = 0.0199 cm⁻²
  • H = R/0.55이므로 B_g² = [2.405² + (0.55π)²]/R² = 8.770/R² → R ≈ 21.0 cm(H ≈ 38.1 cm)

문제가 P_f = 1로 고속 누설을 없앴기 때문에 나온 값입니다. 실제 경수 감속이라면 M² = 3.40 + 27 ≈ 30 cm²로 R ≈ 63 cm가 됩니다. 답안에 이 차이를 한 줄 적으면 변별력이 생깁니다.

예 2 — 중수로 임계 천연우라늄 질량(2009년 4교시 4번): 원문에서 빠진 기호는 "B_m² = 8.6 m⁻²"입니다.

  • B_m² = 8.6×10⁻⁴ cm⁻², H = 2.4R → B_g² = [2.405² + (π/2.4)²]/R² = 7.497/R²
  • R = 93.4 cm, H = 224 cm, V = πR²H = 6.14×10⁶ cm³
  • 연료 체적분율 = π(1.27)²/(15.2)² = 0.0219 → 연료 1.35×10⁵ cm³
  • 질량 = 19 g/cm³ × 1.35×10⁵ cm³ ≈ 2.56 t(외삽거리 무시, 연료봉 전 높이 가정)

원전에서의 의미

  • 설계: 대형 PWR 노심은 B_g²가 작아 누설이 몇 % 수준입니다. k∞ 여유(잉여반응도)는 붕소·제어봉·가연성 독봉으로 상쇄합니다. 노심 B_g²는 고정이므로, 운전 중 반응도 변화는 감속재 온도·붕소 농도에 따른 B_m²(k∞, M²) 변화로 읽을 수 있습니다.
  • 출력분포: 무반사 원통의 φmax/φavg = 3.64는 첨두계수의 출발점입니다. 실제 노심은 반사체(반사체 절약 δ만큼 임계치수 감소), 저누설 장전모형, 가연성 독봉으로 분포를 평탄화합니다.
  • 임계안전: 연료 저장·취급에서는 B_g²를 크게 만들어(얇은 평판, 가는 원통, 랙 간격 유지) keff < 1을 확보합니다. 이것이 "기하학적 안전(geometry control)"이며, 저장대 피치와 중성자 흡수판 설계의 물리적 근거입니다.

규제·기준 근거

  • 10 CFR 50.68(1998 신설): 신연료 저장 keff ≤ 0.95(무붕산수 침수), 최적감속 시 ≤ 0.98, 사용후연료 저장 keff ≤ 0.95(붕산 효과 인정 시 무붕산수 < 1.0), 95/95 기준입니다[3].
  • GDC 62: 연료 저장·취급 중 임계를 우선 기하학적으로 안전한 배치로 방지하도록 요구합니다[4].
  • NUREG-0800 SRP 4.3, 9.1.1·9.1.2: 노심 임계·출력분포 계산 방법과 저장 임계 해석을 심사합니다.
  • ANSI/ANS-8.1: 구 직경·원통 직경·평판 두께 같은 단일 매개변수 미임계 한계를 둡니다.
  • IAEA SSG-27(Rev.1, 2022): 핵분열성물질 취급 임계안전 지침입니다[5]. 원자로 노심처럼 의도적으로 임계인 계통은 제외합니다. 노심 설계 요건은 SSR-2/1(Rev.1, 2016)에 있습니다.
  • 국내: 「원자로시설 등의 기술기준에 관한 규칙」의 핵연료 저장·취급 임계 방지 조항(제33조 ①1호·②1호, 운영은 제61조)이 같은 구조를 따릅니다[6].
  • 출제 당시 대비: 버클링 물리는 변화가 없습니다. IAEA SSG-27은 2014년 초판이 2022년 Rev.1로 개정됐습니다.

답안용 요약

[10점 답안 예시] 버클링(재료·기하학적)

  1. 정의: 확산방정식 ∇²φ + B²φ = 0의 상수, 중성자속 곡률 −∇²φ/φ임
  2. 재료 버클링: B_m² = (νΣf − Σa)/D = (k∞ − 1)/L²(수정 1군 M² = L² + τ), 조성만의 함수
  3. 기하학적 버클링: 외삽 경계 φ = 0을 만족하는 최소 고유값, 형상·치수만의 함수
  4. 형상별: 평판 (π/a)², 원통 (2.405/R)² + (π/H)², 구 (π/R)²
  5. 임계조건: B_m² = B_g² 임계, B_m² > B_g² 초임계, B_m² < B_g² 미임계
  6. keff: keff = k∞/(1 + M²B_g²), P_TNL = 1/(1 + L²B_g²), P_FNL = e^(−τB_g²)
  7. 임계치수: B_g²(치수) = B_m²로 결정, 같은 B_m²에서 구가 최소 체적(130/B³)
  8. 활용: 노심 크기 결정, 반사체로 임계치수 감소, 저장·취급 기하학적 안전

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

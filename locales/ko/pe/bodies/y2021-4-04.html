출처: KINS 원자력면허시험 자료실, 2021년 원자력발전기술사 필기 4교시 4번

문제

핵물질 취급, 저장 또는 운반하는 과정에서 핵임계 폭주사고가 발생하지 않도록 하기 위한 다음의 조치사항에 대하여 기술하시오. 가. 핵임계 영향을 미치는 고유매개변수(조정 불가능 인자) 나. 핵임계 방지의 기술적, 공학적, 행정적 수단 다. 핵임계 안전관리의 기하학적 구조, 질량, 농도 및 독성물질 제어 방법

출제 의도

원자로 노심의 반응도사고가 아니라, 노심 밖에서 핵분열성물질을 다룰 때의 핵임계안전(nuclear criticality safety)을 묻는 문항입니다. 임계에 영향을 주는 인자를 "물질이 정해 주는 것"과 "운영자가 제어하는 것"으로 나누고, 방지 수단의 선호 순서(수동 설계 → 능동 장치 → 행정)와 이중 우발 원칙을 함께 설명하는지가 핵심입니다. 다의 "독성물질"은 중성자 독물질, 즉 흡수체로 읽어야 합니다.

답안 구성

  • 서론: 임계사고의 정의·특징과 keff 미임계 확보의 세 갈래
  • 본론 가: 고유매개변수(물질 특성·평가 전제)와 제어 인자의 구분
  • 본론 나: 기술적(수동)·공학적(능동)·행정적 수단과 이중 우발 원칙, 완화 수단
  • 본론 다: 기하학적 구조·질량·농도·흡수체 제어 방법과 각각의 한계
  • 결론: 다중 제어 병행과 국내외 규제 근거

답안 예시

1. 개요

  • 임계사고: 노심 밖 핵분열성물질이 의도치 않게 초임계가 되어 출력이 급상승(폭주, excursion)하는 사고임
    • 짧은 고출력 펄스 후 온도·기포(용액 방사분해 가스)의 음의 되먹임으로 출력이 진동하며 지속될 수 있음
    • 주 위험은 인근 작업자의 중성자·감마 고선량 피폭이며, 시설 밖 영향은 대개 작음
  • 원리: keff = 생성 ÷ (흡수 + 누설) → 미임계 확보는 ① 생성 감소 ② 흡수 증가 ③ 누설 증가의 세 갈래뿐임
    • 1군 표현 keff = k∞/(1 + M²B²): 가늘고 얇은 형상일수록 기하 버클링 B²가 커져 누설이 늘어남

2. 가. 고유매개변수(조정 불가능 인자)

  • 문제 해석: 표준 용어가 아니므로 "해당 공정에서 물질이 정해 주는 특성, 즉 임계안전평가의 전제"로 해석함
  • 핵분열성 핵종·동위원소 조성: ²³⁵U·²³³U·²³⁹Pu·²⁴¹Pu 여부와 비율 → 단면적 σ, ν, η(중성자 에너지 의존)를 결정함
  • 화학·물리 형태: 금속·산화물·용액·분말 → 감속재 동반 여부와 원자수밀도가 달라짐
  • 밀도: 이론밀도와 분말 벌크밀도를 구분해 최악값을 가정함
  • 비균질성: 입자 크기·봉 격자 배열 → 공명흡수 자기차폐로 균질계와 반응도가 다름
  • 형태·밀도·비균질성은 공정 중 바뀔 수 있으므로(분말 → 용액, 침전 등) 그 변화 범위까지 평가 전제에 넣음
  • 농축도: 물질별로 주어진 값이지만, 시설 허가에서는 상한을 두어 제어함(경수로 연료 예 5 wt% 이하) → 양쪽에 걸침
  • 제어 인자(조정 가능): 질량·형상(기하)·농도·감속·반사·상호작용(간격)·중성자 흡수체 → 고유 인자로 최악 조건을 정한 뒤 제어 한도를 결정함

3. 나. 기술적·공학적·행정적 수단

  • 구분 해석: 기술적 = 설계에 내재된 수동 수단, 공학적 = 능동 장치, 행정적 = 사람이 지키는 한도·절차로 정리함(IAEA SSG-27 Rev.1의 "수동 공학적 → 능동 공학적 → 행정적" 선호 순서에 대응[1])
  • 기술적(수동 설계)
    • 안전형상(favorable geometry) 용기: 가는 원통·얇은 평판·환형 탱크, 작은 체적
    • 고정 흡수체: 붕소강·Boral·Metamic 판, 붕규산 유리 라시히 링
    • 고정 간격: 저장 랙 피치, 운반용기 내부 바스켓
  • 공학적(능동 장치)
    • 계량·농도 계측과 연동한 이송 인터록(한도 초과 시 이송 차단)
    • 누설·수위 감지 연동 자동 차단·격리, 비안전형상 용기로의 이송 경로 차단(감지 후 사람이 조치하면 행정적 대응으로 분류)
  • 행정적
    • 질량·배치 한도 설정과 현장 게시, 절차서·이중 확인(독립 검증)
    • 임계안전평가서와 변경관리, 교육·자격, 자체점검·감사
  • 설계 원칙 — 이중 우발 원칙(ANSI/ANS-8.1)[2]: 독립적이고 발생 가능성이 낮은 공정 조건 변화가 적어도 두 개 겹치기 전에는 임계가 불가능하도록 설계함
    • 단일 우발 A(예: 이중 배치)나 B(예: 반응도를 높이는 반사 조건 변화) 하나만으로는 미임계가 유지돼야 하며, 두 변화의 저확률·독립성과 단독 미임계는 평가로 입증함
    • A와 B가 겹쳐도 "반드시 임계"가 아니라 "임계 가능성이 생기는 조건"이라는 뜻임
  • 완화 수단(방지 실패 대비): 임계사고 경보계통(10 CFR 70.24, ANSI/ANS-8.3)[3][4], 대피 경로, 차폐

4. 다. 기하학적 구조·질량·농도·독성물질 제어 방법

  • 기하학적 구조(형상) 제어
    • 용기 지름·평판 두께·체적을 최악 조건(최적 감속·전반사·최대 농도)에서도 미임계가 되는 값 이하로 제한함
    • 유닛 간 간격을 고정해 상호작용을 줄임(랙 피치, 운반물 배열)
    • 넘침·누출 시 바닥 고임도 얇은 평판 형상이 되게 집수부를 설계하고, 일반 드럼·침전조 같은 비안전형상 용기 반입을 금지함
    • 장점: 운전원 오류에 강한 수동 수단 / 주의: 부식·변형에 의한 형상 변화 감시
  • 질량 제어
    • 배치 질량 ≤ 평가된 미임계 질량 한도(최소 임계질량에 안전여유를 두고, 이중 배치를 가정해 설정)
    • 계량·이중 확인, 계량관리 기록, 작업대·구역별 동시 반입 수 제한, 용기 표지
    • 주의: 최적 감속·반사 조건에서 정한 한도여야 함(감속·반사가 임계질량을 크게 줄임)
  • 농도 제어
    • 용액 농도를 최적 감속에서도 k∞ < 1이 되는 수준 이하로 유지하면 용기 크기와 무관하게 미임계임(균질 조성·농도 유지 전제)
    • 시료 분석·온라인 농도계로 감시
    • 주의: 증발·침전·상분리로 국부 농축이 생기므로 형상 제어와 병행함
  • 독성물질(중성자 흡수체) 제어
    • 고정 흡수체: 붕소강·Cd 판, 붕규산유리 라시히 링(ANSI/ANS-8.5), 고정 흡수체 일반(ANSI/ANS-8.21)[3]
    • 가용성 흡수체: 붕산수, 재처리 공정의 질산가돌리늄(ANSI/ANS-8.14)
    • 주의: 존재·면밀도 확인(쿠폰 시험), 열화(예: Boraflex), 희석·누락 사건을 우발로 고려함

5. 결론

  • 고유 인자로 최악 조건을 정하고, 네 가지 제어를 수동 → 능동 → 행정 순으로 겹쳐 이중 우발 원칙을 만족시켜야 함
  • 국내 근거: 기술기준규칙 제33조①1호·②1호(최적 감속조건에서도 미임계), 제61조 2호(취급·저장 중 미임계 여유도 확인), 핵연료주기시설 제90·91·99조[5], 운반은 「방사성물질등의 포장 및 운반에 관한 규정」의 핵임계 안전지수(CSI = 50/N)와 5N·2N 배열 평가[6]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 형상 제어가 왜 가장 먼저인가

fig2는 ²³⁵U와 물의 균질 용액을 반사체 없는 무한 원통에 담았다고 보고 수정 1군으로 계산한 설명용 곡선입니다. H/²³⁵U 원자수비 600(약 43.5 g/L) 용액의 모델 임계 지름은 32.7 cm이고, 더 진한 300(약 87 g/L)은 27.8 cm, 묽은 1,500(약 17.4 g/L)은 59.8 cm에서 임계가 됩니다. 이 세 농도 범위에서는 진할수록 임계 지름이 작으므로 형상 한계는 최악 농도 조건으로 평가해야 합니다. 이 값은 ANSI/ANS-8.1 한계값이 아니며, 실제 한계는 물 반사·핵종 조성·계산 편향과 불확도·안전여유를 반영한 별도 평가로 정합니다. 형상은 사람이 실수해도 유지된다는 점에서 질량·농도 한도보다 선호됩니다.

해설: 원전에서 보는 같은 원리

원전의 신연료·사용후연료 저장설비도 같은 원리입니다. 미국 10 CFR 50.68(b)는 사용후연료 랙을 무붕산수에서 keff ≤ 0.95(95/95, 붕소 크레딧 적용 시 붕산수 ≤ 0.95와 무붕산수 < 1.0), 신연료 랙을 침수 시 ≤ 0.95·최적감속 시 ≤ 0.98로 정합니다[4]. 국내 기술기준규칙 제33조②1호의 "최적 감속조건하에서도"라는 문언이 바로 신연료 랙의 안개·거품 최적감속 조건을 겨냥한 것입니다. 이 수치는 원전 저장랙 기준이며, 공정시설의 모든 임계안전 한계에 그대로 쓰는 값은 아닙니다.

해설: 사례로 보는 다중 제어 붕괴

1999년 일본 JCO 변환시설 임계사고는 승인 절차와 배치 질량 한도를 벗어나 18.8 % 농축 질산우라닐 용액 약 16 kg U를 안전형상이 아닌 침전조에 붓는 과정에서 일어났습니다. 질량·형상 제어가 동시에 무너졌고, 침전조를 둘러싼 냉각수 자켓이 반사체 역할을 했습니다[7][8]. 단일 행정 통제에 의존하면 이중 우발 원칙이 성립하지 않는다는 점을 보여 주는 사례입니다.

출처: KINS 원자력면허시험 자료실, 2024년 원자력발전기술사 필기 1교시 4번

문제

중성자 평균 세대 시간

핵심 키워드

  • 즉발중성자 수명 ℓp: 즉발중성자가 태어나 흡수·누설로 사라질 때까지의 평균 시간입니다. 열중성자로는 감속시간 + 확산시간이며 경수로는 약 2×10⁻⁵ s입니다.
  • 선행핵 평균수명 τ̄: 지발중성자 선행핵 6군의 평균수명 1/λᵢ를 분율로 가중평균한 값으로, ²³⁵U는 약 13 s입니다.
  • 평균 세대 시간 ℓ̄: 즉발·지발 경로를 가중평균한 세대 간격으로, ℓ̄ = ℓp + Σβᵢ/λᵢ = ℓp + β·τ̄입니다.
  • 세대시간 Λ: 점동특성 방정식의 즉발 생성시간 Λ = ℓp/k입니다. ℓ̄와는 다른 양입니다.
  • 원자로 주기 T: 출력이 e배가 되는 시간입니다. 작은 반응도에서는 T ≈ ℓ̄/ρ로 근사합니다.

답안 예시

1. 가정 및 문제 해석

  • 조건이 없으므로 ²³⁵U 열중성자로(PWR) 기준, β = 0.0065, Keepin 6군 데이터로 가정함 [1]
  • "평균 세대 시간"은 지발중성자를 포함한 평균(ℓ̄)으로 해석하고, 즉발 세대시간 Λ와 구분함

2. 정의

  • 즉발중성자 수명 ℓp = 감속시간 t_s + 확산시간 t_d, 경수로 약 2×10⁻⁵ s [2]
  • 평균 세대 시간 ℓ̄: 핵분열 중성자가 다음 세대 핵분열에 기여하기까지 걸리는 평균 시간을 즉발·지발 경로로 가중평균한 것
  • ℓ̄ = (1−β)·ℓp + Σβᵢ(ℓp + 1/λᵢ) = ℓp + Σβᵢ/λᵢ = ℓp + β·τ̄ [2][3]

3. 대표값(²³⁵U, PWR)

  • Σβᵢ/λᵢ = 0.0847 s(τ̄ ≈ 13.0 s) → ℓ̄ ≈ 2×10⁻⁵ + 0.0847 ≈ 0.085 s
  • ℓp의 약 4,200배: 중성자 수로는 0.65%인 지발중성자가 ℓ̄의 99.98%를 차지함
  • 최대 기여군은 2군(반감기 22.7 s, 약 55%)이며, 최장수명 1군은 약 20%임

4. 의미(운전·안전)

  • 즉발만: T = ℓp/(k−1) = 2×10⁻⁵/0.001 = 0.02 s → 1초에 e⁵⁰배, 제어 불가
  • 지발 포함: T ≈ ℓ̄/ρ ≈ 85 s(ρ = 0.001) → 제어봉·붕소로 대응 가능
  • ρ < βeff(1$)일 때만 성립 → 즉발임계 이상에서는 Λ가 주기를 결정함
  • ℓp가 노형별로 10⁻⁷ s(고속로)~10⁻³ s(중수로)로 달라도 ℓ̄는 β·τ̄ 항이 지배함 → 제어성의 근거는 β임

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설

그림은 ℓ̄ = 0.085 s를 경로별로 나눈 "시간 장부"입니다. 중성자 수로는 즉발이 99.35%지만, 시간으로는 지발 6군이 거의 전부를 채웁니다. 가장 큰 몫은 반감기가 가장 긴 1군(55.7 s)이 아니라 분율과 평균수명의 곱이 가장 큰 2군입니다.

2026년 1교시 5번처럼 조건(τ̄ = 12.5 s, 감속 10⁻⁶ s, 확산 2×10⁻⁵ s)이 주어지면 같은 식으로 ℓ̄ = 2.1×10⁻⁵ + 0.0065 × 12.5 ≈ 0.0813 s가 됩니다. 조건이 없는 2024년 문항은 정의, 식, 대표값과 그 의미를 쓰는 것이 핵심입니다.

T ≈ ℓ̄/ρ는 ρ ≪ β일 때의 단순 근사입니다. 같은 ρ = 0.001을 6군 역시간방정식[3]으로 풀면 54.9 s로, 자릿수는 같습니다.

채점 포인트와 흔한 실수

  • ℓ̄와 Λ 혼동: 점동특성식의 Λ(약 2×10⁻⁵ s) 자리에 0.085 s를 넣으면 지발 효과를 두 번 세게 됩니다. 두 양을 이름과 식으로 구분해 쓰십시오.
  • 식만 쓰고 수치 생략: 10점 단답이라도 ℓp ≈ 10⁻⁵ s와 ℓ̄ ≈ 0.1 s의 대비, 약 4,000배 증가까지 적어야 의미 배점을 받습니다.
  • "지발중성자는 0.65%라 무시 가능": 수 비율과 시간 비율은 다릅니다. 시간으로는 99.98%입니다.
  • 적용 범위 누락: T ≈ ℓ̄/ρ는 ρ ≥ β에서 성립하지 않습니다. 즉발임계 단서 한 줄이 완성도를 가릅니다.
  • τ̄를 ²³⁵U의 수명으로 오해: τ̄는 핵분열생성물 선행핵(⁸⁷Br 등)의 평균수명입니다.

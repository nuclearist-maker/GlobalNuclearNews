출처: KINS 원자력면허시험 자료실, 2025년 원자력발전기술사 필기 4교시 5번

문제

정격출력이 1,350MWe인 원자력발전소에서 1년 동안 450,000MWd의 전력을 송전망으로 보냈다. 이 기간 동안 핵연료 재장전 7일을 포함한 계획예방정비 27일, 계획되지 않은 원자로 정지가 8일이었다. 이 원자력발전소의 1년간 이용률 및 가동률을 계산하시오. (단, 가동 기간에는 모두 정격출력으로 운전한 것으로 가정한다.)

출제 의도

이용률은 전력량의 비율이고, 가동률은 시간의 비율입니다. 두 지표의 분자와 분모를 정확히 구분하는지 확인하는 문제입니다. "재장전 7일을 포함한 27일"이라는 표현을 읽고 정지일수를 중복해서 빼지 않는지도 봅니다. 또 주어진 송전량이 "가동 중 정격 운전" 단서와 약 1 % 어긋나는데, 이를 검산으로 발견하고 처리하는 능력도 변별 요소입니다.

답안 구성

  • 서론: 가정 및 문제 해석(기간 365일, 정지일수 해석, 지표 정의), 주어진 값 정리
  • 본론 1: 이용률 — 기준 전력량 → 대입 → 단위 확인
  • 본론 2: 가동률 — 운전일수 → 대입
  • 본론 3: 검산 — 정격 가정 전력량과 주어진 송전량 비교, 불일치 처리
  • 결론: 답 요약, 두 지표의 차이와 의미

답안 예시

1. 가정 및 문제 해석

  • 기간 1년 = 365일(8,760 h)로 봄(평년, 문제 미명시)
  • 계획예방정비 27일에는 재장전 7일이 이미 포함됨 → 정지 합계 27 + 8 = 35일
  • 450,000 MWd는 송전망으로 보낸 순전력량(10,800,000 MWh)으로 봄
  • 이용률 = 실제 발전량 / (정격출력 × 기간) × 100 % (IAEA PRIS Load Factor와 같은 정의)[1]
  • 가동률 = 발전(계통 병입) 시간 / 기간 역시간 × 100 % (PRIS Operating Factor)[1], 에너지 기준 가용률(EAF·UCF)과는 구분함[1]

2. 주어진 값

항목 기호 값
정격출력 P 1,350 MWe
송전 전력량 E 450,000 MWd
기간 T 365 d
계획예방정비(재장전 포함) T_PM 27 d
비계획 정지 T_U 8 d

3. 이용률

  • 기준 전력량: REG = P × T = 1,350 MW × 365 d = 492,750 MWd
  • 이용률 = E / REG = 450,000 / 492,750 = 0.9132 → 91.3 %
  • 단위 검토: MWd ÷ (MW × d) → 무차원 ✓ (MWh로 하면 10,800,000 / 11,826,000, 같은 값)

4. 가동률

  • 운전일수: T_op = 365 − 27 − 8 = 330 d
  • 가동률 = T_op / T = 330 / 365 = 0.9041 → 90.4 %
  • 주의: 27 + 7 = 34일을 빼면 323일, 88.5 %가 되어 오답

5. 검산

  • 단서대로 정격 운전이면 전력량 = 1,350 × 330 = 445,500 MWd → 이용률 = 가동률 = 90.4 %여야 함
  • 주어진 450,000 MWd와 차이 4,500 MWd(정격 3.3일분)
  • 송전량에 맞추려면 가동 중 평균 출력 = 450,000 / 330 = 1,364 MWe(정격의 101.0 %)
  • 판단: 문제 수치가 약 1 % 서로 맞지 않음. 정의대로 계산한 값을 답으로 쓰고, 불일치를 명기함

6. 결론

  • 이용률 91.3 %(전력량 기준), 가동률 90.4 %(시간 기준)
  • 단서의 정격 운전 가정을 따르면 전력량이 445,500 MWd가 되어 둘 다 90.4 %(주어진 450,000 MWd와는 맞지 않음)
  • 정격 초과 운전이 없으면 이용률 ≤ 가동률. 실제로는 승출력·주기말 감발·부하추종 때문에 이용률이 더 낮은 것이 보통임

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 같은 1년을 두 잣대로 재기

위 그림의 왼쪽은 같은 1년을 시간 막대와 전력량 막대로 나란히 그린 것입니다. 가동률은 시간 막대에서 운전 구간이 차지하는 비율이고, 이용률은 전력량 막대에서 실제 송전량이 차지하는 비율입니다. 운전 중 출력이 늘 정격이라면 두 막대의 끝은 정확히 같은 위치에 와야 합니다. 그런데 이 문제에서는 전력량 막대가 0.9 %p 더 깁니다.

오른쪽 그래프는 출력–시간 면적이 곧 전력량이라는 점을 보여 줍니다. 정지 시점은 문제에 없어서 개념적으로 배치했습니다. 파란 직사각형 세 개의 넓이 합이 445,500 MWd입니다. 주어진 450,000 MWd가 되려면 출력선이 정격 위의 1,364 MWe 점선까지 올라가야 합니다.

해설: 불일치를 어떻게 쓸까

출제자는 "가동 중 정격 운전" 단서를 감발·승출력 같은 부분 출력을 따지지 말라는 뜻으로 넣었을 가능성이 큽니다. 그렇다면 기대 답은 정의대로 구한 91.3 %와 90.4 %입니다. 이번에 python으로 독립 재계산한 값과 소수 첫째 자리까지 일치합니다.

현실에서도 이용률이 가동률보다 클 수 있습니다. 바닷물 온도가 낮은 계절에는 복수기 진공이 좋아져 순출력이 정격을 조금 넘기도 합니다. 정격·설비용량의 기준이 다를 때도 그렇습니다. 답안에 "평균 출력이 정격의 101 %여야 성립하므로 문제 수치가 약 1 % 불일치함" 한 줄을 적으면 검산 능력을 보여 줄 수 있습니다.

해설: 자주 하는 실수

  1. 재장전 7일을 27일과 별도로 다시 뺌 → 88.5 %. "포함한"이라는 표현을 놓친 경우입니다.
  2. MWd를 MWh로 착각하고 1,350 × 8,760과 나눔 → 3.8 %라는 터무니없는 값이 나옵니다. 단위를 맞추면 이런 실수는 바로 드러납니다.
  3. 가동률 분모에서 계획정지를 빼고 330 / 338 = 97.6 %로 계산함 → 이는 계획 정지를 제외한 별도의 신뢰도 지표에 가깝고, 문제가 묻는 가동률이 아닙니다.
  4. 가동률과 가용률(EAF·UCF)을 같은 말로 씀 → 가용률은 에너지 기준 지표입니다. 이 문제에서는 부분 출력 손실이 없으므로 UCF도 (365 − 35)/365 = 90.4 %로 같아집니다.

참고로 이 자료로 계산한 보조 지표는 계획 손실률 27/365 = 7.4 %, 비계획 손실률 8/365 = 2.2 %입니다. 시간 기준 강제정지율 FOR은 8/(8 + 330) = 2.4 %입니다. 출제 연도 2025년은 평년이고, 윤년(366일)으로 보더라도 이용률 91.1 %, 가동률 90.4 %로 결론은 같습니다.

출처: KINS 원자력면허시험 자료실, 2020년 원자력발전기술사 필기 4교시 3번

문제

가압중수로의 특수안전계통에 대해 다음을 설명하시오. 가. 안전기능 나. 안전계통 제1그룹 다. 안전계통 제2그룹 라. 안전보조계통

출제 의도

CANDU형 가압중수로의 안전 설계 철학을 묻는 문항입니다. 특수안전계통 4개(SDS1·SDS2·ECC·격납)를 나열하는 데서 그치지 않고, 이들을 두 그룹으로 나눠 배치한 이유, 즉 단일 사건이 정지 불능이나 "연료 손상 + 방출"을 동시에 일으키지 못하게 하는 공통원인고장 방호 논리를 설명하는지가 핵심입니다. 라는 특수안전계통을 떠받치는 전력·냉각수·공기 계통을 그룹별로 구분해 쓰는지 봅니다.

답안 구성

  • 서론: 안전관련 계통 3종과 특수안전계통의 정의
  • 본론 가: 4대 안전기능과 2그룹 설계 철학
  • 본론 나: 제1그룹 구성(공정계통·SDS1·ECC)과 각 계통 설계
  • 본론 다: 제2그룹 구성(SDS2·격납·EWS·EPS·SCA)과 배정 근거·분리 방법
  • 본론 라: 그룹별 안전보조계통(전력·냉각수·계장용 공기)
  • 결론: 특수안전계통 공통 요건과 국내 현황

답안 예시

1. 개요

  • CANDU 안전관련 계통은 3종임
    • 특수안전계통: 공정계통 고장의 결과를 완화하려고 별도로 둔 4개 계통 — SDS1, SDS2, ECC, 격납계통
    • 안전보조계통: 특수안전계통에 전력·냉각수·계장용 공기를 공급함
    • 안전관련 공정계통: 정상운전 계통 중 사고 완화에 쓸 수 있는 계통
  • 특징: 공정계통 단일 고장 + 특수안전계통 1개 손상(이중 고장)까지 설계기준 안에서 해석함

2. 가. 안전기능

  • ① 정지: 원자로를 정지하고 정지 상태를 유지함
  • ② 냉각: 연료의 붕괴열을 제거함
  • ③ 격납: 방사성물질 방출을 제한함(방벽 유지)
  • ④ 감시: 운전원이 발전소 상태를 감시할 정보를 제공함
  • 2그룹 설계 철학 [1]: 핵심 안전기능을 서로 독립된 두 경로(그룹)로 확보함 → 한 그룹이 화재·비산물·지원계통 고장 같은 국부 공통원인으로 상실돼도 다른 그룹이 정지·냉각·감시와 방출 제한을 수행함
    • 그룹 간에는 고장 전파를 막는 버퍼·격리형 제한적 지원 연결만 허용함

3. 나. 안전계통 제1그룹

  • 구성: 정상운전 공정계통 + SDS1 + ECC + 이들의 안전보조계통, 주제어실(MCR) — 주로 전력 생산용
  • 기능별: 정지 — 원자로조절계통·SDS1 / 열제거 — 열수송·증기·급수·정지냉각·감속재계통, ECC / 방출 제한 — 원자로건물 공기냉각기(열제거 보조, 격납장벽 대체 아님) / 감시 — MCR
  • SDS1: 스프링 보조 중력 낙하 정지봉 28개(CANDU-6), 칼란드리아 위에서 수직으로 압력관 열 사이 감속재에 삽입, 3채널 중 2채널 일치 시 작동(2/3) [2]
  • ECC 3단계(열수송계통에 비상냉각수 주입)
    • 고압: 기체로 가압한 물탱크가 열수송계통 압력이 떨어지면 주입함
    • 중압: 살수탱크 물을 ECC 펌프로 주입함
    • 저압 회수: 건물 바닥 집수부 물 → ECC 펌프·열교환기 → 재주입, 열교환기는 재순환 냉각수(RCW)로 냉각함
    • LOCA 신호로 증기발생기 급속냉각도 함께 개시함

4. 다. 안전계통 제2그룹

  • 구성: SDS2 + 격납계통 + 비상급수계통(EWS) + 비상전원계통(EPS) + 보조제어실(SCA) — 가상 사고·외부 사건(지진 등) 영향 완화 역할, 대체로 내진 검증·홍수위 위 배치
  • SDS2: 질산가돌리늄 용액을 칼란드리아 측면 수평 노즐 6개(연료채널과 직각 방향)로 감속재에 고압 주입함, 3채널 중 2채널 일치 시 작동(2/3), 트립 변수는 가능한 범위에서 SDS1과 다양화함 [2]
  • 격납계통: 프리스트레스 콘크리트 + 에폭시 라이너, 자동 살수계통(살수탱크·분무 헤더), 격리 밸브·댐퍼, 수소 제어 → 최고압력 설계조건은 살수 완전 실패를 동반한 LOCA
  • 배정 근거 [1]
    • SDS1·SDS2를 서로 다른 그룹에 배정 → 한 사건에 의한 두 정지계통의 동시 기능상실 방지
    • ECC(G1)와 격납(G2)을 서로 다른 그룹에 배정 → 한 사건에 의한 ECC·격납 동시 기능상실 방지(연료 냉각 실패와 방출 제한 실패가 겹치지 않게 함)
  • 분리 방법: 원자로건물 밖은 서로 다른 구역(통상 90°)에 배치, EPS·EWS는 별도 건물 / 건물 안은 방벽·거리 / 그룹 간 연결은 버퍼·격리 가능하게 해 고장 전파 차단

5. 라. 안전보조계통

  • 정의: 특수안전계통이 작동하도록 전력·냉각수·계장용 공기를 공급하는 계통임
  • 전원 등급(Class)은 그룹과 다른 분류임: Class IV = 정상 교류(소외·주발전기), Class III = 단시간 중단 허용 교류(상실 시 대기 디젤), Class II = 무정전 교류, Class I = 무정전 직류
  • 제1그룹 [1][2]: 전력 Class IV·III(대기 디젤)·II·I / 냉각수 원수(RSW)·재순환 냉각수(RCW) / 계장용 공기계통
  • 제2그룹: EPS 디젤·Class II·Class I / EWS / 국부 공기탱크
    • EPS: 장기 붕괴열 제거·Group 2 사고후 감시용 전력, Group 1 전원 상실·LOCA 후 지진·설계기준지진에 대비함
    • EWS: ECC 열교환기 냉각수, 열수송계통·증기발생기 보충수 공급
  • 사고 시 제2그룹 지원(EWS·EPS)이 제1그룹 특수안전계통(ECC 등)에 버퍼 연결로 공급될 수 있음

6. 결론

  • 공통 요건: 비가용도 10⁻³ 미만(운전 중 시험으로 입증) [2], 내진·환경 검증, 고장 시 안전측, 수동 작동, 상호·공정계통과 분리·독립
  • 경수로의 "동일 계열 다중화"와 달리 CANDU는 그룹 간 다양성·분리 + 그룹 내 다중성으로 공통원인고장에 대응함

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 그룹 번호가 곧 계통 등급은 아니다

"제2그룹 = 더 중요한 계통"으로 오해하기 쉽지만, 그룹은 중요도 순서가 아니라 공통원인고장 방호를 위한 배치 구분입니다. 정지 기능만 봐도 SDS1(제1그룹)과 SDS2(제2그룹)는 같은 등급의 특수안전계통이며, 원리(기계식 봉 낙하 대 액체 독물질 주입)와 트립 변수를 다르게 해 다양성을 확보합니다. 제2그룹이 지진·외부 사건 대응을 맡는다는 점에서 내진 검증 범위가 넓을 뿐입니다. 표의 배정은 CANDU-6 일반 설계 자료 기준이며, 설계 세부는 호기마다 다를 수 있습니다.

해설: 이중 고장과 트립 커버리지

CANDU 안전해석은 사고를 두 부류로 나눕니다. 하나는 공정계통 단일 고장이고, 다른 하나는 그 고장에 특수안전계통 1개의 손상이 겹친 이중 고장입니다. 예를 들어 냉각재상실사고(LOCA)와 ECC 실패가 겹쳐도 격납계통이 방출을 제한해 선량 기준을 만족해야 합니다. 정지계통은 사건마다 각 계통에 독립적이고 다양한 유효 트립 변수가 2개 이상 있음을 보입니다. 특수안전계통의 비가용도 10⁻³ 목표와 운전 중 시험 요건은 이런 이중 고장 해석의 전제를 뒷받침합니다.

해설: 국내 규제에서 읽는 법

국내 「원자로시설 등의 기술기준에 관한 규칙」은 노형 공통 조문으로 원자로보호계통(제26조), 반응도제어계통(제28조), 비상노심냉각장치(제30조), 격납건물(제23조), 전력공급설비(제24조), 신뢰성(제44조, 다중성·다양성·독립성·물리적 격리성)을 요구합니다 [3]. 2그룹 분리 자체를 명시한 국내 조문은 없고, 캐나다 설계 요건에서 온 설계 철학으로 인허가 문서에 반영돼 있습니다.

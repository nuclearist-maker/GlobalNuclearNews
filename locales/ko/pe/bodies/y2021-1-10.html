출처: KINS 원자력면허시험 자료실, 2021년 원자력발전기술사 필기 1교시 10번

문제

격납용기 관통부 누설시험 Type A, Type B, Type C

핵심 키워드

  • 기밀시험: 격납건물의 기밀성능을 확인하는 누설률 측정시험입니다(원안위고시 제2018-5호).
  • Type A(종합 누설률시험, ILRT): 설계기준사고 조건을 모의해 격납건물 전체 누설률을 잽니다.
  • Type B(관통부 누설률시험): 전기관통부·출입구(에어록)·핵연료이송관처럼 밀봉부·벨로즈가 있는 관통부 압력경계를 시험합니다.
  • Type C(격리밸브 누설률시험): 격납건물 안팎을 잇는 배관의 격리밸브를 시험합니다.
  • Pa·La: Pa는 설계기준사고 시 계산된 격납건물 최대압력, La는 Pa에서의 허용 누설률(공기 질량 %/day)입니다.

답안 예시

1. 가정 및 문제 해석

  • 문제는 "관통부 누설시험"이라 했으나 Type A는 건물 전체 시험임 → 10 CFR 50 App. J의 A·B·C 분류(국내 종합·국부)로 답함[1][2]

2. 정의와 대상

  • Type A: 격납건물을 격리·가압해 전체 누설률 측정(B·C 경로 누설 포함)
  • Type B: 밀봉부·벨로즈 등 관통부 압력경계 — 탄성 밀봉·개스킷 관통부, 벨로즈 배관 관통부, 전기관통부, 에어록(도어 씰·챔버), 핵연료이송관 플랜지
  • Type C: 정상운전 중 안팎 대기를 직접 잇거나 격리신호로 닫히는 격납건물 격리밸브

3. 시험 방법

  • A: 시험압력 설계압력 이하, 0.96 Pa 이상 유지, 안정 후 24시간 이상 자료로 건공기 질량 감소율 계산(절대법·질량점법), 확인시험 4시간 이상[1]
  • B·C: 시험 공간(이중 밀봉 사이, 에어록 챔버, 격리밸브 경계)을 Pa 이상 1.1 Pa 이하로 국부 가압 → 보충 유량 또는 압력·온도 변화율 측정
  • C: 격리기능이 요구되는 방향으로 가압(반대 방향·두 밸브 사이 가압은 동등·보수적 결과 입증 시 허용), 밸브는 정상 방법으로 닫은 그대로 시험(사전 조정 금지)

4. 허용기준(고시 제6·10조)[1]

  • A: 종합 누설률 ≤ 0.75 La, 측정 오차 ≤ 0.25 La
  • B+C: 최대경로 국부 누설률 합 ≤ 0.60 La, 개별 관통부는 각 기준치 이하

5. 주기

  • A: 사용전 → 첫 가동중 3년 이내 → 이후 5년 이내 → 실적 인정 시 10년[1](미국 Option B 조건부 최대 15년)[2][3]
  • B·C: 사용전, 가동중은 대상별 주기(미국 Option B 조건부 연장 최대 Type B 120개월(에어록 제외), Type C 75개월)[3][4]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설

세 시험은 "어디를 가압하는가"로 구분하면 기억하기 쉽습니다. Type A는 건물 전체, Type B는 밀봉부가 있는 관통부의 국부 공간, Type C는 배관 격리밸브의 경계입니다. Type C는 격리기능이 요구되는 방향으로 가압하는 것이 원칙이고, 두 밸브 사이를 가압하는 구성은 같은 결과를 보수적으로 얻을 수 있을 때 쓰는 방법입니다. 세 시험은 각각 따로 시행합니다. Type A는 B·C 경로로 새는 양까지 함께 재므로 가장 포괄적인 시험입니다. 다만 건물 전체를 가압해야 해서 비용과 공정 부담이 커 주기가 깁니다.

허용기준의 0.75와 0.60은 여유를 남기는 장치입니다. Type A는 다음 시험까지의 열화를 고려해 La의 75 %로 제한합니다. B·C는 La의 60 %만 배정해 나머지 경로와 열화에 여유를 둡니다. 최대경로 누설률은 한 경로의 두 방벽 중 큰 값을 그 경로 값으로 씁니다. 성능이 좋은 쪽 방벽을 잃는 단일고장을 가정해도 기준이 성립하게 하려는 것입니다.

La는 설계기준사고 방사선 영향평가에 들어가는 격납건물 누설 입력값입니다. 그래서 누설률시험은 "선량해석 가정이 실제 설비에서 유지되는가"를 확인하는 절차라고 볼 수 있습니다. 국내 APR1400 예로 새울 2호기(옛 신고리 4호기)는 La 0.1 wt%/day를 쓰며, 운영허가 단계 종합시험 결과는 0.0328 wt%/24 h였습니다[5].

현행 기준 메모: 고시 제2018-5호는 2021년 출제 당시와 현행이 같습니다. 미국은 출제 이후인 2023년에 RG 1.163 Rev.1로 NEI 94-01 Rev.3-A(Type C 최대 75개월)를 승인했습니다.

채점 포인트와 흔한 실수

  • Type A는 관통부 시험이 아님: 문제 표현과 달리 건물 전체 시험임을 짚으면 가점 요인입니다.
  • 기준 혼동: 0.75 La(A)와 0.60 La(B+C 최대경로 합)를 바꿔 쓰지 않습니다.
  • 시험압력: 종합은 0.96 Pa 이상 유지(설계압력 이하), 국부는 Pa~1.1 Pa입니다. Pa는 설계압력이 아닙니다.
  • 주기: 국내 종합시험 최대 10년, 15년은 미국 Option B 값입니다.
  • La 단위: 부피가 아니라 공기 질량 기준 %/day입니다.

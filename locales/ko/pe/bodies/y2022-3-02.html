출처: KINS 원자력면허시험 자료실, 2022년 원자력발전기술사 필기 3교시 2번

문제

1단계 PSA는 원자력발전소에서 초기사건 발생 후 진행사건의 완화 또는 종결을 위해 작동이 필요한 발전소 주요 계통과 운전원 조치를 정량적으로 분석하여, 발생가능한 노심손상 사고의 경위와 발생빈도를 확률론적으로 계산하는 도구이다. 다음 1단계 PSA의 주요 수행단계에 대해 기술하시오. 가. 초기사건(Initiating Event) 분석 나. 사건수목(Event Tree) 구성 다. 계통 고장수목(Fault Tree) 분석 라. 신뢰도 자료분석 및 사고경위 정량화

출제 의도

1단계 PSA를 "사건수목과 고장수목을 그린다" 수준이 아니라 입력 → 작업 → 산출물이 이어지는 하나의 분석 체계로 설명할 수 있는지 확인하는 문제입니다. 단계마다 무엇을 근거로 하는지(운전경험, 열수력 해석, 계통 설계, 고장 자료)와 무엇을 넘겨주는지(초기사건 빈도, 성공기준, 계통 비가용도, MCS)를 밝히면 좋은 점수를 받습니다. 라 문항은 공통원인고장과 정량화 근사(절단치, 희귀사건 근사)까지 써야 완성됩니다.

답안 구성

  • 서론: 1단계 PSA의 정의·목적·산출물(CDF, 지배 경위), 전체 흐름
  • 본론 가: 초기사건 목록 작성 → 선별 → 그룹화 → 빈도 산정
  • 본론 나: 표제 선정, 성공기준(열수력 해석), 분기와 말단 상태, 의존성
  • 본론 다: 정상사건 정의, 게이트 전개, 기본사건 유형, CCF·HRA·지원계통, MCS
  • 본론 라: 자료원과 베이지안 갱신, 비가용도 모델, ET-FT 결합 정량화, 중요도·불확실성
  • 결론: 결과 활용과 현행 규제 근거

답안 예시

1. 개요

  • 1단계 PSA = 초기사건 → 노심손상까지의 사고경위를 체계적으로 찾아 빈도를 정량화하는 분석임
  • 산출물: 노심손상빈도(CDF, /원자로·년), 지배 사고경위, 최소단절집합(MCS), 기기·운전원 조치 중요도
  • 결정론적 안전해석(보수적 가정·단일고장)을 대체하지 않고 취약점과 상대 위험도를 보여 주는 보완 수단임
  • 흐름[1][2]: 발전소 친숙화 → 초기사건 → 사건수목 → 고장수목(HRA·CCF 포함) → 신뢰도 자료 → 정량화 → 중요도·불확실성

2. 가. 초기사건 분석

  • 정의: 정상운전을 교란해 안전기능의 작동을 요구하는 사건(기기 고장, 운전원 오류, 소외전원상실 등)
  • ① 목록 작성: 마스터 논리도·FMEA 같은 공학적 평가, 안전성분석보고서 15장, 국내외 운전경험, 기존 PSA 목록을 함께 검토 → 누락 방지
  • ② 선별: 빈도와 영향이 무시할 만한 사건은 근거를 남기고 제외
  • ③ 그룹화: 같은 완화 기능과 성공기준을 요구하는 사건끼리 묶음
    • 냉각재상실: 대·중·소형 LOCA, 원자로용기 파손, SGTR, 격납건물 우회 LOCA(ISLOCA)
    • 과도: 일반 과도, 주급수 상실, 주증기·급수관 파단, 소외전원상실
    • 지원계통 상실: 기기냉각수·필수용수·직류 모선 상실 등
  • ④ 빈도 산정: 발전소 고유 운전경험 + 일반 자료(베이지안), 희귀사건(LOCA)은 NUREG/CR-5750·NUREG-1829 같은 전문가 추정[4][5], 지원계통 상실은 고장수목으로 계산
  • 산출물: 초기사건군 목록과 빈도(평균·분포)

3. 나. 사건수목 구성

  • 초기사건군마다 완화에 필요한 안전기능을 표제(heading)로 시간 순 배열: 원자로 정지 → 안전주입(RCS 보충) → 2차측 열제거·감압 → 재순환·장기 열제거
  • 각 표제의 성공(위)·실패(아래) 분기로 사고경위를 전개 → 말단 상태를 성공 또는 노심손상으로 판정(2단계 접속용 손상 상태 정보도 부여)
  • 성공기준: 표제를 성공으로 보는 최소 계통·기기 조합과 운전원 조치 허용시간(예: 안전주입 4계열 중 1계열) → 최적평가 열수력 해석(MAAP, MARS-KS 등)으로 결정
  • 분기확률은 앞 표제 결과에 따른 조건부확률 → 의존성(공유 지원계통, 운전원 조치 간 의존)을 반영해야 함
  • 산출물: 사고경위 논리와 성공기준표

4. 다. 계통 고장수목 분석

  • 정상사건 = 사건수목 표제의 계통 기능 실패(예: "고압안전주입 실패")
  • 연역적으로 AND·OR 게이트로 전개 → 기본사건까지 내려감
    • 기기 고장 모드: 기동·개방 실패, 운전 중 정지, 오동작
    • 시험·정비 비가용도
    • 공통원인고장(CCF): 베타인자·MGL·알파인자 모델(NUREG/CR-5485)[6]
    • 인적 오류(HRA): 사고 전(시험·정비 후 복구 실패), 사고 후(운전원 조치 실패) — THERP·ASEP, 국내 K-HRA 등
    • 지원계통 의존성: 전원, 냉각수, 작동 신호, 공조
  • 정성 해석: 최소단절집합(MCS) 도출 → 단일고장 MCS와 CCF MCS로 설계 취약점 파악
  • 산출물: 계통 비가용도와 MCS

5. 라. 신뢰도 자료분석 및 사고경위 정량화

  • 필요 자료: 초기사건 빈도, 대기·운전 고장률, 요구시 실패확률, 시험·정비 비가용도, CCF 인자, 인적오류확률(HEP), 복구 확률
  • 자료원: 일반 자료(NUREG/CR-6928과 주기적 갱신 매개변수[3], IEEE Std 500, 국내 일반 자료) + 발전소 고유 운전경험 → 베이지안 갱신(감마 사전분포면 사후 평균 λ = (α + n)/(β + T))
  • 비가용도 모델: 주기시험 대기 기기 q̄ ≈ λ·T/2(T = 시험주기) + 요구시 실패 + 시험·정비 비가용도, 운전 임무 실패 ≈ λ_r·t_m
  • 정량화
    • 사건수목과 고장수목을 결합(fault tree linking) → 사고경위별 MCS 도출
    • 절단치(cutoff)로 미소 MCS 제외, 절단치를 낮춰 결과 수렴 확인
    • 희귀사건 근사: CDF ≈ Σ(MCS 빈도), MCS 빈도 = 초기사건 빈도 × 기본사건 확률 곱
    • 도구 예: AIMS-PSA·FTREX(국내), SAPHIRE·CAFTA·RiskSpectrum
  • 후처리: 복구 조치 반영 → 중요도 FV = [R − R(q=0)]/R, RAW = R(q=1)/R → 불확실성(몬테카를로, 평균과 5·95 백분위) → 민감도

6. 결론

  • 네 단계는 초기사건 빈도 × 사건수목 분기(고장수목 비가용도)라는 하나의 곱셈 구조로 이어짐
  • 결과는 설계 취약점 개선, 운영기술지침서 허용정지시간·시험주기 조정, 위험도 감시, 사고관리 전략 수립에 활용함
  • 국내는 원자력안전법 사고관리계획서와 원안위고시 제2026-1호 제9조(PSA의 기술적 적합성·상세성·분석범위와 목표치)를 근거로 수행함[7]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 라 문항은 숫자 한 줄로 차별화됩니다

fig1은 설명용 계산입니다. 대기 고장률 1.0×10⁻⁵/h인 펌프를 매월(720 h) 시험한다고 하겠습니다. 완전 검출·즉시 복구를 가정하면 시험 직후 0에서 시작한 비가용도가 다음 시험 직전 약 7.2×10⁻³까지 오르고, 시간 평균은 λT/2 = 3.6×10⁻³입니다. 이런 펌프 두 대로 이루어진 2계열 계통(1대만 성공해도 됨)을 독립으로 보면 계통 비가용도는 3.6×10⁻³의 제곱인 약 1.3×10⁻⁵입니다.

여기에 베타인자 β = 0.05를 적용합니다. q를 공통원인고장까지 포함한 기기 전체 값으로 보면 독립 항은 (1−β)q, 공통원인고장 항은 βq입니다. 공통원인고장 항 βq = 1.8×10⁻⁴이 독립 항의 곱(약 1.2×10⁻⁵)보다 15배쯤 커서, 이 예에서는 계통 비가용도 약 1.9×10⁻⁴의 94 %가 공통원인고장에서 나옵니다. 평균 비가용도를 그대로 넣은 정적 고장수목 근사이므로, 두 계열을 동시에 시험하는 시간 위상 효과는 반영하지 않았습니다.

이 숫자가 보여 주는 결론은 두 가지입니다. 첫째, 다중 계열 계통을 독립 가정만으로 계산하면 비가용도를 크게 과소평가할 수 있습니다. 다중성만으로는 공통원인고장을 막지 못하므로 다양성·물리적 분리 같은 공통원인고장 저감대책을 함께 검토합니다. 둘째, 시험주기를 절반으로 줄이면 잠재고장에 의한 q̄도 절반(1.8×10⁻³)이 됩니다. 대신 시험 중 비가용도와 시험 유발 마모가 늘어나므로, 운영기술지침서의 시험주기 조정은 PSA로 득실을 함께 평가합니다. 실제 PSA는 수십 개 초기사건과 수천 개 기본사건을 함께 정량화하므로, 답안에는 이런 단순 예를 원리 설명으로 덧붙이는 정도가 적당합니다.

채점 포인트와 흔한 실수

  • 방향 혼동: 사건수목은 초기사건에서 결말로 가는 귀납적 방법이고, 고장수목은 정상사건에서 원인으로 내려가는 연역적 방법입니다.
  • 성공기준 누락: 사건수목 표제만 나열하고 성공기준과 그 근거(최적평가 열수력 해석)를 빠뜨리는 경우가 많습니다.
  • CCF·HRA 누락: 고장수목 기본사건에 공통원인고장과 인적 오류가 없으면 다중 계열 계통의 위험도를 과소평가한 답이 됩니다.
  • 차원 오류: MCS 확률의 합을 그대로 CDF라고 쓰면 안 됩니다. 초기사건 빈도를 곱한 빈도(/원자로·년)로 표기합니다.
  • 정량화 근사 미언급: 절단치와 희귀사건 근사, 불확실성 분석을 한 줄씩이라도 써야 라 문항이 완성됩니다.

현행 기준으로 달라진 점

  • 국내 고시: 출제 당시 원안위고시 제2017-34호는 현행 제2026-1호(2026.1.16) 「사고관리 범위 및 사고관리능력 평가의 세부기준에 관한 규정」으로 개정되었습니다. 제9조(위험도 평가)의 PSA 요건과 목표치(초기사망·암사망 위험도 각각 전체 위험도의 0.1 % 이하, Cs-137 100 TBq 초과 사고 빈도 합)는 그대로입니다.
  • IAEA 지침: 2010년판 SSG-3는 SSG-3 Rev.1(2024)로 개정되었습니다[2]. 2단계 지침도 SSG-4 Rev.1(2025)로 바뀌었습니다.
  • ASME/ANS 표준: Level 1·LERF PRA 표준이 RA-S-1.1-2022(2022.5)를 거쳐 2024년판으로 개정되었습니다. NRC RG 1.200은 현행 Rev.3(2020.12)[8]이 여전히 이전 판(RA-Sa-2009)을 승인하고 있으며, 2022·2024년판을 승인하는 개정판은 2026년 현재 발행되지 않았습니다.
  • 운영 사례: 2025년 1월 원안위가 새울 1·2호기와 신한울 1·2호기 사고관리계획서를 심의했습니다. 국내 운전경험 자료('93~'17)로 PSA를 수행했고, 발전소 정전이 주요 초기사건으로 나타났습니다.

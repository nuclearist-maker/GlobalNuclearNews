출처: KINS 원자력면허시험 자료실, 2023년 원자력발전기술사 필기 3교시 5번

문제

다음 원자로 반응도계수에 대해 기술하시오. 가. 감속재 온도계수 나. 감속재 밀도계수 다. 감속재 기포계수

출제 의도

세 계수의 정의와 부호만 따로 외웠는지, 아니면 셋이 모두 "감속재 원자수밀도가 줄면 반응도가 어떻게 되는가"라는 하나의 물리 현상에서 나온다는 것을 아는지를 봅니다. 경수로가 과소감속으로 설계된 이유, 붕소 농도와 연소도에 따른 MTC 변화, 노형별(PWR·BWR·CANDU) 기포계수의 차이를 연결해 쓰면 고득점입니다. 세 계수를 궤환 반응도에 함께 넣을 때 같은 효과를 두 번 세지 않아야 한다는 점도 채점 포인트입니다.

답안 구성

  • 서론: 반응도계수 정의, 경수로에서 세 계수의 공통 뿌리(밀도 효과)
  • 본론 가: MTC — 정의, 부호 결정 메커니즘, 붕소·연소·온도 의존, 운영 제한과 측정
  • 본론 나: 밀도계수 — 정의·부호, MTC·압력계수와의 관계식
  • 본론 다: 기포계수 — 정의, 밀도계수와의 관계, 노형별 비교
  • 결론: 세 계수 비교표, 안전해석에서의 보수적 선택, 이중계산 주의

답안 예시

1. 개요

  • 반응도계수 α_x = ∂ρ/∂x: 다른 변수를 고정하고 변수 x가 단위량 변할 때의 반응도 변화(1 pcm = 10⁻⁵ Δk/k)[1]
  • 경수로의 감속재 = 냉각재 → 온도·압력·기포 변화가 모두 물 원자수밀도 변화로 반응도에 작용함
  • 밀도 감소 시 세 효과: ① 감속능↓ → 공명탈출확률 p↓(음) ② 감속·확산거리↑ → 비누설확률↓(음) ③ 물·용해 붕소 흡수↓ → 열이용률 f↑(양)
  • PWR은 과소감속(감속재/연료비 < k∞ 최대점)으로 설계해 ①·②가 ③을 이기게 함 → 음의 계수[1][2]

2. 가. 감속재 온도계수(MTC, α_T)

  • 정의: α_T = ∂ρ/∂T_M [pcm/°C, pcm/°F], 연료온도 고정
  • 실체: 대부분 밀도 효과 → α_T ≈ α_D·(∂ρ_w/∂T)_p, 순수 온도(스펙트럼 경화) 효과는 작음
  • 의존성
    • 붕소 농도↑ → 덜 음(③ 증가), 주기초·저온·고붕소에서 양 가능
    • 연소 진행(BOC → EOC) → 더 음(붕소 희석이 주원인)
    • 온도↑ → 더 음: 15.5 MPa에서 ∂ρ_w/∂T가 290 °C −1.88 → 330 °C −3.14 kg/(m³·K)로 약 1.7배(IAPWS-IF97 계산)[3]
  • 대표값(상용 PWR 예): BOC HFP 약 0 ~ −10, EOC HFP 약 −30 ~ −45 pcm/°F
  • 운영 제한: 운영기술지침서 MTC LCO(STS LCO 3.1.3)[5] — COLR 상한(주기초, 미국 Ginna 예: +5 pcm/°F 저출력·0 pcm/°F 고출력)과 하한(주기말, 같은 예: −44.6 pcm/°F) 사이 유지[4], 기동 노물리시험(HZP)에서 ITC 측정 → MTC = ITC − FTC
  • 의미: 음의 MTC → 출력↑ → 냉각재 온도↑ → 반응도↓ 자기제어(지발 궤환, 수 초 단위)

3. 나. 감속재 밀도계수(α_D)

  • 정의: α_D = ∂ρ/∂ρ_w [pcm/(g/cm³) 또는 pcm/(kg/m³)]
  • 부호: 과소감속·통상 붕소 조건의 경수로에서 양(밀도↑ → 감속↑ → ρ↑) = 밀도 감소 시 반응도 감소, 고붕소에서는 작아지거나 음으로 바뀔 수 있음(MTC 양과 같은 조건)
  • MTC·기포계수·압력계수의 공통 모체
    • α_T ≈ α_D·(∂ρ_w/∂T)_p, α_p ≈ α_D·(∂ρ_w/∂p)_T (PWR 압력계수는 작은 양) — 밀도 외 순수 온도 효과를 무시한 근사
  • 설명용 환산(EOC MTC −30 pcm/°F, 310 °C, ∂ρ_w/∂T = −2.30 kg/(m³·K)): α_D = −54/−2.30 ≈ +23.5 pcm/(kg/m³) → α_p ≈ 23.5 × 2.29 ≈ +54 pcm/MPa
  • 활용: 노심 설계 코드는 밀도·온도를 분리한 단면적 표로 계산하고, 안전해석은 밀도계수 곡선을 입력으로 쓰는 경우가 많음(냉각·감압 사건)

4. 다. 감속재 기포계수(α_V)

  • 정의: α_V = ∂ρ/∂α [pcm/% 기포], α = 증기 체적분율
  • 관계식(밀도 효과만 고려한 근사): 평균 밀도 ρ̄ = (1−α)ρ_l + αρ_g → Δρ̄ = −(ρ_l − ρ_g)Δα → α_V ≈ −α_D·(ρ_l − ρ_g)/100(기포율 1 %p당)
  • 설명용 환산(310 °C에서 구한 α_D를 15.5 MPa 포화상태로 외삽, ρ_l − ρ_g ≈ 492 kg/m³): EOC 약 −116 pcm/%, BOC(MTC −5 pcm/°F) 약 −19 pcm/%
  • 노형 비교
    • PWR: 정상운전은 고온 유로 상부 국부(과냉) 비등 수준 → 궤환 영향 작음, LOCA 초기 기포는 음의 반응도로 정지 보조
    • BWR: 노심 상부 기포율이 높아 주 궤환 — 재순환 유량으로 출력 제어, 압력 상승 시 기포 붕괴 → 양의 반응도
    • CANDU: 감속재(D₂O 칼란드리아)와 냉각재 분리 → 냉각재 기포계수 양(크기는 노심·연소 상태에 따라 다름) → 고속 정지계통 2개로 보완
    • RBMK: 흑연 감속·경수 냉각, 양의 기포계수(체르노빌 사고 요인 중 하나)[9]

  • 세 계수는 같은 밀도 효과 → 같은 밀도 변화를 온도·밀도·기포 항으로 중복 합산 금지(고정 조건 명시)
  • 안전해석: 가장 덜 음(BOC) → 가열·반응도 삽입 사건, 가장 음(EOC) → 냉각 사건(MSLB) 재임계에 보수적
  • 근거: 기술기준규칙 제18조(원자로의 고유보호)[6], GDC 11[7], SRP 4.3[8], 운영기술지침서 MTC LCO[5]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 왜 고온일수록 MTC가 더 음이 되는가

같은 1 °C 상승이라도 고온에서 물이 더 많이 팽창합니다. 15.5 MPa에서 물 밀도 기울기는 290 °C에서 −1.88, 310 °C에서 −2.30, 330 °C에서 −3.14 kg/(m³·K)입니다. 밀도계수가 양이고 비슷하다면 MTC는 이 기울기에 비례하므로, 감속재 온도가 높을수록 MTC 절댓값이 커집니다. 영출력 기동 때(저온) MTC가 가장 덜 음이고, 그래서 운영기술지침서가 저출력 구간의 MTC 상한과 최소임계온도를 함께 관리합니다.

해설: 설명용 환산값을 읽는 법

답안의 α_D ≈ +23.5 pcm/(kg/m³), 기포계수 약 −116 pcm/%, 압력계수 약 +54 pcm/MPa는 "MTC가 전부 밀도 효과이고 α_D가 일정하다"는 단순화로 얻은 값입니다. 특히 기포계수는 310 °C에서 구한 α_D를 344.8 °C 포화상태의 액체·증기 혼합물로 외삽한 것이라, 310 °C 유로의 실제 국부 비등 기포계수로 읽으면 안 됩니다. 실제 기포계수는 기포가 생기는 위치(출력이 높은 축방향 상부)와 스펙트럼 변화에 따라 달라 노심 설계 코드로 계산합니다. 시험 답안에서는 수치를 외울 필요가 없고, "MTC가 덜 음인 주기초에는 기포계수·압력계수도 그만큼 약하다"는 연동 관계를 보여 주는 정도로 쓰면 됩니다.

해설: 자주 하는 실수

  1. 밀도계수 부호를 "음"으로만 쓰는 경우 — 정의(밀도 증가당)를 먼저 밝히고 "밀도 감소 시 반응도 감소"로 서술해야 오해가 없습니다.
  2. MTC·밀도계수·기포계수를 독립 궤환으로 모두 더하는 경우 — 같은 효과의 중복입니다.
  3. CANDU의 양의 기포계수를 "감속재 기포"로 쓰는 경우 — 냉각재 기포입니다.
  4. PWR 압력계수를 음으로 쓰는 경우 — 압력↑ → 밀도↑ → 감속↑이라 작은 양입니다.

출처: KINS 원자력면허시험 자료실, 2020년 원자력발전기술사 필기 2교시 5번

문제

아래 그림과 같이 무한한 확산 매질에서 각각 초 당 S개의 중성자를 방출하는 4개(A, B, C, D)의 중성자 점선원이 있다. 다음을 구하시오. 단, 점선원에 대한 중성자속은 φ(r) = (S·e^(−r/L)) / (4πr·D)이고, r은 선원으로부터의 거리, L은 중성자 확산거리, D는 중성자 확산계수이다.

(그림: 한 변이 2a인 정사각형의 네 꼭짓점에 위 왼쪽 A, 위 오른쪽 B, 아래 왼쪽 C, 아래 오른쪽 D가 있고, 변 BD의 중앙에 P₁, 정사각형 중앙에 P₂가 있음)

가. 정사각형 한 변의 중앙에 있는 점 P₁에서의 중성자속(Neutron flux) 나. 정사각형 한 변의 중앙에 있는 점 P₁에서의 중성자류(Neutron current) 다. 정사각형 중앙에 위치한 P₂에서의 중성자속 라. 정사각형 중앙에 위치한 P₂에서의 중성자류

출제 의도

1군 확산이론의 두 가지 기본 성질을 확인하는 문제입니다. 첫째, 확산방정식이 선형이라 여러 선원의 해를 중첩할 수 있습니다. 둘째, 중성자속 φ는 스칼라라 그냥 더하지만, 중성자류 J = −D∇φ는 벡터라 방향을 따져 더해야 합니다. 대칭을 이용해 상쇄되는 성분을 먼저 지우면 계산이 짧아집니다. 점선원 중성자류에 흡수 효과 항(1/rL)이 붙는다는 점도 확인 포인트입니다.

답안 구성

  • 가정 및 문제 해석: 좌표·거리 설정, 중첩 원리, 점선원의 중성자류 식
  • 가·나: P₁의 φ(4개 스칼라 합)와 J(벡터 합, B·D 상쇄)
  • 다·라: P₂의 φ와 J(대칭 상쇄)
  • 검산: 무흡수 극한, 수치 미분, a/L 의존성

답안 예시

1. 가정 및 문제 해석

  • 무한 균질 매질, 1군 확산 근사, 정상상태, 네 선원 세기 S(n/s) 동일
  • 좌표: 정사각형 중심을 원점 → A(−a, a), B(a, a), C(−a, −a), D(a, −a), P₁(a, 0), P₂(0, 0)
  • 거리: P₁ → B·D = a, P₁ → A·C = √(a² + (2a)²) = √5·a, P₂ → 네 선원 = √2·a
  • 중첩: 확산방정식이 선형이므로 φ = Σφᵢ(스칼라 합), J = ΣJᵢ(벡터 합) [1][2]
  • 점선원 하나의 중성자류(픽의 법칙)
    • dφ/dr = −(S / 4πD)·e^(−r/L)·(1/r² + 1/(rL))
    • J = −D·dφ/dr·r̂ = S·e^(−r/L)·(1 + r/L) / (4πr²), 방향은 선원에서 점으로 향하는 r̂ [1]

2. 가. P₁의 중성자속

  • φ(P₁) = φ_B + φ_D + φ_A + φ_C = (S / 4πD)·[2·e^(−a/L)/a + 2·e^(−√5a/L)/(√5a)]
  • φ(P₁) = (S / 2πDa)·[e^(−a/L) + e^(−√5a/L)/√5]

3. 나. P₁의 중성자류

  • B 기여: 아래(−y), D 기여: 위(+y), 거리 같아 크기 같음 → 상쇄
  • A 기여: 방향 (2, −1)/√5, C 기여: 방향 (2, 1)/√5 → y성분 상쇄, x성분만 합산(cos θ = 2/√5)
  • Jₓ = 2 × (2/√5) × S·e^(−√5a/L)·(1 + √5a/L) / (4π·5a²)
  • J(P₁) = S·(1 + √5a/L)·e^(−√5a/L) / (5√5·π·a²), 방향 +x(변 BD에 수직, 정사각형 바깥쪽)
  • D는 명시적 계수로는 소거됨(L = √(D/Σa)를 통해서는 영향)

4. 다·라. P₂의 중성자속과 중성자류

  • 다. φ(P₂) = 4 × S·e^(−√2a/L) / (4πD·√2a) → φ(P₂) = S·e^(−√2a/L) / (√2·π·D·a)
  • 라. A–D, B–C가 대각선상 정반대 방향, 같은 크기 → J(P₂) = 0(대칭으로 ∇φ = 0)
  • 순 중성자류가 0이어도 중성자는 있음: 확산 근사의 부분류 J⁺ = J⁻ ≈ φ/4 > 0 [2]

5. 검산과 수치 예

  • 무흡수 극한(L → ∞): φ(P₁) → (S/2πDa)(1 + 1/√5), J(P₁) → S/(5√5πa²) — 1/r² 장의 중첩과 일치
  • a = L일 때: φ(P₁) = 0.0662·S/(DL), φ(P₂) = 0.0547·S/(DL), J(P₁) = 0.00985·S/L², φ(P₁)/φ(P₂) = 1.21
  • 단위: φ [n/(cm²·s)] = S[n/s] / (D[cm]·a[cm]), J [n/(cm²·s)] = S / a² → 일치
  • 수치 미분(J = −D∇φ 중앙차분)으로 a/L = 0.5, 1, 2에서 해석식과 일치 확인

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 왜 가까운 선원 둘이 0이 되는가

P₁은 B와 D의 정확히 가운데에 있습니다. 두 선원에서 오는 중성자류는 크기가 같고 방향이 반대라 서로 지웁니다. 남는 것은 멀리 있는 A와 C가 만드는 성분입니다. 이 둘은 각각 오른쪽 아래와 오른쪽 위를 향하므로 위아래 성분이 지워지고 오른쪽(+x) 성분만 남습니다. 그래서 P₁의 중성자류는 크기가 작고, 거리 √5·a에 해당하는 지수항 e^(−√5a/L)만 들어갑니다. 반면 중성자속은 방향이 없으므로 네 기여가 모두 더해지고, 가까운 B·D 항이 가장 큰 몫을 차지합니다. a/L = 1에서 B 하나의 중성자류 크기는 A 하나의 약 10.6배인데도 결과에 남지 않습니다.

그래프는 a/L이 커질수록 중성자속에서 가까운 선원의 비중이 커짐을 보여 줍니다. a와 D를 고정하고 흡수(Σa)를 키우면 L이 줄어 a/L이 커집니다. 이때 거리 a인 B·D 항보다 √2·a, √5·a인 항이 더 빨리 줄어 φ(P₁)/φ(P₂)는 1.02(무흡수 극한)에서 a/L = 3일 때 2.48까지 커집니다. 이 결과는 균질 매질의 확산 근사이므로 선원 바로 옆이나 흡수가 매우 강한 조건에서는 정확도가 떨어집니다.

해설: 채점 포인트와 흔한 실수

  • φ를 벡터처럼 상쇄시킴: 중성자속은 네 기여를 모두 더합니다.
  • J를 스칼라로 더함: 가까운 B·D 기여까지 더하면 크게 틀립니다.
  • 1/(rL) 항 누락: 점선원 J에는 (1 + r/L) 인자가 붙습니다.
  • cos θ를 1/√5로 씀: x성분은 2a/(√5a) = 2/√5입니다.
  • J(P₂) = 0을 "중성자가 없다"로 해석: φ(P₂) ≠ 0이고 부분류도 있습니다.

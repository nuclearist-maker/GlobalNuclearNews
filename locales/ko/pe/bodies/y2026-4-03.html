출처: KINS 원자력면허시험 자료실, 2026년 원자력발전기술사 필기 4교시 3번

문제

다음 자료를 가진 임계상태의 균질 원자로의 중성자 누설률을 계산하시오.

  • φ : 1×10¹³ n/㎠·s
  • Σa : 0.08 cm⁻¹
  • Σf : 0.05 cm⁻¹
  • 핵분열당 생성 중성자수 : 2.5

출제 의도

"임계"라는 단어 하나가 풀이의 전부입니다. 임계 정상상태에서는 단위 체적의 중성자 수가 변하지 않으므로 생성 = 흡수 + 누설이 성립하고, 누설률은 생성률에서 흡수률을 뺀 값이 됩니다. 확산계수 D나 노심 크기가 주어지지 않은 것도 같은 이유입니다. 누설을 −D∇²φ로 직접 계산할 필요 없이 수지식만으로 구하라는 뜻입니다. 계산은 세 줄이면 끝나므로, 25점의 나머지는 ① 누설률의 단위와 뜻(단위 체적당인지, 비율인지)을 정확히 쓰는지 ② k∞·비누설확률·버클링과 연결해 결과를 검산·해석하는지에서 갈립니다.

답안 구성

  • 서론: 가정 및 문제 해석(1군, 정상 임계, 외부 선원 없음, 누설률의 정의)
  • 본론 1: 1군 확산방정식에서 중성자 수지식 도출
  • 본론 2: 생성률·흡수률·누설률 계산(대입·단위)
  • 본론 3: 검산 — k∞, 비누설확률, DB², 핵분열 1회당 수지
  • 결론: 누설률 답, 물리적 의미와 실제 노심 비교

답안 예시

1. 가정 및 문제 해석

  • 주어진 단면적은 1군(에너지 평균) 거시단면적으로 보고, 모든 핵분열은 같은 군의 중성자로 일어난다고 가정함
  • 임계·정상상태(∂n/∂t = 0), 외부 중성자원 없음, 노심 조성은 균질함
  • 노심 체적이 주어지지 않았으므로 누설률은 단위 체적·단위 시간당 누설 중성자 수(n/cm³·s)로 구함. 노심 전체 누설률(n/s)은 이 값 × 체적임
  • φ는 노심의 (평균) 중성자속으로 해석함. 균질 무반사 노심의 기본 모드에서는 누설/흡수 비가 위치에 관계없이 일정하므로 비율 결과는 노심 어디서나 같음
  • 주어진 값: φ = 1×10¹³ n/cm²·s, Σa = 0.08 cm⁻¹, Σf = 0.05 cm⁻¹, ν = 2.5 n/fission

2. 중성자 수지식

  • 1군 확산방정식: (1/v)∂φ/∂t = D∇²φ − Σaφ + νΣfφ[1][2]
  • 각 항: 생성률 νΣfφ, 흡수율 Σaφ, 누설률 −D∇²φ (단위 모두 n/cm³·s)
  • 기본 모드 ∇²φ = −B²φ → 누설률 = DB²φ
  • 임계(∂φ/∂t = 0) → νΣfφ = Σaφ + 누설률
  • 따라서 누설률 = νΣfφ − Σaφ = (νΣf − Σa)φ — D, B²를 몰라도 구할 수 있음

3. 계산

  • 생성률 = νΣfφ = 2.5 × 0.05 cm⁻¹ × 1×10¹³ n/cm²·s = 1.25×10¹² n/cm³·s
  • 흡수율 = Σaφ = 0.08 cm⁻¹ × 1×10¹³ n/cm²·s = 8.0×10¹¹ n/cm³·s
  • 누설률 = 1.25×10¹² − 8.0×10¹¹ = 4.5×10¹¹ n/cm³·s
  • 단위 확인: (cm⁻¹) × (n/cm²·s) = n/cm³·s ✓
  • 누설 분율(생성 대비) = 4.5×10¹¹ / 1.25×10¹² = 0.36 (36 %), 흡수 분율 0.64 (64 %)

4. 검산

  • k∞ = νΣf/Σa[3] = 0.125/0.08 = 1.5625
  • 임계(keff = 1)이므로 비누설확률 P_NL = 1/k∞ = 0.64 → 누설 분율 1 − 0.64 = 0.36 ✓ (위 계산과 일치)
  • 1군 keff = k∞/(1 + L²B²)[1] = 1 → L²B² = k∞ − 1 = 0.5625 = 누설/흡수 비(4.5×10¹¹/8.0×10¹¹) ✓
  • DB² = 누설률/φ = 4.5×10¹¹/1×10¹³ = 0.045 cm⁻¹ = νΣf − Σa ✓ → D가 주어지면 B² = 0.045/D로 임계 치수를 구할 수 있음
  • 핵분열 1회당 수지(Σfφ = 5.0×10¹¹ fission/cm³·s 기준): 생성 2.5개 = 흡수 Σa/Σf = 1.6개 + 누설 0.9개 ✓
  • 흡수 1.6개 중 핵분열 1개가 다음 세대 2.5개를 만들어 세대가 정확히 이어짐 → 임계 조건과 모순 없음

5. 결론 및 의미

  • 누설률 = 4.5×10¹¹ n/cm³·s (생성 중성자의 36 %, 핵분열 1회당 0.9개)
  • k∞ = 1.5625로 무한 매질이면 초임계지만, 36 % 누설이 정확히 그 초과분(0.5625/1.5625)을 상쇄해 임계가 됨
  • 누설 36 %는 작은 무반사 노심에 해당하는 큰 값임. 대형 상용 PWR은 노심이 커서 B²가 작고 반사체가 있어 누설이 몇 % 수준이며, 남는 k∞ 여유는 붕소·제어봉·가연성 독봉으로 흡수함
  • 누설을 줄이는 방법: 노심 대형화(B² 감소), 구·최적 원통(H ≈ 1.85R)[1] 형상, 반사체 설치, 저누설 장전모형(외곽에 연소 연료 배치) — 저누설 장전은 원자로용기 고속중성자 조사량도 줄임

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: "누설률"은 무엇을 답해야 하나

문제는 단위를 지정하지 않았습니다. 그래서 답안에는 절대값(n/cm³·s)과 분율(36 %)을 모두 쓰는 것이 안전합니다. 주어진 값이 중성자속과 거시단면적이므로 계산이 자연스럽게 닿는 곳은 단위 체적당 반응률입니다. 반면 "누설률"을 "생성 중성자 중 새는 비율"로 읽는 문헌도 있습니다. 두 값은 생성률로 나누면 서로 바뀌므로, 한쪽만 쓰고 끝내기보다 둘을 함께 쓰고 비누설확률 0.64로 검산까지 보이면 해석 차이로 감점될 여지가 없습니다.

노심 전체의 누설률(n/s)은 체적이 있어야 나옵니다. 예를 들어 체적을 가정해 곱하는 식의 답은 근거 없는 값이므로 쓰지 않는 편이 낫고, "체적 V가 주어지면 4.5×10¹¹·V n/s"라고 한 줄로 남기면 됩니다.

해설: 흔한 오답

실수 계산 결과
ν를 빠뜨림 (Σf − Σa)φ −3.0×10¹¹(음수 → 바로 오류)
핵분열률을 흡수에서 뺌 (Σa − Σf)φ 3.0×10¹¹
누설/흡수 비를 누설 분율로 씀 4.5/8.0 0.5625(이 값은 L²B²)

첫 번째 실수는 결과가 음수라서 스스로 걸러집니다. 세 번째는 k∞ − 1 = 0.5625와 숫자가 같아 그럴듯해 보이지만, 분율의 분모는 흡수가 아니라 생성입니다. 이 문제에서 비누설확률은 1/k∞ = 0.64이고, 1군 공식 1/(1 + L²B²) = 1/1.5625로도 같은 값이 나옵니다.

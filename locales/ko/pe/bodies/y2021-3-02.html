출처: KINS 원자력면허시험 자료실, 2021년 원자력발전기술사 필기 3교시 2번

문제

OPR형 원전의 안전감압계통(SDS : Safety Depressurization System)에 대하여 다음 사항을 기술하시오. 가. SDS 설치 목적 나. SDS 사용 시기 및 구체적 방법 다. 타 노형(WH형 및 APR형) 원전에서 SDS 기능을 수행하는 계통 혹은 기기

출제 의도

가압기 PORV가 없는 CE 계열 OPR1000이 왜 전용 감압계통을 두었는지, 그 계통이 설계기준사고용이 아니라 설계기준 초과 사건(급수완전상실)과 중대사고용이라는 점을 아는지 봅니다. 다 항목은 같은 "RCS 의도적 감압" 기능을 WH형은 PORV로, APR1400은 POSRV로 수행한다는 노형 비교 능력을 확인합니다. 방출처(격납건물 대기 / 가압기 방출탱크 / IRWST)를 정확히 구분해 쓰는 것이 변별 포인트입니다.

답안 구성

  • 서론: 가정 및 문제 해석(OPR1000 기준), SDS의 위상
  • 본론 가: 설치 목적 3가지와 배경(PORV 부재), 구성·설계기준
  • 본론 나: 사용 시기 3가지, 일방관류냉각 운전 6단계, 중대사고 감압
  • 본론 다: WH형 PORV + 차단밸브, APR1400 SDVS(POSRV·RCGVS)·3방향 밸브·ERDV
  • 결론: 3노형 비교표

답안 예시

1. 가정 및 문제 해석

  • "OPR형" = OPR1000(한국표준형, CE 계열), "APR형" = APR1400으로 해석함
  • 구성·수치는 공개 학회 논문·설계 자료의 OPR1000 예이며 밸브 구성·설정치 등 세부는 호기별 설계값
  • SDS = 가압기 증기부에서 RCS를 원격 수동으로 급속 감압하는 계통, 설계기준 초과 사건 전용(안전정지·설계기준사고 완화 기능 없음)[2]

2. 가. SDS 설치 목적

  • ① 급수완전상실(TLOFW) 대응: SG 열제거 상실 시 RCS를 HPSI 체절압력 아래로 감압 → 급수·배출(일방관류냉각)으로 붕괴열 제거, 노심 노출 방지
    • 감압이 없으면 가압기 안전밸브(PSV, 해석상 개방 약 17.2 MPa[3])가 설정압 부근에서 개폐만 반복 → RCS 고압 유지 → 안전주입 불가 → 재고 고갈
  • ② 고압 노심손상 대응: 원자로용기 파손 전 감압 → 고압용융물방출(HPME)·격납건물직접가열(DCH) 방지, 고압 자연순환에 의한 고온관·SG 전열관 크리프 파손 방지[9]
  • 배경: CE 계열은 가압기 PORV가 없음 → 배출 경로를 전용 계통으로 확보(OPR1000 급수·배출 = SDS + 안전주입계통[2])
  • 현행 위상: 급수완전상실은 사고관리 고시(원안위고시 제2026-1호) 별표 1 다중고장 필수 9종의 하나[1]
  • 구성(OPR1000 예)
    • 가압기 상부에서 나오는 독립된 2개 배관, 각 배관 끝 파열판을 거쳐 격납건물 대기로 방출[2]
    • 정상운전 중 닫혀 있고, 필요 시 운전원이 주제어실에서 원격 수동 개방[2] — 밸브 종류·전원 구성·안전등급 경계는 호기별 설계(FSAR)
  • 용량 평가조건(한울 3·4 FSAR 5장 조건을 학회가 재해석한 예[3])
    • 안전주입 일부만 가용 + SDS 1계열을 PSV 최초 개방 즉시 개방
    • 안전주입·SDS 모두 가용 + PSV 최초 개방 30분 뒤 개방
    • 두 조건 모두 최고 피복재 온도가 1,204 °C 기준에 크게 못 미쳐 노심 냉각 유지

3. 나. SDS 사용 시기 및 구체적 방법

  • 사용 시기
    • ① TLOFW: 비상운전절차서 기능회복절차의 열제거 안전기능 수행경로가 SG 냉각 → 일방관류냉각으로 넘어갈 때
    • ② 중대사고: 노심출구온도(CET) 649 °C 이상 + 노심냉각 회복 실패 → 중대사고관리지침서(SAMG) 진입 → 완화전략 원자로냉각재계통 감압의 수단(SG 경유 2차측 감압, 가압기 보조살수, SDS 등)
    • 정상운전·LOCA 등 설계기준사고에는 사용하지 않음(고온 냉각재 격납건물 직접 방출 → 기기 환경 악화)
  • 구체적 방법(일방관류냉각 골격)
    1. 진입 판단: 급수(주·보조·기동·복수) 복구 불가, SG 수위 저하·건조 임박, RCS 압력·CET 상승
    2. 준비: RCP 정지, 안전주입작동신호(SIAS) 확인·필요 시 수동, HPSI·충전펌프 가동, RWT 정렬
    3. 개방: 주제어실에서 SDS 밸브를 원격 수동 개방(가용한 계열 모두), 방출 유량과 RCS 압력 하강 확인 — 지체 금지(늦을수록 노심 가열 여유가 줄어듦[3])
    4. 성공 확인: RCS 압력 하강 → HPSI 주입유량 확인 → 안전주입탱크 주입, CET·과냉각여유도·원자로용기 수위·가압기 수위 감시
    5. 장기 냉각: RWT 저수위 → 재순환작동신호(RAS) → 격납건물 집수조 재순환(방출수가 집수조로 모임), 격납건물 압력·온도·수소 감시
    6. 종료: 급수 복구 → SG 열제거 확립 → SI 종료 기준 확인 → SDS 닫음 → SG 냉각 → 정지냉각
  • 중대사고 감압: 원자로용기 파손 전 RCS를 저압으로 낮춰 HPME·DCH 위험 저감(APR1400 심사 예 250 psia ≈ 1.72 MPa 이하[7]) — OPR1000의 목표값은 호기별 사고관리계획서 기준

4. 다. 타 노형에서 SDS 기능을 수행하는 계통·기기

  • WH형(고리 3·4, 한빛 1·2 등)
    • 기기: 가압기 PORV(전력구동 방출밸브) + 전동 차단밸브(block valve)
    • 방출처: 가압기 방출탱크(PRT) 수중 방출·응축(탱크 과압 시 파열판 파열 → 격납건물)
    • 사용: 2차측 열제거원 상실 기능회복절차의 bleed and feed(SI 작동 + PORV 개방), 중대사고 RCS 감압
    • 예: 고리 3·4는 안전등급 PORV 3개로 일방관류냉각 수행(별도 SDS 없음)[8]
    • PORV는 저온과압보호(LTOP) 저설정으로도 사용
  • APR형(APR1400)
    • 계통: 안전감압배기계통(SDVS) = POSRV 4개 + 원자로냉각재 배기계통(RCGVS)
    • POSRV: 자동 과압보호 설정압 2,470 psia, 개당 244.9 t/h[4] — 과압보호(스프링 파일럿 자동) + 급속감압(직렬 전동 파일럿 2개, 원격 수동, 둘 다 열려야 개방) 겸용
    • 방출처: 설계기준(급수·배출)은 IRWST 수면 아래 스파저로 응축
    • 중대사고(호기별 대안 설계): 새울 1·2·UAE·미국 설계인증은 POSRV 배출관 3방향 전환밸브 2개로 방출 방향을 SG 격실로 전환, 새울 3·4는 가압기에서 SG 격실로 가는 별도 비상감압밸브(ERDV) 2계열[5]
    • 감압 목표 250 psia(1.72 MPa)[7] — KINS 해석의 DCH 판정 기준 1.78 MPa[6]와 다른 값
    • RCGVS: 원자로용기 상부헤드·가압기 증기부 고점 배기(비응축성 기체 → IRWST), 살수 불가 시 압력 제어 보조

5. 결론

구분 WH형 OPR1000 APR1400
감압 기기 가압기 PORV + 차단밸브 SDS 2계열(원격 수동 밸브) POSRV 4개 + RCGVS
방출처 PRT(과압 시 파열판 → 격납건물) 파열판 → 격납건물 대기 IRWST / 중대사고 SG 격실
안전밸브 기능 통합 아니오(PSV 별도) 아니오(PSV 별도) 예(POSRV)
정상 대기 차단밸브 격리 가능 밸브 닫힘(운전원 수동 개방) 전동 파일럿 닫힘
  • 세 노형 모두 "RCS 의도적 감압 → 안전주입 유량 확보·급수배출 냉각 / 용기 파손 시 HPME·DCH 위험 저감"이라는 같은 기능을 서로 다른 기기로 구현함
  • OPR1000 SDS는 격납건물 환경 악화를 감수하는 설계기준 초과 전용 수단이므로 조기 개시 판단이 핵심임

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: PSV가 열려 있는데 왜 감압이 안 되나

안전밸브는 압력이 설정치를 넘을 때만 열리고 조금 내려가면 닫힙니다. 그래서 급수완전상실에서 PSV가 계속 개폐해도 RCS는 2,500 psia 근처에 머물고, HPSI는 이 압력을 이기지 못합니다. 냉각재만 빠져나가고 들어오는 물은 없는 상태가 이어집니다. SDS는 이 "고압 함정"을 일부러 깨는 밸브입니다. 한울 3·4 조건 해석에서는 SDS를 PSV 개방 즉시 열거나 30분 늦게 열어도 최고 피복재 온도가 각각 325 °C, 350 °C에 머물렀습니다[3]. 저자들은 그래도 가능한 한 빨리 열라고 결론지었습니다.

해설: 방출처를 정확히

세 노형의 방출처가 답안의 변별 포인트입니다. OPR1000은 IRWST가 없으므로 파열판을 지나 격납건물 대기로 바로 나갑니다. 그래서 설계기준사고에는 쓰지 않습니다. WH형 PORV는 가압기 방출탱크로 갑니다. APR1400 POSRV는 IRWST 물속 스파저에서 증기를 응축합니다. 중대사고 때는 IRWST 상부에 수소가 쌓이는 것을 피하려고 SG 격실로 경로를 바꿉니다.

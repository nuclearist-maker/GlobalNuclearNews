출처: KINS 원자력면허시험 자료실, 2026년 원자력발전기술사 필기 1교시 5번

문제

²³⁵U의 중성자 평균 세대시간 산출 및 원자로 운전에 미치는 지발중성자 역할 (단, 모핵종 평균수명은 12.5초, 감속시간은 10⁻⁶초, 확산시간은 2×10⁻⁵초이다.)

핵심 키워드

  • 즉발중성자 수명 l_p: 감속시간 + 확산시간. 경수로에서 10⁻⁵~10⁻⁴ s 수준입니다.
  • 지발중성자 분율 β: ²³⁵U 열중성자 핵분열에서 0.0065. 문제에 없으므로 가정값으로 밝혀 써야 합니다.
  • 모핵종(지발중성자 선행핵) 평균수명 τ̄: ⁸⁷Br 등 선행핵 6군을 분율로 가중평균한 붕괴 평균수명입니다. ²³⁵U 자체의 수명이 아닙니다.
  • 평균 세대시간 l̄: 선행핵 대기를 포함해 즉발·지발을 가중평균한 세대 간격, l̄ = l_p + β·τ̄. 점동특성식의 즉발 생성시간 Λ(= l_p/k)와는 다른 양입니다.
  • 원자로 주기 T: 출력이 e배 되는 시간, 단순 모델에서 T ≈ l̄/(k−1).

답안 예시

1. 가정 및 정의

  • ²³⁵U 열중성자 핵분열의 지발중성자 분율 β = 0.0065로 가정함[2]
  • 즉발중성자 수명 l_p = 감속시간 t_s + 확산시간 t_d
  • 평균 세대시간 l̄ = (1−β)·l_p + β·(τ̄ + l_p) = l_p + β·τ̄[1]

2. 산출

  • l_p = 1×10⁻⁶ + 2×10⁻⁵ = 2.1×10⁻⁵ s
  • β·τ̄ = 0.0065 × 12.5 = 0.08125 s
  • l̄ = 2.1×10⁻⁵ + 0.08125 ≈ 0.0813 s (약 8.1×10⁻² s)
  • 즉발 수명 대비 약 3,900배 증가 → 0.65%의 지발중성자가 세대시간을 지배함

3. 운전 영향 (k = 1.001 투입 예)

  • 즉발만 고려(β = 0 가상): T = 2.1×10⁻⁵ / 0.001 = 0.021 s → 1초 후 출력 약 10²⁰배, 제어 불가
  • 지발 포함(단순근사): T = 0.0813 / 0.001 ≈ 81 s → 1초 후 약 +1.2%, 제어 가능

4. 지발중성자의 역할

  • 제어 가능성 확보: 선행핵 붕괴 대기가 출력 상승을 늦춰, 0 < ρ < βeff 범위에서 주기를 수십 초 이상으로 유지 → 제어봉·붕소·운전원 대응 시간 확보
  • 즉발임계 경계: ρ < β(1$) 유지가 운전의 기본 한계, 반응도를 $·¢로 관리
  • 과도 응답: 반응도 변화 직후 즉발도약·즉발강하 후 안정주기로 이행
  • 정지 후 감소 한계: 즉발강하 뒤에는 최장 수명군(반감기 약 55.7 s)이 남아, 장시간 안정주기가 약 −80 s(|T₁| > 1/λ₁ ≈ 80.6 s)보다 짧아지지 않음[2]
  • 연소 영향: ²³⁹Pu 축적(β≈0.0021)[2]으로 주기 말 βeff 감소 → 동특성 응답이 빨라져 안전해석에 반영

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

위 그림은 답안의 숫자를 한 개의 로그 시간축에 올려 본 것입니다. 감속·확산 시간은 마이크로초 영역에 머물지만, 지발중성자 0.65%가 섞이는 순간 평균 세대시간이 0.1초 근처로 뛰어오르고, 같은 반응도에서 원자로 주기는 0.021초에서 81초로 바뀝니다.

채점 포인트와 흔한 실수

  • β 가정 누락: 문제에 β가 없다고 생략하면 계산이 성립하지 않습니다. "β = 0.0065 가정"을 첫 줄에 쓰는 것이 가장 확실한 득점 포인트입니다.
  • l_p 구성 오류: 확산시간만 쓰거나 감속시간만 쓰는 경우가 있습니다. 둘을 더하는 것이 정석이며, 식 l̄ = l_p + β·τ̄가 정확히 성립한다는 점을 보이면 좋습니다.
  • 숫자만 쓰고 의미 생략: 0.0813 s에서 멈추지 말고, 주기 비교 한 줄로 "왜 제어가 가능한가"까지 연결해야 역할 문항 배점을 받습니다.
  • 모델 적용 범위: T ≈ l̄/(k−1)은 ρ가 β보다 충분히 작을 때의 근사입니다. 이 예는 ρ/β ≈ 0.15라서 1군 근사 T ≈ (β−ρ)/(λρ), λ = 1/τ̄[3]로 검산하면 약 69 s가 나옵니다. 값은 조금 다르지만 같은 자릿수이고, ρ ≥ β에서는 둘 다 성립하지 않는다는 단서를 달면 완성도가 높아집니다.
  • 에너지와 시간 혼동: 지발중성자의 제어상 의미는 '느린 방출 시점'입니다. 낮은 방출 에너지는 βeff 보정의 이유로 구분해서 쓰십시오.

출처: KINS 원자력면허시험 자료실, 2018년 원자력발전기술사 필기 4교시 2번

문제

원자로격납건물 누설률시험의 목적, 2가지 시험 유형, 허용기준에 대해 설명하시오.

출제 의도

격납건물 기밀시험(누설률시험)을 "왜 하는가 → 무엇을 어떻게 재는가 → 무엇과 비교하는가"의 흐름으로 정리할 수 있는지 확인하는 문항입니다. 2가지 유형은 건물 전체를 가압하는 종합 누설률시험(ILRT, Type A)과 관통부·격리밸브를 따로 가압하는 국부 누설률시험(LLRT, Type B·C)입니다. 변별점은 허용기준을 숫자만 쓰지 않고 기준값 La·Pa의 정의, 0.75·0.60이라는 계수의 의미(열화 여유, 경로 배분), 최대경로 누설률 합산 원칙과 연결해 설명하는지입니다.

답안 구성

  • 서론: 격납건물의 역할과 누설률시험의 정의(Pa·La)
  • 본론 1: 시험 목적 4가지
  • 본론 2: 2가지 시험 유형 — 종합(Type A)과 국부(Type B·C)의 경계·압력·방법·주기
  • 본론 3: 허용기준 — 국내 고시와 미국 App. J 비교, 계수의 의미
  • 결론: La와 사고 선량해석의 연결

답안 예시

1. 개요

  • 격납건물: 다중방벽의 마지막 물리적 방벽으로, 설계기준사고 때 방출된 방사성물질을 가둠
  • 누설률시험(기밀시험): 격납건물을 사고 압력 수준으로 가압해 새는 양을 측정하고 허용누설률 안에 있는지 확인하는 시험임(원안위고시 「원자로격납건물 기밀시험에 관한 기준」)[1]
  • Pa(기준시험압력): 설계기준사고 시 계산된 격납건물 최대압력(설계압력이 아님)
  • La(허용누설률): Pa에서 허용되는 최대 누설률, 격납건물 내 공기 질량의 %/day — 운영기술지침서에 명시함(예: APR1400 0.1 %/day)[5]

2. 시험 목적

  • ① 사고 선량해석 가정의 입증: 사고 방사선 영향평가는 La로 누설한다고 가정함(PWR 처음 24 h La, 이후 0.5 La)[7] → 실제 누설이 La 이하여야 제한구역 경계 선량 기준 판단이 성립함
  • ② 시공·정비 결함과 경년열화의 조기 발견: 라이너 부식·관통부 밀봉 열화·에어록 씰·격리밸브 시트 누설
  • ③ 운전 중 기밀 성능 유지 확인: 격납건물 운전가능성(LCO)의 점검요건으로 쓰임[6]
  • ④ 규제 요건 이행: 「원자로시설 등의 기술기준에 관한 규칙」 제23조(격납건물)·제41조③(누설기준)[4], 10 CFR 50.54(o)·Part 50 App. J, GDC 52·53[2]

3. 2가지 시험 유형

구분 종합 누설률시험(ILRT) 국부 누설률시험(LLRT)
미국 구분 Type A Type B(관통부) · Type C(격리밸브)
검증 경계 격납건물 전체(격리 상태, B·C 경로 포함) B: 전기관통부·에어록·장비반입구 개스킷 / C: 격리밸브 시트
시험압력 시험 중 Pa의 96 % 이상, 설계압력 이하 유지[1] Pa 이상으로 국부 가압
방법 절대법: P·수증기분압·평균온도로 건공기 질량 W = (P − Pv)V/(RT) 산정 → 질량점법 회귀 L = −2400·B/A(%/day), 95 % 상한신뢰한계로 판정[3] 압력강하법 또는 보충유량법
시간 안정 후 24 h 이상 자료 + 인위 누설 확인시험 4 h 이상(오차 ≤ 0.25 La)[1] 경로별 수 시간 이내
주기(국내) 사용전 → 첫 가동중 3년 이내 → 5년 이내 → 성능 인정 시 10년[1] 계획예방정비 주기에 맞춰 반복
장점·한계 전체 누설을 한 번에 보증, 누설 위치는 모름 누설 위치를 찾아 보수, 콘크리트·라이너 전체는 못 봄
  • 격리밸브는 사고 시 격리가 필요한 방향으로 가압하고, 조정·보수 전 상태 그대로(as-found) 먼저 측정함 → 실제 운전 중 성능을 반영

4. 허용기준

구분 국내 고시[1] 미국 App. J Option A[2] 미국 Option B 프로그램
종합(Type A) 측정 누설률 ≤ 0.75 La < 0.75 La as-found < 1.0 La(성능기준), 복귀 전 as-left < 0.75 La
국부(B+C 합) 최대경로 누설률 합 ≤ 0.60 La < 0.60 La 복귀 전 최대경로 합 < 0.60 La
확인시험 오차 ≤ 0.25 La 동일 취지 ANSI/ANS-56.8[3]
  • 0.75 La의 의미: 다음 시험까지 생길 열화와 측정 불확도에 25 % 여유를 남김
  • 0.60 La의 의미: La의 60 %만 관통부·밸브 경로에 배정 → 나머지는 라이너·콘크리트 경로와 열화 여유
  • 최대경로 누설률: 한 관통 경로의 두 격리방벽(내측·외측 밸브) 중 큰 값을 그 경로의 값으로 보고 경로별로 합산함 → 단일고장으로 좋은 쪽 방벽을 잃어도 기준이 성립하도록 보수적으로 잡음
  • 실적 예: 신고리 4호기(현 새울 2호기) 운영허가 시 종합 누설률 0.0328 wt%/24 h로 기준 0.075 wt%/24 h(= 0.75 La, La 0.1 %/day) 대비 약 0.33 La였음[8]
  • 초과 시: as-found가 1.0 La를 넘으면 격납건물 불능 → 운영기술지침서 조치(복구, 실패 시 정지 모드 진입)[6], 국내는 보수전 결과 불만족 시 시험 주기를 단축함[1]

5. 결론

  • 누설률시험은 실제 누설률이 사고 선량해석에 넣은 허용누설률 La 이내인지 측정으로 검증하는 절차임
  • 종합 시험으로 전체를, 국부 시험으로 경로별 누설을 관리하고, 0.75 La·0.60 La로 열화 여유를 확보함

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 종합 시험이 있는데 왜 국부 시험을 따로 하나

종합 시험은 B·C 경로까지 포함한 총량을 보지만, 대형 시험이라 발전소 정지 기간이 길고 몇 년에 한 번만 합니다. 또 기준을 넘었을 때 어디서 새는지 알려주지 않습니다. 실제 누설의 대부분은 관통부와 격리밸브처럼 움직이거나 정비하는 부품에서 생기므로, 정비 때마다 국부 시험으로 경로를 하나씩 잡아 보수합니다. 두 시험은 대체 관계가 아니라 "총량 보증 + 경로 관리"의 보완 관계라고 쓰면 됩니다.

해설: 누설률시험과 구조건전성시험은 다르다

구조건전성시험(SIT)은 설계압력의 115 % 수준으로 가압해 변형·균열 등 구조 거동을 보는 사용전 시험입니다. 누설률시험은 Pa 근처에서 기밀성만 봅니다. 답안에서 두 시험의 압력·목적을 섞어 쓰지 않도록 주의합니다.

해설: La의 단위와 Pa를 헷갈리지 않으려면

La는 "하루 동안 격납건물 공기 질량의 몇 %가 새는가"이므로 단위가 wt%/day입니다. 부피 %나 유량(L/min)으로 쓰면 틀립니다. 국부 시험 결과는 보통 표준 유량(sccm 등)으로 나오므로, 합산할 때는 Pa 조건의 질량 누설률로 환산해 La와 같은 단위로 비교합니다. 또 Pa는 설계압력이 아니라 설계기준사고 해석에서 나온 최대압력이므로, 설계압력보다 낮은 값입니다. 시험은 이 Pa에서 해야 사고 때의 누설을 대표할 수 있습니다.

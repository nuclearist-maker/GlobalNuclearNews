출처: KINS 원자력면허시험 자료실, 2018년 원자력발전기술사 필기 2교시 1번

문제

반응도(ρ)와 지발중성자분율(β)의 크기에 따라 원자로의 동적상태를 5가지로 구분하고 특성을 설명하시오.

출제 의도

반응도를 β와 비교해 미임계·임계·지발초임계·즉발임계·즉발초임계로 나눌 수 있는지 봅니다. 경계가 ρ = 0과 ρ = β 두 곳이라는 점, 그리고 β를 넘는 순간 출력 변화의 시간 척도가 선행핵 붕괴(초)에서 즉발중성자 세대시간(밀리초)으로 바뀐다는 점이 핵심입니다. 상태마다 증배계수 조건, 출력 거동(즉발도약·안정주기), 제어 가능성을 함께 써야 25점 답안이 됩니다.

답안 구성

  • 서론: 반응도·지발중성자분율·달러 단위 정의, 즉발 증배계수 k(1−β)
  • 본론 1: 다섯 상태의 조건과 증배계수(표)
  • 본론 2: 상태별 특성(출력 거동, 주기, 제어 가능성)
  • 본론 3: 점동특성식으로 본 경계의 의미와 운전·설계 대응
  • 결론: 운전은 지발초임계 안에서만, 즉발임계는 운영 제한으로 피하고 가상 사고는 해석으로 확인

답안 예시

1. 개요

  • 반응도 ρ = (k−1)/k: 임계에서 벗어난 정도, 단위 Δk/k·pcm·달러($ = ρ/βeff)
  • 지발중성자분율 β: 핵분열 중성자 중 선행핵(핵분열생성물)의 β⁻ 붕괴 뒤 나오는 중성자 비율 → U-235 열핵분열 β = 0.0065 [2], Pu-239 약 0.0021 [1]
  • 노심 거동은 중요도로 가중한 βeff 기준(대형 PWR βeff/β ≈ 0.97)
  • 즉발중성자만의 증배계수 = k(1−β) → 이 값이 1을 넘느냐가 즉발임계 판단 기준

2. 다섯 가지 동적 상태(구분 기준: ρ = 0, ρ = β)

상태 반응도 조건 증배계수 출력 거동
① 미임계 ρ < 0 k < 1 즉발강하 후 감소(선원 있으면 평형)
② 임계(지발임계) ρ = 0 k = 1, k(1−β) < 1 일정
③ 지발초임계 0 < ρ < β 1 < k < 1/(1−β) 즉발도약 후 초~분 단위 지수 증가
④ 즉발임계 ρ = β (1$) k(1−β) = 1 즉발중성자만으로 임계
⑤ 즉발초임계 ρ > β k(1−β) > 1 ms 단위 급증

3. 상태별 특성

  • ① 미임계(ρ < 0)
    • 반응도 투입 직후 즉발강하 P₁/P₀ = β/(β−ρ)(예 −1$ → 0.5배) 뒤 선행핵 붕괴 속도로 감소
    • 안정주기는 음의 반응도마다 다름(−0.1$ −172 s, −1$ −83.9 s) → 깊은 미임계 극한 −1/λ₁ = −80.6 s(최장수명 선행핵군), 반응도를 더 넣어도 이보다 빨라지지 않음
    • 선원이 있으면 미임계 증배로 평형(단순 모형 M = 1/(1−k)) → 기동 시 1/M으로 임계 접근 감시
  • ② 임계 = 지발임계(ρ = 0)
    • 즉발 + 지발중성자 전체로 k = 1 → 출력 일정(정상 운전)
    • 즉발만 보면 k(1−β) < 1(즉발 미임계) → 지발중성자가 있어야 임계 유지
  • ③ 지발초임계(0 < ρ < β)
    • 즉발도약 β/(β−ρ)(0.5$ → 2배) 후 안정주기로 지수 증가
    • 6군 계산(Keepin 상수, Λ = 2×10⁻⁵ s) [2]: 0.1$ 98.6 s, 0.5$ 5.7 s, 0.9$ 0.38 s → 1$에 가까울수록 급감
    • 증가 속도를 선행핵 붕괴(평균 대기시간 가중 평균 약 13 s)가 정함 → 제어봉·붕소·운전원 조치가 따라갈 시간 여유가 있으나, 여유는 반응도 크기와 삽입 속도에 좌우됨
    • 기동·출력 상승은 이 영역에서만 함 → 기동률(SUR = 26.06/T dpm) 제한
  • ④ 즉발임계(ρ = β = 1$)
    • k(1−β) = 1 → 즉발중성자만으로 임계, 지발중성자의 시간 지연 효과가 증가 속도를 붙잡지 못함
    • 주기 약 92 ms(같은 6군 조건) — 곡선은 1$에서도 연속, 주기 유한
    • 1$의 pcm 값은 βeff에 따라 달라짐(β = 0.0065이면 약 650 pcm, 연소가 진행되면 감소)
  • ⑤ 즉발초임계(ρ > β)
    • 주기 ≈ Λ/(ρ−β)(지발항이 충분히 작을 때), 1.2$ 약 15 ms
    • 제어봉 구동·운전원 대응보다 빠름 → 첫 출력 첨두는 도플러 등 즉발 음의 궤환과 반응도 삽입 이력이 결정 → 연료 엔탈피 급증·손상 우려
    • 사례: SL-1(1961), 체르노빌 4호기(1986)

4. 경계의 의미와 운전·설계 대응

  • 유효 세대시간: 즉발만 Λ ≈ 2×10⁻⁵ s, 지발 포함 Λ + β·τ̄ ≈ 0.085 s → 약 4,000배 차이가 제어 가능성의 근원
  • 1군 점동특성 dP/dt = [(ρ−β)/Λ]P + λC에서 ρ < β이면 첫 항이 음 → 출력이 선행핵 공급(λC)을 따라감, ρ > β이면 첫 항만으로 증가 [3]
  • 설계·운전: 반응도 삽입률·제어봉가 제한, 제어봉 삽입한계(PDIL)로 정상운전·과도에서 즉발임계 배제
  • 즉발임계를 넘을 수 있는 제어봉 이탈 사고는 해석으로 연료 엔탈피·파손 기준 충족 확인(RG 1.236) [4]
  • 고유 안전: 음의 핵연료온도계수(도플러)·감속재온도계수로 반응도 증가 억제(기술기준규칙 제18조) [5]
  • 주기말 βeff 감소(Pu-239 축적) → 같은 pcm이 더 큰 $ → 해석에 보수적으로 반영

5. 결론

  • 다섯 상태의 경계는 ρ = 0(임계)과 ρ = β(즉발임계)
  • β는 작지만(0.65 %) 출력 응답을 초 단위로 늦춰 원자로를 제어할 수 있게 만드는 양 → 운전은 지발초임계 안에서만 하고, 즉발임계는 운영 제한으로 피하며 가상 사고는 해석으로 결과를 확인

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 그래프 한 장으로 다섯 상태 보기

그림의 곡선은 반응도를 계단으로 넣고 궤환과 외부선원이 없다고 둔 6군 점동특성에서, 시간이 지나 남는 지배 모드의 주기를 계산한 결과입니다. 임계(ρ = 0) 양쪽에서 주기는 무한대로 커지고, 양의 쪽은 1$를 지나면서 기울기가 바뀌어 밀리초 영역으로 내려갑니다. 음의 쪽은 아무리 반응도를 크게 넣어도 −80.6 s에 붙습니다. 이 비대칭이 "출력은 빨리 올라갈 수 있지만, 정지 후 중성자 출력은 일정 속도 이상으로 빨리 줄지 않는다"는 운전 특성을 설명합니다. 이 주기는 중성자·핵분열 출력에 대한 것이며 붕괴열 감소와는 다릅니다.

해설: "지발임계"의 범위를 넓히지 마세요

지발임계는 ρ = 0 한 점입니다. 0 < ρ < β 구간은 지발초임계로 따로 이름 붙입니다. 또 즉발도약식 β/(β−ρ)는 임계 평형에서 계단 투입한 직후를 다루는 식이라, ρ가 β에 가까워지면 쓰지 않습니다. 5가지 상태를 표로 정리하고, 각 상태에 "증배계수 조건 + 주기 수치 1개 + 제어 의미"를 붙이면 채점자가 확인하는 요소가 모두 들어갑니다.

해설: 1$ 부근에서 숫자가 얼마나 빨리 바뀌는가

β = 0.0065로 두면 0.1$는 약 65 pcm입니다. 같은 6군 조건에서 0.8$의 주기는 0.94 s, 0.9$는 0.38 s, 1.0$는 92 ms, 1.1$는 28 ms입니다. 반응도가 65 pcm씩 늘 때마다 주기가 몇 배씩 짧아지는 셈입니다. 그래서 정상운전과 예상운전과도에서는 반응도 삽입률과 제어봉 삽입한계로 즉발임계 근처에 가지 않게 합니다. 반면 제어봉 이탈처럼 1$를 넘을 수 있는 가상 사고는 사고해석으로 연료 엔탈피와 피복관 파손 기준을 만족하는지 확인합니다.

현행 기준으로 달라진 점

  • 동특성 물리와 상태 구분은 출제 이후 달라진 것이 없습니다.
  • 제어봉 이탈 사고 판정기준은 2020년 6월 RG 1.236이 RG 1.77(1974)을 대체했습니다[4]. 냉각가능성 기준은 첨두 반경평균 엔탈피 230 cal/g 미만 등이며, RG 1.77의 280 cal/g는 구 기준입니다.
  • 「원자로시설 등의 기술기준에 관한 규칙」은 2026년 두 차례 개정(원안위규칙 제36호 2026.1.20, 제37호 2026.3.30)됐으나 제18조(원자로의 고유보호)·제28조(반응도제어계통)의 취지는 출제 당시와 같습니다[5]. 미국 기준으로는 10 CFR 50 부록 A GDC 11·26·28에 해당합니다[6].

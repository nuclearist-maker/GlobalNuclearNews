출처: KINS 원자력면허시험 자료실, 2018년 원자력발전기술사 필기 3교시 1번

문제

2 MeV 중성자가 산소(¹⁶O) 원자핵과 충돌하여 에너지를 잃고 0.025 eV의 열중성자로 감속된다. 이때 다음을 구하시오. 가) 산란 후 중성자의 최소에너지 나) 산란 후 중성자의 평균에너지 다) 충돌당 감소되는 중성자 에너지의 평균 라) 대수적 에너지 평균 감쇄 마) 감속될 때까지 평균 충돌 횟수

출제 의도

탄성 산란 운동학의 기본량 다섯 개를 한 줄로 이어 계산하게 하는 문제입니다. 핵심은 α = [(A−1)/(A+1)]² 하나에서 최소 에너지, 평균 에너지, 평균 손실, ξ가 모두 나온다는 점을 보이는 것입니다. 변별은 세 군데서 납니다. 첫째, 가~다 항은 첫 충돌(E = 2 MeV) 기준의 에너지 값이고, 라·마 항은 에너지와 무관한 레싸지(lethargy) 공간의 값이라는 차이를 아는지입니다. 둘째, ξ를 식으로 끌어내고 근사식으로 검산하는지입니다. 셋째, 결과를 수소·탄소 등과 비교해 산소가 경수 감속에서 어떤 역할을 하는지까지 해석하는지입니다.

답안 구성

  • 서론: 주어진 값, 가정(정지 자유핵·탄성·질량중심계 등방), α 정의
  • 본론 1(가·나·다): 첫 충돌 후 에너지 분포(균일 분포) → 최소·평균 에너지, 평균 손실
  • 본론 2(라): ξ 유도와 대입, 근사식 검산
  • 본론 3(마): 총 레싸지 Δu → 평균 충돌 횟수, 문자 그대로의 최소 횟수 참고
  • 결론: 검산·적용 한계, 감속재 비교(물 속 산소의 의미)

답안 예시

1. 가정 및 문제 해석

  • 주어진 값: E₀ = 2 MeV = 2×10⁶ eV, E_th = 0.025 eV, 산소 A = 16
  • 가정: 표적 핵 정지·자유, 탄성 산란, 질량중심계(CM) 등방 산란, 흡수 무시
  • 가~다 항은 2 MeV 중성자의 첫 충돌 기준으로 계산함(다음 충돌부터는 에너지에 비례해 줄어듦)
  • "대수적 에너지 평균 감쇄" = 충돌당 평균 레싸지 증가량 ξ = ⟨ln(E/E′)⟩로 해석함

2. 충돌 파라미터 α

  • 정면충돌(CM 산란각 180°)에서 E′/E가 최소 → α = [(A−1)/(A+1)]²[1]
  • 산소: α = (15/17)² = 225/289 = 0.7785
  • CM 등방이면 E′는 αE~E 사이에 균일 분포: P(E′) = 1/[(1−α)E][1]

3. 가) 산란 후 최소 에너지

  • E′_min = αE₀ = 0.7785 × 2 MeV = 1.557 MeV(약 1.56 MeV)
  • 한 번 충돌로 잃을 수 있는 최대 에너지는 (1−α)E₀ = 0.443 MeV(약 22 %)

4. 나) 산란 후 평균 에너지

  • 균일 분포의 평균: ⟨E′⟩ = (1+α)E₀/2 = 0.8893 × 2 MeV = 1.779 MeV(약 1.78 MeV)

5. 다) 충돌당 평균 에너지 손실

  • ⟨ΔE⟩ = E₀ − ⟨E′⟩ = (1−α)E₀/2 = 0.1107 × 2 MeV = 0.221 MeV
  • 비율로는 충돌마다 평균 약 11.1 %를 잃음 — 에너지 손실 "양"은 E에 비례해 줄지만 "비율"은 일정함

6. 라) 대수적 에너지 평균 감쇄 ξ

  • ξ = ⟨ln(E/E′)⟩ = ∫ ln(E/E′)·dE′/[(1−α)E] (구간 αE~E) = 1 + α·lnα/(1−α)[1]
  • ln α = ln 0.7785 = −0.2503
  • ξ = 1 + 0.7785 × (−0.2503)/0.2215 = 1 − 0.880 = 0.120
  • 검산(근사식): ξ ≈ 2/(A + 2/3) = 2/16.67 = 0.120 ✓, 교과서 표값 0.120과 일치[2]
  • 의미: E와 무관하게 충돌 1회마다 레싸지가 평균 0.120씩 증가함

7. 마) 열화까지 평균 충돌 횟수

  • 총 레싸지 증가: Δu = ln(E₀/E_th) = ln(2×10⁶/0.025) = ln(8×10⁷) = 18.2
  • n = Δu/ξ = 18.2/0.120 = 151.7 → 약 152회(평균 추정치)
  • 참고 — 매번 정면충돌하는 문자 그대로의 최소: 1회 최대 증가 ln(1/α) = 0.250 → n_min = ⌈18.2/0.250⌉ = 73회

8. 검산과 물리적 타당성

  • 단위: α·ξ·Δu·n 무차원 ✓, ln 사용(log₁₀을 쓰면 7.90/0.120 = 66회로 틀림)
  • 실제 질량비 A = 15.86(¹⁶O/중성자)을 쓰면 α = 0.7768, ξ = 0.121, n = 150 → 결론 동일
  • ¹⁶O 첫 들뜬 준위는 약 6.05 MeV(입사 중성자 문턱 약 6.4 MeV) → 2 MeV에서는 비탄성 산란이 없어 탄성 가정이 타당함
  • 한계: MeV 영역 산소의 탄성 산란은 공명이 있고 각분포가 비등방임. 전방 산란이 우세한 에너지에서는 실제 평균 손실이 등방 가정보다 작아짐. 수 eV 이하에서는 분자 결합·열운동(상향 산란) 때문에 정지 자유핵 가정이 맞지 않음 → 0.025 eV까지의 n은 관례적 추정치

9. 결론 — 물 속 산소의 의미

  • 결과: E′_min 1.557 MeV, ⟨E′⟩ 1.779 MeV, ⟨ΔE⟩ 0.221 MeV, ξ 0.120, n ≈ 152회(최소 73회)
  • 각 핵종만으로 감속한다고 본 이상모형에서 수소(ξ = 1, 약 18회)에 비해 산소는 충돌당 감속 효과가 작음 → 경수 감속은 수소가 주역이고, 물 분자의 산소는 고속 중성자 산란에 보조로 기여함
  • 산소는 열중성자 흡수 단면적이 1 mb 미만으로 매우 작아 흡수 손실은 거의 없음 → 물의 흡수는 주로 수소가 담당함

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 가~다 항과 라·마 항은 "축"이 다릅니다

가~다 항은 에너지 축의 값이라 2 MeV라는 출발점이 있어야 답이 나옵니다. 두 번째 충돌에서는 평균 1.779 MeV에서 다시 11.1 %를 잃으므로 손실량은 약 0.197 MeV로 줄어듭니다. 반면 라 항의 ξ는 레싸지 축의 값이라 출발 에너지가 필요 없습니다. 충돌 후 에너지 비 E′/E의 분포가 E를 포함하지 않기 때문입니다. 마 항의 충돌 횟수는 ξ에 총 레싸지 Δu = ln(E₀/E_th)를 곱해 나누므로 시작·종료 에너지가 다시 들어갑니다. 이 차이를 한 줄로 적어 두면 채점자는 수식을 외운 것이 아니라 구조를 이해했다고 봅니다.

해설: 152회는 정확한 평균인가요

n = Δu/ξ는 근사입니다. 마지막 충돌에서 레싸지가 18.2를 넘어서는 넘침분이 있어, 같은 이상모형에서 처음으로 0.025 eV 아래에 도달하는 평균 횟수는 약 152.4회로 Δu/ξ보다 약 0.7회 많습니다. 질량이 큰 산소는 계단(ξ)이 작아 이 오차의 비중이 매우 작습니다. 답안에는 "약 152회(평균 추정)"로 충분합니다. 문제의 "평균 충돌 횟수"를 정면충돌 최소 73회와 혼동하지 않도록, 둘을 구분해 적는 것이 안전합니다.

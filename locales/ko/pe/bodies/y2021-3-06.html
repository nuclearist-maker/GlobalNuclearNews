출처: KINS 원자력면허시험 자료실, 2021년 원자력발전기술사 필기 3교시 6번

문제

가압경수로 저출력 상태에서 원자로에 0.002 ΔK/K의 반응도를 삽입시켰을 때 아래의 주어진 정보를 이용하여 다음을 답하시오.

주어진 정보 값
유효지발중성자분율(β_eff) 0.0065
지발중성자 평균 붕괴상수(λ) 0.08 s⁻¹
즉발중성자 세대시간(l_p) 2×10⁻⁵ s

가. 역시간 방정식(제시) 나. 지발중성자를 고려할 때 원자로주기 다. 지발중성자를 고려하지 않을 때 원자로주기

출제 의도

역시간 방정식을 점동특성 방정식에서 끌어낼 수 있는지, 1군으로 줄여 2차식을 풀고 물리적으로 의미 있는 근(안정주기)을 고를 수 있는지 봅니다. 다 문항은 같은 반응도에서 지발중성자를 빼면 주기가 몇 ms 수준으로 짧아진다는 대비를 통해, 원자로를 제어할 수 있는 이유가 지발중성자에 있다는 점을 쓰게 하려는 것입니다.

답안 구성

  • 가정 및 문제 해석: 반응도 단위, 궤환 무시, l_p를 세대시간 Λ로 사용, 1군
  • 가: 점동특성 → 지수해 → 6군 역시간 방정식, 1군 형태
  • 나: 1군 2차식 풀이 → 두 근의 의미 → T = 28.1 s, 근사식 검산, SUR
  • 다: β = 0 → T = Λ/ρ = 0.010 s
  • 결론: 약 2,800배 차이와 지발중성자의 역할

답안 예시

1. 가정 및 문제 해석

  • ρ = 0.002 Δk/k = 200 pcm = 0.31 $(ρ/β = 0.002/0.0065) → 0 < ρ < β, 지발초임계
  • "저출력 상태" → 온도·출력 궤환 무시, 일정 반응도를 계단으로 삽입. 풀이를 위해 초기 임계 평형·외부 중성자원 무시를 추가로 가정함
  • l_p는 문제 표현대로 즉발중성자 세대시간 Λ로 사용함(같은 2×10⁻⁵ s를 수명 ℓ로 보고 Lamarsh 형식[1]으로 풀어도 28.14 s, 차이 약 3×10⁻⁵ s)
  • 문제가 평균 λ 하나만 주었으므로 지발중성자 1군 근사

2. (가) 역시간 방정식

  • 점동특성 방정식: dn/dt = [(ρ − β)/Λ]·n + Σλᵢcᵢ, dcᵢ/dt = (βᵢ/Λ)·n − λᵢcᵢ
  • n = n̂·e^(ωt), cᵢ = ĉᵢ·e^(ωt)(ω = 1/T) 대입 → ĉᵢ = βᵢn̂/[Λ(ω + λᵢ)]
  • 역시간 방정식(6군): ρ = ωΛ + Σ βᵢω/(ω + λᵢ)[1], 주기로 쓰면 ρ = Λ/T + Σ βᵢ/(1 + λᵢT)
  • 1군: ρ = ωΛ + βω/(ω + λ) → Λω² + (Λλ + β − ρ)ω − ρλ = 0[3]
  • 의미: 투입 반응도 ρ와 출력의 지수 증가율 ω를 잇는 식. 6군이면 근 7개, 1군이면 근 2개이며 양의 근 하나가 안정주기를 정함

3. (나) 지발중성자를 고려할 때 원자로주기

  • 주어진 값: Λ = 2×10⁻⁵ s, β = 0.0065, λ = 0.08 s⁻¹, ρ = 0.002
  • 계수: Λλ + β − ρ = 1.6×10⁻⁶ + 0.0065 − 0.002 = 0.0045016, ρλ = 1.6×10⁻⁴
  • 식: 2×10⁻⁵ω² + 0.0045016ω − 1.6×10⁻⁴ = 0
  • 근: ω = [−0.0045016 ± √(0.0045016² + 4 × 2×10⁻⁵ × 1.6×10⁻⁴)]/(2 × 2×10⁻⁵) = (−0.0045016 ± 0.0045031)/(4×10⁻⁵)
    • ω₁ = +0.03554 s⁻¹ → T₁ = 28.1 s (안정주기, 답)
    • ω₂ = −225.1 s⁻¹ → 감쇠시정수 −1/ω₂ = 4.4 ms: ω₂ ≈ −(β − ρ)/Λ인 즉발 과도항. 3~5 시정수(약 13~22 ms) 안에 사라지면서 출력을 빠르게 끌어올림(즉발도약)
  • 검산: Λ를 무시한 근사 T ≈ (β − ρ)/(λρ) = 0.0045/(1.6×10⁻⁴) = 28.125 s → 0.05 % 차이. 역대입 Λω₁ + βω₁/(ω₁ + λ) = 0.0020000 ✓
  • 부가: 기동률 SUR = 26.06/T = 0.93 dpm, 출력 배가시간 = T·ln2 = 19.5 s, 즉발도약 P₁/P₀ = β/(β − ρ) = 1.444[1](1군 정확해의 안정 모드 계수 1.4440과 거의 같음)

4. (다) 지발중성자를 고려하지 않을 때 원자로주기

  • β = 0으로 두면 모든 중성자가 즉발 → 역시간 방정식은 ρ = ωΛ
  • T = Λ/ρ = 2×10⁻⁵/0.002 = 0.010 s(수명 형식 ℓ/(k − 1) = ℓ(1 − ρ)/ρ = 0.00998 s, 같은 값)
  • 1초 뒤 핵분열 출력은 e¹⁰⁰ ≈ 2.7×10⁴³배가 되는 셈 → 기계적 제어로는 대응할 수 없음(궤환을 배제한 가상 외삽)

5. 결론

  • 같은 0.002 Δk/k에서 주기는 28.1 s 대 0.010 s, 약 2,800배 차이
  • 이 문제처럼 즉발임계에서 충분히 떨어진 지발초임계(ρ < β)에서는 출력 상승 속도를 지발중성자(λ, 평균 수명 약 12.5 s)가 정하고 Λ의 영향은 작음 → 제어봉·붕소로 제어할 시간 여유가 생김
  • ρ가 β에 가까워지면 주기가 급격히 짧아짐(이 1군 모델에서 ρ = β일 때 약 0.2 s). 즉발초임계에서 지발 항의 영향이 충분히 작아지면 T ≈ Λ/(ρ − β)로 근사함 → 운전 중 투입 반응도는 β보다 충분히 작게 관리함

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 1군 값과 6군 값이 다른 이유

같은 조건을 Keepin의 U-235 6군 상수[2](β 합 0.0065로 정규화)로 풀면 안정주기는 17.3 s입니다. 이 값은 문제 답의 보정값이 아니라 다른 군 모델의 참고 결과입니다. 1군 모델은 지발중성자 6개 군의 시간 척도를 λ 하나로 묶으므로, 반응도가 커져 단주기 선행핵군의 몫이 커지는 영역에서는 6군과 차이가 커집니다(ω → 0 등가값 λ_eff = β/Σ(βᵢ/λᵢ) = 0.0767 s⁻¹). 시험에서는 문제가 준 λ로 1군을 풀고, "1군 결과는 군 모델과 λ 선택에 따라 달라진다"는 한 줄을 덧붙이면 충분합니다.

해설: 근 두 개를 모두 언급하세요

2차식의 근을 하나만 쓰면 아쉽습니다. 음의 근은 버리는 근이 아니라 출력이 처음 수십 ms 동안 1.44배 부근까지 빠르게 오르는 즉발도약을 담당하는 항입니다. 출력은 불연속으로 뛰는 것이 아니라 4.4 ms 시정수로 연속적으로 오른 뒤 느린 증가 모드로 넘어갑니다. 1군 정확해는 P(t)/P₀ = 1.444·e^(t/28.14) − 0.444·e^(−225t)이고, 20 ms 뒤 1.44배, 60 s 뒤 약 12.2배가 됩니다. 안정주기 28.1 s는 이 과도가 끝난 뒤 출력이 e배로 늘어나는 데 걸리는 시간입니다.

채점 포인트와 흔한 실수

  • 다 문항에서 β를 빼는 실수: 지발 미고려는 β = 0이므로 T = Λ/ρ입니다. Λ/(ρ − β)는 즉발초임계 근사식입니다.
  • 반응도 단위 혼동: 0.002를 0.2(%)로 넣으면 주기가 엉뚱해집니다.
  • 음의 근을 주기로 답하기: 안정주기는 양의 근의 역수입니다.
  • SUR 환산 오류: 26.06/T(dpm)이지 60/T가 아닙니다.

현행 기준으로 달라진 점

출제 이후 달라진 기준 없음(확인 근거: 점동특성·역시간 방정식은 교과서 물리이며 법령·고시가 개입하지 않음). 기동률·주기의 운전 허용값은 호기별 절차서와 설정치로 판단합니다. 계산에 쓴 βeff = 0.0065, Λ = 2×10⁻⁵ s는 문제 조건이며, 실제 PWR의 βeff는 연소가 진행되며 지발중성자 분율이 작은 Pu-239(β ≈ 0.0021, U-235 ≈ 0.0065)의 핵분열 비중이 커져 주기말로 갈수록 줄어들고[1][2], 같은 반응도에서도 주기가 짧아집니다(구체 값은 노심·주기별 설계값).

출처: KINS 원자력면허시험 자료실, 2020년 원자력발전기술사 필기 4교시 4번

문제

길이가 L이고, 직경이 D인 수평 원형 배관 내에서 난류의 유체(Turbulent flow)가 흐르고 있다. 포화영역(Fully developed region)에서의 압력강하에 대한 입구영역(Developing region)에서의 압력강하의 비(Δp입구영역/Δp포화영역)를 구하시오. 단, 입구영역의 길이는 Zₑ, 등가직경은 Dₕ이고, L = 200D, Zₑ = 40Dₕ이다.

출제 의도

Darcy–Weisbach 식으로 마찰 압력강하가 유로 길이에 비례한다는 점, 원형관의 등가(수력)직경이 직경과 같다는 점, 배관을 입구영역과 포화영역(완전발달영역)으로 나눠 길이를 바르게 배분하는지를 봅니다. 여기에 난류 입구영역에서 속도분포가 발달하면서 생기는 추가 압력강하를 정성·정량으로 설명할 수 있으면 변별력이 생깁니다.

답안 구성

  • 가정 및 문제 해석: Dₕ = D, 포화영역 길이 = L − Zₑ, 비압축·수평·일정 물성
  • 본론 1: 입구영역·포화영역의 정의와 속도분포 발달
  • 본론 2: Darcy–Weisbach 적용 → 비 = Zₑ/(L − Zₑ) = 1/4
  • 본론 3: 보정 — 운동량 보정계수(1/7승 법칙)와 벽전단 초과분, Re = 10⁵ 예시 0.264
  • 결론: 기본 답 0.25, 정밀 해석 약 0.26~0.27, 원전 유로 압력강하 계산에서의 의미

답안 예시

1. 가정 및 문제 해석

  • 원형관 → Dₕ = 4A/P = 4(πD²/4)/(πD) = D → Zₑ = 40Dₕ = 40D
  • 배관 전체 L = 200D 중 앞 40D가 입구영역 → 포화영역은 Zₑ~L 구간으로 해석, 길이 = L − Zₑ = 160D
  • 비압축성·등온 단상, 물성 일정, 수평 배관(위치수두 변화 없음), 단면 일정(평균유속 V 일정)
  • Re·조도 미제시 → 입구영역 평균 마찰계수를 포화영역 값 f와 같게 두고 분포 발달 효과를 무시하는 근사로 기본 답을 냄(난류는 혼합이 강해 분포 발달이 빠름). 보정은 4항에서 따로 검토함
  • 압력 기준 p₀는 저수조가 아니라 관 입구 단면의 정압으로 둠

2. 입구영역과 포화영역

  • 입구영역(발달영역): 관 입구의 거의 균일한 속도분포가 벽 경계층 성장으로 바뀌어 가는 구간. 중심 유속이 빨라지고 벽 근처는 느려짐
  • 포화영역(완전발달영역): 경계층이 관 중심에서 만나 속도분포가 축 방향으로 더 변하지 않는 구간 → 압력구배 dp/dz 일정
  • 난류 입구길이 Lₑ/D ≈ 4.4Re^(1/6) [1](Re = 10⁴~10⁶에서 약 20~44D, 통용 10~60D) → 문제의 40D는 이 범위 안임. 층류(약 0.06Re)보다 훨씬 짧음

3. 압력강하비 계산

  • Darcy–Weisbach: Δp = f·(ℓ/D)·(ρV²/2) [1][2]
  • 입구영역: Δp입구 = f·(40D/D)·(ρV²/2) = 40f·(ρV²/2)
  • 포화영역: Δp포화 = f·(160D/D)·(ρV²/2) = 160f·(ρV²/2)
  • Δp입구/Δp포화 = 40/160 = 1/4 = 0.25 (f·ρV²/2 약분 → Re와 무관)
  • 검산: 전체 Δp = 200f·(ρV²/2) = 40f + 160f ✓, 입구영역 몫은 전체의 20 %

4. 보정: 입구영역의 추가 압력강하

  • 실제 입구영역 압력강하 = 벽 마찰 + 운동량 플럭스 증가 + 얇은 경계층에 의한 벽전단 초과분
  • 일반식: Δp입구/Δp포화 = (f̄ₑ/f)·(40/160) = 0.25 + K_dev/(160f) (K_dev: 같은 길이의 완전발달 압력강하를 넘는 추가분, 속도수두 단위)
  • 운동량 보정계수 β_m = ∫u²dA/(V²A): 균일 유입 1.0 → 1/7승 법칙 완전발달 1.0204 [1]
  • 운동량 항 Δp_mom = (1.0204 − 1.0)·ρV² = 0.0204ρV² = 0.041 × (ρV²/2) [3]
  • 예시(매끈한 관, Re = 10⁵, McAdams f = 0.184Re^−0.2 = 0.0184 [2])
    • Δp입구 = (40 × 0.0184 + 0.041)·(ρV²/2) = 0.777·(ρV²/2)
    • Δp포화 = 160 × 0.0184·(ρV²/2) = 2.944·(ρV²/2)
    • 비 = 0.777/2.944 = 0.264
  • Re에 따른 변화: Re = 10⁴(Blasius 0.0316) 0.258, Re = 10⁶(0.0116) 0.272 → f가 작을수록 운동량 항의 상대 비중이 커짐
  • 위 값은 균일 유입을 가정하고 벽전단은 완전발달 값으로 둔 채 운동량 변화만 더한 예시임. 실제 값은 입구 벽전단 분포와 유입 조건(날카로운 모서리·라운드·난류 촉진)이 있어야 정해짐

5. 결론

  • 기본 답: Δp입구/Δp포화 = Zₑ/(L − Zₑ) = 1/4 = 0.25
  • 보정 예시: 운동량 변화만 더하면 Re = 10⁴~10⁶에서 약 0.26~0.27(Re = 10⁵에서 0.264). 정확한 값은 입구 벽전단 분포와 유입 조건으로 정해짐
  • 난류·L/D가 큰 유로에서는 입구 영향이 작아 완전발달 마찰계수로 전 길이를 계산하고, 입구·출구·지지격자 손실은 형상손실계수 K로 따로 더하는 것이 실무 관행임 [2]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 왜 0.2가 아니라 0.25인가

가장 흔한 실수는 "입구영역 40D ÷ 전체 200D = 0.2"로 답하는 것입니다. 문제는 포화영역의 압력강하를 분모로 두었으므로 분모 길이는 입구영역을 뺀 160D입니다. 0.2는 입구영역이 배관 전체 압력강하에서 차지하는 몫이고, 같은 계산에서 함께 써 주면 검산이 됩니다. 또 등가직경 Dₕ를 굳이 준 것은 비원형 유로라면 Dₕ ≠ D일 수 있다는 점을 짚으라는 뜻으로 읽을 수 있습니다. 원형관은 Dₕ = D임을 한 줄로 밝히고 넘어가면 됩니다.

해설: 원전 유로에서의 압력강하 계산

노심 압력강하는 마찰(완전발달 f), 형상손실(하부 노심판·지지격자·상부 노심판의 K), 가속(가열에 따른 밀도 감소), 위치(중력) 항의 합으로 계산합니다. 지지격자를 지날 때마다 속도분포가 흐트러졌다가 다시 발달하므로 입구영역 효과가 반복되는데, 이 효과는 보통 격자 손실계수와 격자 하류의 열전달 증진으로 함께 반영합니다. 증기발생기 전열관처럼 L/D가 수백 이상인 유로는 입구영역 비중이 작아 이 문제의 기본 답처럼 길이 비로 근사해도 오차가 크지 않습니다.

채점 포인트와 흔한 실수

  • 분모 길이: 포화영역은 L − Zₑ = 160D입니다. 40/200 = 0.2는 오답입니다.
  • Dₕ = D 명시: 원형관의 수력직경이 직경과 같다는 근거(4A/P)를 쓰세요.
  • 가정 명시: 입구영역 f를 포화영역과 같게 둔 근사임을 밝히고, 운동량 변화와 입구 벽전단 분포가 보정 요인이라고 덧붙이면 좋습니다.
  • 층류 상관식 혼용: 입구길이 0.06Re는 층류용입니다. 난류는 4.4Re^(1/6) 정도로 훨씬 짧습니다.

현행 기준으로 달라진 점

출제 이후 달라진 기준 없음(확인 근거: Darcy–Weisbach 식·입구영역 해석은 유체역학 교과서 내용이며 법령·고시가 개입하지 않음). 실제 노심·계통 압력강하는 각 노형의 설계 상관식과 시험으로 정한 손실계수로 평가합니다.

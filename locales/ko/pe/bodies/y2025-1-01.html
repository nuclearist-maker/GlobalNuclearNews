출처: KINS 원자력면허시험 자료실, 2025년 원자력발전기술사 필기 1교시 1번

문제

가압경수로 비상노심냉각계통(ECCS)의 기능

핵심 키워드

  • 재고량 보충·노심 냉각: LOCA로 잃은 냉각재를 채워 노심을 다시 덮고 피복재 온도를 제한합니다.
  • 부반응도 주입: 고농도 붕산수로 주증기관 파단(MSLB) 같은 과냉각 사고의 재임계를 막습니다.
  • 재순환 장기 냉각: 수원이 바닥나면 격납건물 집수조 물을 다시 넣어 붕괴열을 계속 제거합니다.
  • 붕산 석출 방지: 고온관·저온관 동시 주입으로 노심의 붕산 농축을 씻어 냅니다.
  • 허용기준: 성능은 원안위고시 제2017-23호(10 CFR 50.46) 다섯 기준으로 판정합니다[3][4].

답안 예시

1. 정의

  • LOCA 등 설계기준사고 시 RCS에 붕산수를 주입해 노심을 냉각하고 장기 냉각을 보장하는 공학적 안전설비임
  • 근거: 기술기준규칙 제30조(비상노심냉각장치)[1], 10 CFR 50 App. A GDC 35[2]

2. 기능

  • ① 재고량 보충·노심 냉각: 파단으로 잃은 냉각재 보충 → 노심 재관수, PCT·피복 산화 제한
  • ② 부반응도 주입: 붕산수(예: APR1400 IRWST 4,000~4,400 ppm[5])로 MSLB 과냉각 재임계 방지, 정지여유 확보
  • ③ 재순환 장기 냉각: 수원 소진 → 집수조 재순환(RWT형 노형은 RAS로 흡입원 전환), 붕괴열 지속 제거
  • ④ 붕산 석출 방지: 장기 냉각 중 고온관·저온관 동시 주입 → 노심 관통 유량으로 농축수 배출
  • 대상 사고: LOCA, 제어봉 집합체 이탈, 2차측 냉각재 상실, SGTR[7]

3. 기능 수행 수단 (예시: APR1400 DCD 기준)

  • 피동: SIT 4기(N₂ 578~624 psig, 붕소 2,300~4,400 ppm)[5], 유량조절기로 대유량→소유량 자동 전환
  • 능동: SIP 4기(4계열 독립) → 원자로용기 DVI 주입, 작동 신호 SIAS(가압기 저압력 또는 격납건물 고압력)[6]
  • 수원: 격납건물 안 IRWST → 재순환 흡입원 전환(RAS) 불필요[6]
  • RWT형 기존 노형: HPSI(고압)·LPSI(저압 대유량) + 격납건물 밖 RWT → RAS

4. 성능 요건

  • 고시 제2017-23호: PCT ≤ 1,204 °C, 국부 산화 ≤ 17 %, 수소 ≤ 1 %, 냉각 가능 형상, 장기 냉각[3][4]
  • 단일고장 + 소외전원 상실 가정에도 기능(다중성·독립성)[1][2]

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설

이 문제는 "기능"을 묻기 때문에 계통 구성을 길게 늘어놓으면 배점을 놓치기 쉽습니다. 기능은 무엇을 막는가로 나누면 정리가 됩니다. ①은 피복 손상, ②는 재임계, ③은 붕괴열 축적, ④는 붕산 석출에 의한 유로 막힘을 막습니다. 그림처럼 ①은 LOCA·SGTR에서, ②는 MSLB에서 주 역할을 합니다. ③·④는 대형 LOCA 이후 장기 단계의 몫입니다.

각 기능은 허용기준과도 이어집니다. ①은 PCT·산화·수소·냉각 가능 형상, ③·④는 다섯째 기준인 장기 냉각에 대응합니다. 고온관 동시 주입 시점은 노형별 붕산 석출 해석과 운전 절차로 정하므로 호기마다 다릅니다. 답안에는 "장기 냉각 중(사고 후 수 시간 이내 전환)"처럼 쓰고 구체 시각은 단정하지 않는 것이 안전합니다.

채점 포인트와 흔한 실수

  • "LOCA 전용"으로 쓰는 실수: MSLB 붕산 주입과 SGTR 보충까지 써야 기능 범위가 완성됩니다.
  • 기능 대신 기기 나열: SIT·HPSI·LPSI는 기능을 수행하는 수단입니다. 기능 4가지를 먼저 쓰고 수단은 짧게 붙이십시오.
  • 고온관 주입 목적 혼동: 냉각 능력 증대가 아니라 붕산 석출 방지가 핵심입니다.
  • 수소 1 % 오해: 격납건물 농도가 아니라 피복 전량 반응 가상량 대비입니다.

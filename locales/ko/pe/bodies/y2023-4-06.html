출처: KINS 원자력면허시험 자료실, 2023년 원자력발전기술사 필기 4교시 6번

문제

어떤 원자로의 감속재 온도가 100℃ 상승하였을 때, 0.2% Δk/k에 해당하는 반응도가 감소하였다. 다음을 계산하시오. 가. 감속재 온도계수 나. 감속재의 온도가 350℃에서 320℃로 감소하였을 때 반응도 변화량 다. 1군 지발중성자를 가정하여 상기 '나'의 반응도 변화에 대한 원자로안정주기 (단, β = 0.0065, λ = 0.08 sec⁻¹) 라. 상기 '다'의 원자로안정주기를 고려할 때의 유효증배계수 (소수점 넷째 자리까지 표기)

※ 공개 문제지 텍스트에서 빠진 수식(Δk/k, β·λ 조건)은 원본 hwp의 수식 개체에서 복원했습니다.

출제 의도

온도계수 → 반응도 → 주기 → 증배계수로 이어지는 반응도 계산의 기본 사슬을 한 문항에 묶었습니다. 확인하려는 것은 네 가지입니다. ① % Δk/k 단위를 정확히 환산하는가 ② 감속재 냉각이 양의 반응도라는 부호를 맞추는가 ③ 1군 점동특성식에서 안정주기 T = (β − ρ)/(λρ)를 유도·적용하는가 ④ 반응도 정의 ρ = (k − 1)/k로 keff를 역산하는가. 계산 자체는 짧으므로 가정과 검산, 물리적 의미를 함께 써야 25점 답안이 됩니다.

답안 구성

  • 서론: 가정 및 문제 해석, 주어진 값 정리
  • 본론 가: 감속재 온도계수 정의와 계산
  • 본론 나: 반응도 변화량(부호 포함)
  • 본론 다: 1군 역시간식 → 안정주기 근사식 유도 → 대입
  • 본론 라: 반응도 정의로 keff 역산
  • 결론: 검산(역대입), 물리적 해석(음의 MTC와 출력 상승)

답안 예시

1. 가정 및 문제 해석

  • 원본 문제지의 수식 개체 기준: 반응도 감소 0.2 % Δk/k = 0.002, 1군 지발중성자 β = 0.0065, λ = 0.08 s⁻¹
  • 350 ℃에서 원자로는 임계(ρ₀ = 0, k₀ = 1)였다고 가정함 → 나의 반응도 변화가 곧 최종 반응도임
  • 감속재 온도계수는 350~320 ℃ 구간에서 일정하다고 가정함(1차 선형 근사)
  • 온도는 "차이"만 쓰므로 ℃와 K가 같음
  • 다의 안정주기는 반응도 투입 후 과도항이 사라진 점근 주기로 보며, 즉발중성자 수명 Λ의 기여는 무시함(Λ = 2×10⁻⁵ s로 잡아도 보정 약 0.04 s)
  • 반응도 정의는 ρ = (k − 1)/k를 씀

2. 주어진 값

항목 기호 값
온도 상승 ΔT₁ +100 ℃
반응도 변화 Δρ₁ −0.2 % Δk/k = −2.0×10⁻³ (−200 pcm)
온도 변화(나) ΔT₂ 320 − 350 = −30 ℃
지발중성자 분율 β 0.0065
1군 붕괴상수 λ 0.08 s⁻¹

3. 감속재 온도계수 (가)

  • 정의: α_M = ∂ρ/∂T_M ≈ Δρ/ΔT
  • 대입: α_M = (−2.0×10⁻³)/(+100 ℃) = −2.0×10⁻⁵ Δk/k/℃ = −2 pcm/℃
  • 음수이므로 감속재 온도가 오르면 반응도가 줄어드는 음의 되먹임임

4. 반응도 변화량 (나)

  • Δρ₂ = α_M × ΔT₂ = (−2.0×10⁻⁵)(−30) = +6.0×10⁻⁴ Δk/k = +0.06 % Δk/k = +60 pcm
  • 냉각으로 감속재 밀도가 커져 감속이 좋아지므로 양의 반응도가 들어감(ρ = 0.092 $)

5. 1군 안정주기 (다)

  • 1군 점동특성의 역시간식: ρ = ωΛ + βω/(ω + λ), ω = 1/T[1]
  • Λ 항 무시 → ρ = β/(1 + λT) → T = (β − ρ)/(λρ)
  • 대입: T = (0.0065 − 0.0006)/(0.08 × 0.0006) = 0.0059/0.000048 = 122.9 s
  • ρ > 0이므로 양의 주기, 출력은 P(t) = P₀·e^(t/T)로 증가함
  • 참고: 기동률 SUR = 26.06/T[1] = 0.21 dpm, 출력 배가시간 = T·ln2 = 85.2 s

6. 유효증배계수 (라)

  • 반응도 정의 ρ = (k − 1)/k → k = 1/(1 − ρ)
  • 다의 주기에서 반응도를 역산하면 ρ = β/(1 + λT) = 0.0065/(1 + 0.08 × 122.92) = 6.00×10⁻⁴ (나의 값과 같음)
  • k = 1/(1 − 0.0006) = 1/0.9994 = 1.000600… → keff = 1.0006 (소수점 넷째 자리)
  • ρ ≈ k − 1 근사를 써도 1.0006으로 같음

7. 검산 및 결론

  • 단위 검산: [ρ]는 무차원, [λρ]는 s⁻¹ → T의 단위 s ✓
  • 역대입: T = 122.9 s를 ρ = β/(1 + λT)에 넣으면 6.0×10⁻⁴ ✓
  • ρ = 60 pcm ≪ β = 650 pcm이므로 지발중성자가 주기를 지배하는 지발 초임계 영역임
  • 결론: 음의 MTC 원자로에서 감속재 30 ℃ 냉각은 +60 pcm을 넣고, 1군 근사로 약 123 s 주기의 출력 상승을 일으킴

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 반응도–주기 곡선 위에서 보기

안정주기 식 T = (β − ρ)/(λρ)는 반응도가 작을수록 주기가 1/ρ에 비례해 길어지고, ρ가 β에 가까워질수록 주기가 0으로 떨어지는 모양입니다. 위 그림의 파란 곡선이 이 1군 근사이고, 주황 점선은 지발중성자 6군 모델(Keepin 상수[2], β 합 0.0065로 정규화, Λ = 2×10⁻⁵ s)의 역시간식 수치해입니다. 같은 60 pcm에서 6군 해는 109 s로, 1군 λ = 0.08 s⁻¹ 근사(122.9 s)보다 약 11 % 짧습니다. 100 pcm에서는 1군 68.8 s, 6군 54.9 s로 차이가 더 벌어집니다. 시험에서는 문제가 1군을 지정했으므로 122.9 s가 답이며, 6군 값은 "1군 근사가 소반응도에서 주기를 다소 길게 준다"는 해석으로만 덧붙이면 됩니다.

간혹 T ≈ β/(λρ) = 135.4 s로 쓰는 답안이 있습니다. 이는 ρ ≪ β라고 보고 분자에서 ρ를 뺀 근사로, 이 문항에서는 약 10 % 차이가 납니다. 근사를 쓴다면 근거를 밝혀야 합니다.

해설: 숫자가 말해 주는 것

문제의 −2 pcm/℃는 설명용 값입니다. 실제 PWR의 MTC는 붕소 농도와 연소도에 따라 크게 달라서, 주기초에는 0 근처이고 주기말로 갈수록 수십 pcm/°F의 음수가 됩니다. 또 감속재 온도 350 ℃는 가압경수로 운전압력 15.5 MPa의 포화온도(약 345 ℃)[3]보다 높으므로, 문제의 온도는 계산용 가상 조건으로 보는 것이 맞습니다. 답안 가정에 "MTC 일정"을 적어 두면, 실제 MTC가 온도에 따라 변한다는 점을 알고 있음을 보여 줄 수 있습니다.

자주 하는 실수는 다섯 가지입니다. ① 0.2 %를 0.2나 2×10⁻⁴로 환산하는 것 ② 냉각인데 반응도를 음수로 쓰는 것 ③ 다에서 ρ를 β에서 빼지 않고 근거 없이 근사하는 것 ④ 라에서 k = 1 − ρ처럼 부호를 뒤집는 것 ⑤ 온도 차이에 273을 더하는 것입니다.

현행 기준으로 달라진 점

출제 이후 달라진 기준 없음(확인 근거: 온도계수·점동특성 계산은 물리 법칙이며, 문제의 β = 0.0065는 U-235 열중성자 핵분열의 통용값입니다). 운영 측면에서 MTC 한계는 표준기술지침서 LCO 3.1.3 체계에 따라 노심운전제한보고서(COLR)에 두며[4], 국내 「운영기술지침서의 작성에 관한 기준」은 현행 원안위고시 제2024-13호(2024.12.31 시행)입니다[5]. 설계 요건인 반응도 되먹임의 고유보호는 「원자로시설 등의 기술기준에 관한 규칙」(현행 원안위규칙 제37호) 제18조(원자로의 고유보호)에 있습니다[6].

출처: KINS 원자력면허시험 자료실, 2020년 원자력발전기술사 필기 4교시 2번

문제

원자로 출력을 50 %에서 100 %로 증발하고자 한다. 이 때 평형 제논(Xe) 농도의 증가로 인해 생기는 반응도는 몇 pcm인지 아래 정보를 활용하여 계산하시오. 단, 유효증배계수(k_eff)의 변화는 제논 농도 변화에 따른 열중성자이용률(Thermal utilization factor, f)의 변화에만 의존하며, 나머지 5개 인자는 모두 1.0이라고 가정한다.

  • 각 출력에서 중성자속: φ50% = 2.5×10¹³ n/cm²·s, φ100% = 5.0×10¹³ n/cm²·s
  • 아이오딘 및 제논의 생성수율: γI = 0.06, γXe = 0.002
  • 핵분열 반응단면적: Σf = 0.18 cm⁻¹
  • 핵연료(F) 및 감속재(M)의 흡수단면적: Σa,F = 0.58 cm⁻¹, Σa,M = 0.10 cm⁻¹
  • 제논의 미시적 흡수단면적: σa,Xe = 2.7×10⁶ barn
  • 제논 반감기: T1/2,Xe = 9.2 hr

출제 의도

평형 제논 농도식을 세우고, 제논 흡수가 열중성자이용률 f를 통해 반응도로 이어지는 경로를 단위 환산까지 정확히 계산할 수 있는지 봅니다. 출력이 두 배가 되어도 평형 제논은 두 배가 되지 않는 포화 특성을 숫자로 확인하는 것이 핵심이고, 반응도 차이를 어떤 정의로 구했는지 밝히는지도 채점 포인트입니다.

답안 구성

  • 가정 및 문제 해석: k = f, 반응도 정의, "증발" = 출력 증가
  • 1단계: 상수 정리(λXe, σa,Xe 단위, 포화 플럭스 φX)
  • 2단계: 출력별 평형 제논 농도와 거시 흡수단면적
  • 3단계: 출력별 f와 반응도, 차이 계산
  • 검산과 물리적 해석: 포화, 과도 거동, 실제 노심과의 차이

답안 예시

1. 가정 및 문제 해석

  • "증발(增發)"은 출력 증가(50 → 100 %)로 해석함. 두 출력 모두 아이오딘·제논이 평형에 도달한 상태끼리 비교함(과도 과정은 계산 대상 아님)
  • 나머지 5인자 = 1 → k = f = Σa,F/(Σa,F + Σa,M + Σa,Xe)
  • 반응도 정의 ρ = (k − 1)/k를 쓰고, 답은 Δρ = ρ100 − ρ50으로 구함
  • 평형 제논 식에는 아이오딘 반감기가 소거되므로 T1/2,I가 없어도 계산 가능함

2. 상수 정리

  • λXe = ln2/(9.2 h × 3,600 s/h) = 2.093×10⁻⁵ s⁻¹
  • σa,Xe = 2.7×10⁶ b × 10⁻²⁴ cm²/b = 2.7×10⁻¹⁸ cm²
  • 포화 플럭스 φX = λXe/σa,Xe = 7.75×10¹² n/(cm²·s) → 두 출력 모두 φ > φX(흡수 제거 우세, 포화로 접근)
  • 총 수율 × 핵분열 단면적 = (0.06 + 0.002) × 0.18 = 0.01116 cm⁻¹

3. 평형 제논 농도와 흡수단면적

  • 평형식: X∞ = (γI + γXe)Σfφ/(λXe + σa,Xe φ), Σa,Xe = σa,Xe·X∞ [1][2]
  • 50 %: σa,Xe φ = 6.75×10⁻⁵ s⁻¹ → 분모 8.843×10⁻⁵ s⁻¹
    • X∞ = 2.79×10¹¹/8.843×10⁻⁵ = 3.155×10¹⁵ cm⁻³, Σa,Xe = 8.519×10⁻³ cm⁻¹
  • 100 %: σa,Xe φ = 1.35×10⁻⁴ s⁻¹ → 분모 1.559×10⁻⁴ s⁻¹
    • X∞ = 5.58×10¹¹/1.559×10⁻⁴ = 3.579×10¹⁵ cm⁻³, Σa,Xe = 9.662×10⁻³ cm⁻¹
  • 출력 2배에 제논은 1.13배(X50/X100 = 0.882)만 증가함

4. 열중성자이용률과 반응도

  • 무제논 f₀ = 0.58/0.68 = 0.85294 (참고)
  • f50 = 0.58/0.688519 = 0.842388, f100 = 0.58/0.689662 = 0.840992
  • ρ = 1 − 1/f이므로 Δρ = 1/f50 − 1/f100 = (Σtot,50 − Σtot,100)/Σa,F
    • Δρ = (0.688519 − 0.689662)/0.58 = −1.971×10⁻³
  • 답: 약 −197 pcm (평형 제논 증가로 반응도가 197 pcm 감소함)
  • 같은 결과를 제논 반응도로 보면 ρXe = −Σa,Xe/Σa,F: 50 % −1,469 pcm, 100 % −1,666 pcm → 차이 −197 pcm
  • 참고: Δk/k50 = −166 pcm은 상대 증배계수 변화로 다른 양임(Δρ = (Δk/k50)/k100, 여기서 k ≈ 0.84라 차이가 큼) → 반응도 정의를 답안에 명시함

5. 검산과 물리적 해석

  • 단위: σa,Xe φ(s⁻¹)와 λ(s⁻¹) 차원 일치, X∞(cm⁻³) × σ(cm²) = Σ(cm⁻¹) 확인
  • 포화: φ → ∞이면 ρXe → −(γI + γXe)Σf/Σa,F = −1,924 pcm이 상한 [1] → 100 %에서 이미 87 %에 도달
  • 제거 경로: 제논 총 제거 중 중성자 흡수 비율이 50 % 출력에서 76 %, 100 %에서 87 %임
  • 절대 ρ(약 −18,710·−18,907 pcm)는 "나머지 인자 = 1"로 가정한 모형의 값이라 실제 운전 노심의 반응도로 해석할 수 없음 → 같은 모형 조건의 차이를 답으로 씀
  • 운전 측면: 증발 직후 연소 증가로 제논이 먼저 줄어(양의 반응도) 수 시간 뒤 최저가 되고, 아이오딘 증가로 다시 늘어 새 평형(−197 pcm 추가)에 접근함(정성적 시간 규모 약 2일, 이 문제 입력만으로 계산한 값은 아님) → 붕소 희석·제어봉으로 보상하고 축방향 출력분포를 감시함

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 왜 197 pcm밖에 안 될까

출력 운전 중 PWR의 중성자속은 포화 플럭스 φX보다 몇 배 큽니다. 이 영역에서는 제논이 붕괴보다 중성자 흡수로 주로 사라지므로, 출력을 올리면 생성과 연소가 함께 늘어 평형 농도는 13 %만 늘어납니다. fig2의 곡선이 50 % 지점부터 이미 눕기 시작하는 이유입니다. 반대로 정지하면 연소 항이 사라져 제논이 크게 늘어나며, 이것이 정지 후 제논 정점과 재기동 제약의 원인이 됩니다.

해설: 교과서 값과 실제 노심

이 문제의 상수로 구한 전출력 평형 제논 반응도(−1,666 pcm)는 1군·균질 모델의 설명용 값입니다. 실제 PWR 전출력 평형 제논은 이보다 큰 약 −2,500~−3,000 pcm 수준으로 알려져 있습니다. 문제의 수율(0.06·0.002)도 교과서 값(γI 0.0639, γXe 0.00237) [1]을 반올림한 것이므로, 답은 주어진 값으로 계산하고 실제 값과 다를 수 있다는 점만 한 줄 덧붙이면 됩니다.

현행 기준으로 달라진 점

출제 이후 달라진 기준 없음 — 제논 평형식과 반응도 정의는 교과서 물리이며 변화가 없습니다(확인 근거: Lamarsh 3판 7.4절 [1]). 국내 「원자로시설 등의 기술기준에 관한 규칙」은 현행 원안위규칙 제37호(2026.3.30)이고, 반응도제어계통(제28조)·노심관리(제61조) 요건의 골격은 같습니다 [3].

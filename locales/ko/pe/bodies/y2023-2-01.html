출처: KINS 원자력면허시험 자료실, 2023년 원자력발전기술사 필기 2교시 1번

문제

다음 원자로 과도사고(Transient)에 대해 기술하시오. 가. 주증기 배관 파단 나. 증기발생기 전열관 파단 다. 소외전원상실을 수반한 단일 원자로냉각재펌프 회전자 고착 라. 제어봉 이탈

출제 의도

안전해석 15장의 대표 사건 네 개를 사건군별로 구분할 수 있는지 봅니다. 각 사건의 초기 변화(과냉각·반응도, 1·2차 경계, 노심유량, 급격한 반응도 삽입)를 짚고, 그 결과로 어떤 보호 신호가 작동하며 어떤 판정기준으로 평가하는지를 일관된 틀로 정리해야 합니다. 네 사건을 같은 분량·같은 순서로 쓰는 것이 득점에 유리합니다.

답안 구성

  • 서론: 가정 및 문제 해석(네 사건 모두 SRP 15장 가상사고), 공통 판정 축 3개
  • 본론 가: MSLB — 과냉각 → 반응도 → 재임계, 제한 조건(HZP·EOC·고착봉)
  • 본론 나: SGTR — 격납건물 우회, 증상, 압력 평형 전략
  • 본론 다: RCP 고착 + LOOP — 유량 급감, 관성서행, 파손봉 가정
  • 본론 라: 제어봉 이탈 — 출력 펄스, 도플러, RG 1.236 기준
  • 결론: 비교표와 설계 대책 요약

답안 예시

1. 가정 및 문제 해석

  • 문제는 "과도사고"로 묶었으나 네 사건의 제한 형태는 모두 NUREG-0800 SRP 15장 가상사고(PA, ANS Condition IV 상당)로 분석함[1]
  • 소형 2차측 증기 유출(SG 방출밸브 오개방 등)은 예상운전과도(AOO)로 구분함
  • 각 사건을 정의 → 진행 → 정지·완화 → 제한 가정 → 판정기준 순으로 기술함
  • 공통 판정 축: ① 연료(DNBR·선출력·연료 엔탈피) ② RCS·주증기 압력(사건별 허용 설계한계) ③ 부지 경계 선량

2. 가. 주증기 배관 파단(MSLB, SRP 15.1.5)

  • 정의: 2차측 주증기관 파단 → SG 열제거 급증 → 1차측 과냉각 → 음의 MTC로 양의 반응도 삽입
  • 진행
    • SG 압력 급감 → 저온관 온도 하강 → 냉각재 수축 → 가압기 수위·압력 감소
    • 원자로 정지(노형별: 저SG압력, 가변과출력, 저가압기압력 등) → MSIS로 MSIV 폐쇄 → 건전 SG 방출 종료
    • MSIV 상류 파단이면 파단 SG가 건조될 때까지 방출 지속 → 급수 격리·파단 SG 보조급수 차단
    • SIAS → 붕산 주입으로 음의 반응도 확보 → 건조 후 RCS 재승온, 건전 SG로 붕괴열 제거
  • 제한 가정: 고온 영출력(HZP)·주기말(EOC)(MTC 최대 음, SG 수량 최대), 반응도가 최대인 제어봉 1개 고착, 소외전원 유·무, 단일고장
  • 재임계 판정 = 순반응도 0 도달 여부(SDM에 고착봉이 이미 반영되어 있어 중복 차감하지 않음)
    • 냉각 중 도플러 기여는 +(연료온도 하강), 재임계 뒤 출력이 오르면 −
    • 재임계 여부는 노형·SDM·주기 시점별 해석 결과에 따름
  • 국부 현상: 파단 루프 쪽 비대칭 냉각 + 고착봉 주변 첨두계수 증가 → DNBR·첨두 선출력으로 평가
  • 격납건물 내부 파단은 격납건물 압력·온도 상승(살수 작동) — 격납건물 설계압력 평가 사건
  • 대책: SG 출구 유량제한기(고정 벤투리, 임계유동으로 방출 상한), 빠른 MSIV, 충분한 SDM, MTC 하한 관리

3. 나. 증기발생기 전열관 파단(SGTR, SRP 15.6.3)

  • 정의: 설계기준 = 전열관 1개 양단(완전 원주) 파단[1], 1차(약 15.5 MPa) → 2차(약 7 MPa) 유출
  • 특징: 1차 압력경계 손상이며, 2차계통으로 새어 나간 냉각재가 ADV·MSSV 등으로 대기 방출되면 격납건물 우회 경로가 됨
  • 증상
    • 가압기 압력·수위 감소, 충전유량 증가
    • 파열 SG 수위 증가, 급수 < 증기 유량
    • 2차측 방사선 경보(복수기 공기추출기 배기, SG 취출수, 주증기관 N-16)
    • 격납건물 압력·방사선은 변화 없음 → LOCA와 구별
  • 진행: 저가압기압력 트립·SIAS → SI 유량 = 파단유량인 압력에서 RCS 압력 정체 → 소외전원 상실 가정 시 복수기 상실 → ADV·MSSV 대기 방출
  • 운전 전략: 파열 SG 확인·격리 → 건전 SG로 냉각 → RCS 감압(파열 SG 압력과 평형) → SI 종료 → 정지냉각 진입
    • 격리 전 충분히 냉각해야 파열 SG 압력이 MSSV 설정압에 닿지 않음
    • SI를 계속 돌리면 유출 지속 → SG 과충수·주증기관 침수 위험
  • 판정: 사고 전 옥소첨두·사고 동반 옥소첨두 두 경우를 선원항으로 가정한 부지 경계 선량, 과충수 방지 확인

4. 다. 소외전원상실을 수반한 단일 RCP 회전자 고착(SRP 15.3.3)

  • 정의: RCP 1대 회전자가 순간 고착 → 해당 루프 유량이 거의 즉시 0, 역류까지 발생 → 노심유량 급감
  • 소외전원상실 동반은 보수적 가정임: 터빈 트립 시점(또는 수 초 후)에 소외전원 상실 → 나머지 RCP도 관성서행 → 유량 감소 확대 → DNB 측면 제한 경우
  • 진행
    • 유량 급감 → 냉각재 온도 상승 → 가압기 인서지 → RCS 압력 상승
    • 원자로 정지(노형별): CE형 CPC 저DNBR(RCP 축속도 입력), W형 저RCS유량·RCP 저속도
    • 터빈 트립 → 소외전원 상실 → 비상디젤발전기·보조급수 → 자연순환, 복수기 상실로 ADV·MSSV 열제거
  • 판정
    • DNBR이 한계 아래로 내려간 연료봉은 파손으로 가정해 선량 평가에 반영
    • 냉각 가능 형상 유지, RCS·주증기 첨두압력은 사건별 허용 설계한계 이하
  • 대책: RCP 플라이휠 관성(유량 감소 완화), 빠른 유량 감시 트립, DNBR 운전 여유(LCO)

5. 라. 제어봉 이탈(SRP 15.4.8)

  • 정의: 원자로용기 헤드의 제어봉구동장치 압력하우징 원주 파단 → 압력차로 제어봉 집합체 1개가 약 0.1 s 안에 이탈
  • 결과: 국부 양의 반응도 급삽입 + 출력분포 왜곡(첨두계수 급증) + 하우징 파단부의 소형 냉각재상실
  • 진행
    • 제한 사례에서 이탈 반응도가 βeff를 넘으면 즉발임계 → 수십 ms 폭의 출력 펄스
    • 펄스 정점은 도플러(음의 FTC) 궤환이 꺾음 → 이후 트립(고출력·가변과출력 등)으로 정지
  • 제한 가정: HZP·EOC(이탈 반응도 최대, βeff 최소)가 대개 제한, 전출력 경우도 평가
  • 판정(현행 미국 RG 1.236, 2020)[2]
    • 냉각 가능성: 첨두 반경평균 연료 엔탈피 < 230 cal/g, 연료 용융 < 10 % 체적
    • 피복관 파손 문턱: 고온 파손(피복관 차압 함수), PCMI 파손(초과 수소 함량 함수), 용융 연료 → 파손봉 수를 선량 평가에 반영
    • RCS 압력: ASME III Service Level C 응력 이내(신규 신청)
  • 대책: 출력의존 삽입한계(PDIL)로 이탈 가능 반응도를 사전에 제한(운전제한), CEDM 하우징 1등급 설계·가동중검사, 음의 FTC

6. 결론

  • 초기 변화: MSLB = 과냉각·반응도, SGTR = 1·2차 경계(우회 방출), RCP 고착 = 노심유량(DNB), 제어봉 이탈 = 급격한 반응도 삽입(엔탈피)
  • 네 사건 모두 연료 손상 정도·압력경계·선량 세 축으로 판정하며, 제한 조건(HZP·EOC·고착봉·LOOP)을 보수적으로 조합함
  • 설계 대책은 사건별 1차 원인을 직접 막는 장치(유량제한기·MSIV, SG 전열관 관리, 플라이휠, PDIL)와 공통 보호(원자로 정지·SI)로 이중화됨

※ 답안 예시이며 공식 정답이 아닙니다. 현행 기준(2026년)으로 작성했습니다.

해설: 왜 네 사건을 함께 묻나

네 사건은 각각 다른 사건군을 대표합니다. 2차계통 열제거 증가, 냉각재 재고량 감소, 냉각재 유량 감소, 반응도·출력분포 이상입니다. 답안에서 사건마다 초기 변화를 한 줄로 밝혀 두면 진행 과정과 판정기준이 자연스럽게 따라옵니다. 소외전원상실 가정은 다목에만 적혀 있지만, 실제 해석에서는 MSLB와 SGTR에서도 소외전원 유·무를 모두 따져 더 불리한 쪽을 씁니다. SGTR은 복수기를 잃어 대기 방출이 생기므로 소외전원 상실이 대개 불리합니다.

해설: 230 cal/g를 쓸 때 주의할 점

230 cal/g는 냉각 가능 형상을 지키는 상한입니다. 피복관 파손 여부는 별도 문턱으로 판단합니다. 고연소도 연료는 PCMI 파손 문턱이 훨씬 낮을 수 있어, 엔탈피 상승량을 피복관 초과 수소 함량별 곡선과 비교합니다. 구 RG 1.77의 280 cal/g[3]는 2020년 RG 1.236으로 대체되었습니다[2].

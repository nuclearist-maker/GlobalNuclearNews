Questions and corrections

Use the site's public GitHub issue tracker to report a broken link, suggest a source or request a correction. A GitHub account is required to open an issue.

Open a GitHub issue →

Include the article URL, the passage concerned and, where possible, a link to a primary source. This makes it easier to identify and assess the issue.

Public correspondence

Issues and replies are public. Do not include private contact details, personal records, passwords or confidential information. The site currently provides no private contact form or published inquiry email address.

GitHub handles account and issue data under its Privacy Statement. Response times are not guaranteed.

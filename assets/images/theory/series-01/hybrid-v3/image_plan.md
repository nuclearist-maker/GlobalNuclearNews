# 이미지 계획 — 001·002

모든 자산은 독립 ImageGen 장면을 기반으로 하며 최종 규격은 1600×900 PNG이다. 한글·수치·수식은 편집 가능한 HTML/CSS에서 결정론적으로 합성한다.

## 001 원자력공학의 범위

- `001-thumbnail.png`: 발전·의료·재료검사·우주를 연결하는 원자력공학 응용 장면. 본문 머리말 앞.
- `001-body-01.png`: 핵분열→열발생→열전달→터빈→전력의 에너지 변환. 앵커: “발전소에서는 이를 다섯 단계의 에너지 변환으로 확대한다.” 뒤.
- `001-body-02.png`: 물리적 장벽과 안전기능의 중첩. 앵커: “원자력 안전은 완성된 설비에 마지막으로 붙이는 부속 기능이 아니다.” 뒤.

## 003-007 추가 계획

각 글은 제목 직후 독립 썸네일, 첫 원리·관계식 설명 뒤 `body-01`, 두 번째 계산·적용 설명 뒤 `body-02`를 배치한다. 003은 세 입자 비교/탄소 적용, 004는 탄소 핵종 비교/핵반응 장부, 005는 수소 동위원소/추적자, 006은 탄소-12 분할/질량계, 007은 몰의 입자장/연료펠릿으로 장면과 설명 기능을 분리했다. 모든 본문 이미지에서 주 피사체는 중앙 10~85% 영역, 합성 정보층은 상단 4~17%와 하단 80~96%, no-intrusion 영역은 각 핵·시료·검출기 윤곽으로 설정했다.

# 원자력이론 001~005 본문 이미지 개정 계획

- 공통 규격: 1600×900 PNG, 16:9, ImageGen 실사·3차원 장면과 HTML/CSS 정밀 정보 레이어의 합성
- 정보 배치: 주요 피사체와 겹치지 않는 음영 영역만 사용하고, 정보판은 텍스트 길이에 맞춰 자동 축소
- 001: 핵분열에서 전력망까지의 에너지 흐름 / 에너지·의료·재료·안전 응용
- 002: 경기장 비유의 길이척도 / 핵반지름 세제곱근 법칙과 수치 비교
- 003: 양성자·중성자·전자 역할 / 입자 변화에 따른 이온·동위원소·원소 변화
- 004: 핵종 기호 A·Z·N / 탄소-12와 탄소-14 비교
- 005: 수소 동위원소 구성 / 화학적 공통점과 핵적 차이

각 최종 PNG의 편집 원본은 같은 이름의 HTML과 `composite.css`, 사진형 기반 이미지는 `-base.png`로 보존한다.

# 원자력이론 게시물 운영 기준

## 게시물별 독립 시각 설계와 수식 무결성

- 생성 전에 게시물마다 `visual_design.md/json`을 작성하고 학습명제, 독자 질문, 시각 문법, 공간·시간축, 물리량·단위, 구성 서명을 확정한다.
- 공통 좌우 분할, 동일 반투명 카드, 동일 제목·공식판을 반복하고 내용만 교체하는 템플릿형 이미지를 금지한다.
- 수식은 HTML의 `sup/sub`, MathML, KaTeX·MathJax 또는 검증된 SVG로 조판한다. 평문 `T1/2`, `10-15`, `U-235`를 최종 수식 대신 사용하지 않는다.
- 수식이 있는 이미지는 `formula_manifest.json`과 `tools/qa_theory_formulas.py`의 DOM·렌더 검사를 통과해야 한다. 원본과 390 px 축소본에서 첨자, 분수선, 글리프, 단위가 직접 판독되지 않으면 FAIL이다.
- 1~5번 시험 묶음은 공개 배포하지 않고 로컬 결과와 QA 보고서를 사용자에게 먼저 제시한다. 사용자가 적용방향을 확정한 뒤에만 6~50번으로 확장한다.
- 본문과 캡션은 모두 `합니다체` 경어체로 통일하고 `tools/qa_theory_style.py`를 게시물별로 실행한다.
- 한 편이 본문·수식·이미지 원본검사를 모두 통과해야 다음 편으로 진행한다. 5편마다 이미 승인된 전체 게시물과 반복문장·구성 서명·정보밀도를 누적 비교한다.
- 합성 정보영역은 주요 피사체·입자경로·계통 유로와 겹치지 않아야 하며 좌표 교차검사와 원본 시각검사를 모두 통과해야 한다.

원자력이론 게시물은 상위 제작 프로젝트의 `THEORY_PUBLICATION_WORKFLOW.md`와 다음 사이트 규칙을 적용한다.

- 본문 이미지는 실사형 또는 완성도 높은 3차원 ImageGen 기반 장면과 HTML/CSS/SVG·그래프 도구의 정확 정보 레이어를 합성한다.
- 선·도형만으로 만든 평면 이미지, 내용보다 큰 빈 글상자, 빈 패널, 가짜 UI와 반복 카드 구도를 최종본으로 사용하지 않는다.
- 기반 PNG, 편집 가능한 합성 원본, 최종 1600×900 PNG, 이미지 계획과 PASS/FAIL 검수기록을 보존한다.
- 원본 크기와 모바일 축소본에서 글자 잘림, 피사체 가림, 레이어 겹침, 수식·축·단위와 정보 밀도를 확인한다.
- 게시물은 `assets/app.js`에 `section: "theory"`와 일관된 `category`를 등록한다. 이론 게시판은 실제 게시물의 고유 카테고리를 자동으로 필터 버튼으로 표시하므로 버튼을 HTML에 수동 추가하지 않는다.
- 원자력이론 HTML은 반드시 `posts/theory/`에 저장한다. 글로벌 원자력 소식 HTML이 저장되는 `posts/news/`와 혼합하지 않는다.
- 배포 후 공개 목록의 전체·카테고리 필터와 각 최종 이미지 URL을 직접 확인한다.
- 대량 제작은 5편 단위로 중간 품질 게이트를 둔다. 각 묶음은 제작자 자체검사 후 별도 QA 담당이 `tools/qa_theory_posts.py`와 원본·모바일 시각검사를 수행하고, 모든 FAIL이 해결된 뒤에만 다음 묶음과 배포로 진행한다.
- 동일 이미지 경로, 동일 파일 해시, 지각적으로 유사한 이미지, 같은 기반 장면에 글자만 바꾼 이미지는 치명적 중복으로 간주해 배포를 차단한다.
- 본문은 유효문자 1,400자 이상으로 정의·원리·단계별 예시·실제 적용·오해와 한계·핵심 정리를 6절 이상 포함하고, 수치 또는 상황 예시를 최소 2개와 주제별 클릭 가능한 참고자료를 제공한다.
